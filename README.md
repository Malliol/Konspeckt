# Konspeckt

# Курс «Подготовка к специалисту по платформе 1С»

Источник: YouTube-плейлист https://www.youtube.com/playlist?list=PLh28ogpgRJUPQDnx1uV9p19jLbpyBa3ua (129 уроков, Илья Леонтьев).

- `notes/` — конспект каждого из 129 уроков (правила экзамена, баллы/штрафы, приёмы, код 1С).
- `transcripts/` — полный текст урока. Для уроков, у которых удалось скачать субтитры повторно, текст **с таймкодами** (абзацы по ~45 с, со ссылкой на момент видео); для остальных — очищенный текст без таймкодов.
- `comments/` — комментарии зрителей под видео (топ по лайкам, с ответами).
- `chat/` — повтор чата прямого эфира (live chat replay), где он сохранён.
- `build_extras.py` — сборка расшифровок с таймкодами, комментариев и чата из сырых данных yt-dlp; `vtt2txt.py` — очистка субтитров.

## Полнота данных

Для всех **129** уроков есть расшифровка с таймкодами (`transcripts/`) и комментарии зрителей (`comments/`); повтор live-чата (`chat/`) есть у **122** уроков (у остальных видео эфира не было). Недокачанных уроков нет.


Получение субтитров:

```
pip install yt-dlp
yt-dlp --skip-download --write-auto-subs --sub-langs ru-orig --sub-format vtt \
  -o "%(playlist_index)02d_%(id)s" "<playlist url>"
```
