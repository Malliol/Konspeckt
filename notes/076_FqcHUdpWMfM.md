# Урок 76. Отчёт «Анализ начислений», вариант 2 (СПР). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=FqcHUdpWMfM · 42 мин · [полный текст](../transcripts/076_FqcHUdpWMfM.md)

## О чём урок
Билет № 5, отчёт **«Анализ начислений»**: подразделение, сотрудник, **начисление по окладу** (отработано часов, сумма), **начисление от продаж** (процент надбавки, сумма надбавки), итого; сверху заголовок «Месяц: …». Разбор приёмов СКД; оставшееся условие билета (штрафы за опоздание) — на следующее занятие.

## Запрос: объединение двух регистров
- Данные из **двух регистров расчёта**: основные начисления (оклад, отработано часов) и дополнительные (процент надбавки, сумма надбавки).
- Использовать **`ОБЪЕДИНИТЬ ВСЕ`**, а не соединение: в каждой части — одинаковое число полей, **разные по смыслу значения — в разных колонках** (остальные заполнять `0`): «Оклад» (из `Результат`), «ОтработаноЧасов», «ПроцентНадбавки» (из параметра), «Надбавка» (из `Результат`). Соответствие полей по порядку — проверять, чтобы результат оклада не попал в колонку надбавки.
- Условия в обеих частях: `ПериодРегистрации = &ПериодРегистрации` и `Активность = ИСТИНА`.
- Группировка (схлопывание) — не в запросе, а в СКД (ресурсы + группировки).

## СКД
- Параметр «ПериодРегистрации»: убрать ограничение доступности, «Всегда использовать», выражение `НачалоПериода(&ПериодРегистрации, "Месяц")` (**кавычки обязательны**); в пользовательские настройки; значение по умолчанию — начало месяца; **«Выводить параметры» — Ложь**.
- **Ресурсы:** оклад, надбавка, отработано часов, процент (без ресурсов группировка не схлопнет данные). **Итого** — это не итог СКД, а **вычисляемое поле** «СуммаИтого» = «Оклад + Надбавка» (тоже ресурс).
- Структура: группировки «Подразделение» и «Сотрудник»; вариант 1 — **вложенные**, вариант 2 (**предпочтительнее**) — **одна составная группировка «Подразделение, Сотрудник»** (расположение полей группировок — «отдельно и только в итогах»; допускается дублирование названия подразделения в строках). Составная проще и безопаснее: итоги по подразделению не надо отключать.
- **Выбранные поля**: порядок — отработано часов, оклад, процент надбавки, надбавка, итого. Чтобы над полями появился общий заголовок, **сгруппировать выбранные поля** и дать группе заголовок: **«Начислено по окладу»** (отработано + сумма) и **«Начислено от продаж»** (процент + сумма); заголовки полей: «Отработано часов», «Сумма», «Процент надбавки», «Сумма», «Итого: сумма».
- Если нужна точная «фотография» образца (над «отработано часов» — своя группа, «Сумма» — в группе с пустым заголовком): создавать группы с заголовком **пробелом**; **у разных групп с одинаковым заголовком система склеивает их** — поэтому для второй пустой группы ставить **два пробела**. На экзамене **не делать** — «ничего не снизят».
- **Условное оформление:** ширина колонок 15 символов (сотрудник/подразделение) и 10 для чисел; **заголовок полей — полужирный, по центру**; область — «заголовок полей» (не везде).
- **Заголовок «Месяц: …»:** группировка «Заголовок» (детальные записи, имя «Заголовок»), **вариант использования — «Дополнительная информация»**, макет группировки «Месяц: [ПериодРегистрации]», формат `ММММ гггг "г."` (4 буквы «М», 4 «г»), ячейку убрать **цветом рамки и фоном формы** (быстрее, чем отключать макет оформления).

## Пустая строка (билет 5)
- Подчинить группировку «Подразделение…» заголовку → пропадают суммы → в настройках снять **«Авто-позиция ресурсов» → «Не использовать»**.
- Побочный эффект: при **вложенных группировках** ресурсы выводятся «в середине» — поле «Сотрудник» уезжает в конец (авто-поле: подразделение, затем все ресурсы, затем сотрудник). Ремонт: вернуть **«авто»-поля**, в отдельной колонке для всех полей; **не трогать авто-поля без необходимости**.
- **Итог:** включить **расположение общих итогов по вертикали — «Конец»** в **ближайшей к заголовку группировке** (не «детальные записи»); размер итога становится нормальным.
- Итоги по подразделению отключаются на закладке **«Ресурсы»**: для каждого ресурса указать группировки, по которым считать (только «Сотрудник» и общий итог). Проверять с несколькими подразделениями (Бердыев работает ещё и в «Внедрении»).
- Сортировка явно не нужна — отчёт сортируется по полям группировок.
- **Вывод:** составная группировка — «и ошибкой это не будет», и итогами возиться не надо; вложенная — «познавательно, но сложнее».
