# Урок 32. Отчёт по взаиморасчётам по проектам. Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=JgR-qvp6mso · 37 мин · [полный текст](../transcripts/032_JgR-qvp6mso.md)

## О чём урок
Отчёт «Состояние взаиморасчётов» (по задаче урока 31) с **динамическими колонками**: **таблица СКД** (контрагенты в строках, проекты в колонках). Основа — решение урока 31.

## Образец отчёта
Контрагенты в строках, проекты — в колонках (их количество не ограничено); на пересечении — сумма в рублях над суммой в валюте (в рублёвых проектах и в авансах валютной суммы нет). Авансы выводятся **последним столбцом**, положительным знаком.

## Построение
1. Отчёт «СостояниеВзаиморасчётов» (подсистема «Оперативный учёт»), запрос к `Взаиморасчеты.Остатки` — контрагент, проект, валюта, сумма в валюте, сумма в рублях.
2. Параметр «Период» (параметр остатков «Период»; использование всегда; по умолчанию «Начало завтрашнего дня» — остатки на текущую дату).
3. **Структура — «Таблица»** (новая группировка типа «таблица»): в **строках** — «Контрагент», в **колонках** — «Проект». В ресурсах — **нужны** (в отличие от прежних отчётов): без ресурсов числа на пересечении строк и колонок не выводятся. Ресурсы: «Сумма в валюте», «Сумма в рублях» (кнопка «>>»).
4. Итоги: по горизонтали и вертикали отключить (расположение общих итогов — «Нет»). Вывод параметров — «Не выводить».
5. **Две суммы друг под другом:** в «Выбранных полях» сгруппировать «Сумма в рублях» и «Сумма в валюте» (группа с расположением «Вертикально»).
6. Условное оформление: влево, формат 0 знаков, отступ 1 символ; **минимальная ширина колонки** (12 символов, 15 — слишком много). Условное оформление нужно **ограничивать группировкой** (область использования), иначе оно перебивает макеты (формат даты в заголовке не применился).

## Порядок проектов: аванс последним
- В запросе поле порядка использовать нельзя: при сортировке по нему СКД требует добавить это поле в группировку «Проект». Решение — **вычисляемое поле «ПорядокПоПроекту»**: `ВЫБОР КОГДА Проект = ЗНАЧЕНИЕ(Справочник.Проекты.ПустаяСсылка) ТОГДА 1 ИНАЧЕ 0 КОНЕЦ`.
- Поле в «ограничении» (доступно только для упорядочивания): снять флажки «Выбор»/«Условие»/«Группировка», оставив «Упорядочивание».
- Сортировка в группировке «Проект»: сначала «ПорядокПоПроекту», затем «Авто» (проект). Так аванс выводится последним.
- Выражение `ВЫБОР` в запросе не вредит производительности (медленная операция — чтение данных, а не вычисление условия).

## Заголовки колонок
- Заголовок группировки «Контрагент» — макет заголовка группировки (ячейка «Контрагент / Проект», жирный, по центру).
- Заголовок колонки проекта выводится **макетом группировки** (не заголовка) для группировки «Проект» (иначе содержимое окажется не в той ячейке): в ячейке — название проекта, ниже — «Руб. / Вал.» (**две строки**: проект над подзаголовком).
- Выражения для ячеек макета:
  - Проект: `ВЫБОР КОГДА Проект = ЗНАЧЕНИЕ(Справочник.Проекты.ПустаяСсылка) ТОГДА "Аванс" ИНАЧЕ ПРЕДСТАВЛЕНИЕ(Проект) КОНЕЦ` (в выражении СКД слово в кавычках записывается удвоенными кавычками);
  - Валюта: `ВЫБОР КОГДА Валюта = Рубль ТОГДА "руб." ИНАЧЕ "руб. / " + Валюта.КраткоеНаименование КОНЕЦ`.
- **Валюту нужно добавить в группировку «Проект»** (иначе система не знает, откуда её взять — ошибка «валюта не используется в группировке»).
- В справочник «Валюты» добавлен реквизит **«КраткоеНаименование»** (строка 5, проверка заполнения): вывод «EUR», «USD». Либо просто переименовать валюты.
- Параметры макета в этом случае нужно заполнить в СКД (иначе — синтаксическая ошибка: «параметр не заполнен»). Это были ошибки автора при подготовке.

## Суммы в наборе данных
Знак аванса и валютных сумм меняются в запросе, потому что в макете (в отличие от заголовков) значения не преобразуются:
- `СуммаВВалютеОстаток`: `ВЫБОР КОГДА Валюта = Рубль ТОГДА 0 ИНАЧЕ СуммаВВалютеОстаток КОНЕЦ` (в рублёвом проекте и в авансе валютной суммы нет);
- `СуммаВРубляхОстаток` для авансов: `ВЫБОР КОГДА Проект = Пусто ТОГДА -СуммаВРубляхОстаток ИНАЧЕ СуммаВРубляхОстаток КОНЕЦ` (аванс отображается положительным).
Получение наименования/краткого наименования валюты через точку в запросе не снижает оценку (в любом случае соединение с валютой явное или неявное, число обращений к БД не меняется). Для проекта в макете оставляют ссылку, а слово «Аванс» выводят в макете (чтобы в колонке не смешивались значения разных типов).

## Заголовок отчёта
Макет «Заголовок» (детальные записи, «Дополнительная информация»): «Состояние взаиморасчётов на [Период]» (формат даты). Выражение условного оформления перекрывает формат даты в макете — формат лучше задавать только в макете. Пустую строку убирают подчинением таблицы заголовку; тогда у таблицы нужно включить «Макет оформления», у заголовка — выключить.
