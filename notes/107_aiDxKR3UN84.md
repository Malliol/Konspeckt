# Урок 107. Премия начальнику бригады: максимум надбавки без измерения «Подразделение» (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=aiDxKR3UN84 · ~25 мин · [полный текст](../transcripts/107_aiDxKR3UN84.md)

## О чём урок
**Билет № 13** («бригады»). Большая часть заготовлена автором (оплата по ставке из документа, надбавка по продажам — см. урок 84/75; отчёт по надбавкам); **тема урока — премия начальнику бригады**: процент от **максимальной надбавки сотрудника бригады**.

## Условие
- **Бригада = подразделение** (не создавать справочник «Бригады»; «недаром бригада упоминается в контексте совместительства»); **совместительство не допускается** (нет измерения «Подразделение» в регистре расчёта); все — по пятидневке (график не нужен).
- **Оплата по часовому тарифу — ставка из документа** (параметр, не из регистра).
- **Надбавка** = общая сумма продаж за **предыдущий квартал** по бригаде × процент (процент — в документе): расходная накладная с полем «Подразделение»; продажи — регистр накопления (если уже есть регистр бухгалтерии — использовать его; в билетах задачи «склеиваются», нужно творчески подстраиваться). **Квартал:** `КонецПредыдущегоКвартала = НачалоКвартала(ПериодРегистрации) − 1 секунда`, `НачалоПредыдущегоКвартала = НачалоКвартала(КонецПредыдущегоКвартала)`.
- **Начальнику бригады выплачивается премия в виде процента от надбавки того сотрудника бригады, который получил максимальную сумму надбавки; процент вводится в документе (параметр).**

## Конфигурация
- Вид расчёта **«ПремияНачальникуБригады»** в «ДополнительныхНачислениях»; **база не настраивается** (в конфигурации урока убрали зависимость от базы и «Базовый период» — **не используем виртуальную таблицу «База»**, потому что подразделение не измерение).
- Подчинённость: «начальник бригады» — **тот, кому в ТЧ назначена премия**; бригада — **подразделение строки**; сотрудники бригады — все остальные в этом подразделении.
- Возможный вопрос: входит ли надбавка самого начальника в максимум? Автор: **не входит** (читаем «сотрудники своей бригады» как «подчинённые»); альтернатива — входит (в билете неясно) → **пояснительная записка**.

## Почему не разрезы
Популярное решение (Прохоров): `База(&Измерения = подразделение, &Разрезы = сотрудник)` (урок 79). Но подразделение — **измерение** только при совместительстве; здесь совместительство **не допускается** → «читерство», если ради этого добавлять измерение (Юрий Зайцев: «−2 балла за получение базы через основную таблицу vs −0,5 за лишнее измерение»; автор: «решение, которое ничего не нарушает, должно быть; без пояснительной записки не обойтись»). ## Запрос (расчёт премии начальнику)
1. `ВТ_Данные` ← допначисления по документу: `Регистратор = &Ссылка`, `ВидРасчета В (&ВидыРасчета)` (премия): `НомерСтроки`, `Сотрудник` (начальник), `Подразделение` (**«Подразделение» — реквизит регистра расчёта, хранится в движении**), индекс по подразделению.
2. `ВТ_БазаНачислений` ← та же таблица `РегистрРасчета.ДополнительныеНачисления`: **`ПериодРегистрации = &ПериодРегистрации`** (а не регистратор — «надбавки могли быть посчитаны другими документами за тот же месяц»), `ВидРасчета = &Надбавка`, **`Активность = ИСТИНА`** (при получении базы активность учитывается — как у платформы): `Сотрудник`, `Подразделение`, `Результат` (надбавка); индекс по подразделению.
3. Основная таблица `ВТ_Данные` **ЛЕВОЕ соединение** с `ВТ_БазаНачислений` по подразделению **с условием `БазаНачислений.Сотрудник <> Данные.Сотрудник`** (исключаем надбавку начальника); группировка по `НомерСтроки`, **`МАКСИМУМ(Результат)`** → «БазаНачислений» (`ЕСТЬNULL`). (В примере: 50 тыс — Бердыев, 100 тыс — Жупиков, 150 тыс — Иванов (с учётом/без начальника) → без начальника 100 тыс.)
4. Расчёт: `Результат = БазаНачислений * Движение.Параметр / 100` (**по параметру процента**, не по выборке); `ЗаполнитьЗначенияСвойств(Движение, Выборка, "БазаНачислений")` (реквизит «БазаНачислений» 10/2).
- **Порядок:** премия считается **после надбавок** (надбавки входят в базу) — отдельный блок/цикл после расчёта допначислений «Надбавка».
- Параметры: `ВидыРасчета = {ПремияНачальнику}` (общая схема — массив), `Выборка.Сбросить(); Выборка.НайтиСледующий(...)` + `Если Движение.ВидРасчета = ПремияНачальнику Тогда …`; запись `Записать()` без «Истина» (нет периода действия).
- Ошибка в видео — деление на «10 вместо 100» (на проверке получилось 500 000 вместо 50 000).

## Прочее и дискуссия
- Измерения создаются «когда нужно для отчёта или получения базы» (замечание зрителя) — автор: если условие явно запрещает совместительство, подразделение — реквизит, **без пояснительной записки не обойтись**.
- Голосование зрителей: «как лучше — добавить измерение подразделения или как показал» — большинство за способ без измерения.
- «Слушайте своё сердце» — в неоднозначных формулировках.
