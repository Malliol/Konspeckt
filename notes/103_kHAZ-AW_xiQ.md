# Урок 103. Учёт невыходов (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=kHAZ-AW_xiQ · ~15 мин · [полный текст](../transcripts/103_kHAZ-AW_xiQ.md)

## О чём урок
**Билет № 10**, условие о невыходах: **«Невыход на работу без уважительной причины должен быть зафиксирован в информационной базе, но не оплачивается; он может вводиться задним числом»**. Автор: «невыход — это больничный, который не нужно рассчитывать». Оставшаяся часть билета — «компенсация затрат на обеды» (следующие уроки).

## Условие билета № 10
Метод отклонений; сотрудники могут работать по **разным графикам**; **совместительство допускается**; **оплата по часовому тарифу = ставка × фактически отработанное время**; компенсация затрат на обеды; **невыход**.

## Реализация
- **Вид расчёта «Невыход»** в плане «ОсновныеНачисления» (есть начало и конец; период действия); **вытесняет «Оплату по часовому тарифу»** (закладка «Вытесняющие» у оплаты — отметить «Невыход»); **база не настраивается** (расчёта у невыхода нет); результат не считается — запись «остаётся с нулём».
- **Невыход может вводиться задним числом → сторно:** в подготовке записей (перед записью) получить `ТаблицаДополнения = Движения.ОсновныеНачисления.ПолучитьДополнение();` (записи оплаты предыдущих месяцев, пересекающиеся с невыходом) и для каждой строки создать сторно-запись:
  - **`ЗаполнитьЗначенияСвойств(Движение, Строка, "Сотрудник, Подразделение, ГрафикРаботы, ВидРасчета, ТарифнаяСтавка")`** — **только измерения, график, вид расчёта и тарифная ставка** (параметр, нужный для расчёта сторно по старой ставке) — а не всю строку (ресурсы/результат не копируем);
  - `ПериодРегистрации = Строка.ПериодРегистрацииСторно; ПериодДействияНачало = Строка.ПериодДействияНачалоСторно; ПериодДействияКонец = Строка.ПериодДействияКонецСторно; Сторно = Истина`.
- **Расчёт оплаты:** тарифную ставку брать **из движения для сторно-записей** (на момент расчёта той записи), **для обычных — срезом последних на период регистрации**: в данных графика вытащить `Сторно` и `ТарифнаяСтавка` (из параметра движения); во втором запросе: `ВЫБОР КОГДА Сторно ТОГДА ТарифнаяСтавка ИНАЧЕ ЕСТЬNULL(Срез.ТарифнаяСтавка, 0) КОНЕЦ`; `ЕСТЬNULL` из данных графика для ставки уже не нужен. В расчёте результата — **`?(Движение.Сторно, -1, 1)`** умножение: «умножать надо именно на `?(…, -1, 1)` — иначе не взлетает».
- **Флажок «Базовый» у измерений** при получении базы (даже в билетах без базы по основному регистру — по допначислениям базу придётся получать): забыл → могут снижать оценку («не забывайте!»).

## Проверка
- Бердыев: в сентябре (ставка 1 000) — 176 000; с 1 октября ставка 10 000 (подразделение бухгалтерия); **невыход 5–10 октября, введённый в октябре**: сторно по **старой** ставке (1 000) и оплата по новой (10 000); вытеснение — оплата 168 часов уменьшилась до 96 (невыход 5–15).
- «Невыход нужно фиксировать в текущем месяце, чтобы увидеть уменьшение зарплаты».
