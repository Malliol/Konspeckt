# Урок 72. Сторнирование записей (СПР). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=mR1W_cuqars · 23 мин · [полный текст](../transcripts/072_mR1W_cuqars.md)

## О чём урок
Билет № 3, фраза условия: **«данные о командировке могут вводиться задним числом»**. Решение — **сторнирование** оклада за период, на который «ложится» командировка.

## Проблема
Командировка (август), введённая на даты июля, не вытесняет оклад, рассчитанный за июль (период регистрации июль): **вытеснять можно только записи с тем же или более поздним периодом регистрации**. Зарплата за июль уже посчитана и, вероятно, выплачена — бесконтрольное вытеснение задним числом запрещено платформой. Итог: у командировки отработано часов = 0, результат нулевой.

## Решение: стороно-записи
1. В обработке проведения после записи основных начислений получить дополнение: `Движения.ОсновныеНачисления.ПолучитьДополнение()` (таблица значений — записи, которые мешают командировке; например, оклад с 1 по 28 июля).
2. В таблице три важных поля: **`ПериодРегистрацииСторно`, `ПериодДействияНачалоСторно`, `ПериодДействияКонецСторно`** — подсказка, что указать в сторно-записях: **период регистрации — текущий (август)**, период действия — **именно мешающий отрезок** (5–10 июля).
3. Цикл:
```bsl
Для Каждого Строка Из Таблица Цикл
    Движение = Движения.ОсновныеНачисления.Добавить();
    ЗаполнитьЗначенияСвойств(Движение, Строка);   // копируем мешающую запись целиком
    Движение.Сторно = Истина;                      // признак сторно
    Движение.ПериодРегистрации      = Строка.ПериодРегистрацииСторно;
    Движение.ПериодДействияНачало   = Строка.ПериодДействияНачалоСторно;
    Движение.ПериодДействияКонец    = Строка.ПериодДействияКонецСторно;
КонецЦикла;
```
Отменяется не весь оклад, а только мешающая часть.
4. После этого командировка ложится и считается.

## Знак минус
Флажок «Сторно» сам сумму не вычитает — **результат нужно умножить на −1**: `Если Движение.Сторно Тогда Движение.Результат = -Движение.Результат`. Делать **вне условия по виду расчёта** (на будущее для всех видов; оптимизаторы могут вынести под оклад). Аналогично **минусовать ресурсы**, влияющие на базу: **«ОтработаноЧасов» (и прочие ресурсы) для сторно тоже со знаком минус** (замечание зрителя — легко упустить).

## Открытый вопрос
Сторно оклада должно идти по **старому значению оклада**, а не по тому, что на начало текущего периода (если оклад менялся). Белоусов записывает оклад в **реквизит регистра расчёта** в момент подготовки записей. Автор оставил решение на следующий урок (73).
