# Урок 106. Расчёт зарплаты в нескольких валютах (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=xkbTVHNBWUw · ~20 мин · [полный текст](../transcripts/106_xkbTVHNBWUw.md)

## О чём урок
Билет № 8, последнее условие: **«Зарплата начисляется в двух валютах — долларах и евро»** (раньше в билете: «в рублях и долларах»). **Фиксированное число валют → отдельный ресурс на каждую валюту**; если «в произвольной валюте/произвольном количестве» — схема сложнее (в билетах не встречается).

## Структура
- В регистрах расчёта (**основные и дополнительные**): вместо ресурса «Результат» — **два ресурса: «РезультатВДолларах» (синоним «Результат USD») и «РезультатВЕвро» (синоним «Результат EUR»)**; точность — как у «Результата» (10/2). Размер ставки в билете «12,5» — «явно не рубли»; решаем, что это **доллары** (оплата по тарифу — «результат в долларах»); в евро — конвертация.
- Все прежние расчёты **результат → «РезультатВДолларах»**; в запросе базы поле называется **`РезультатВДолларахБаза`** (ресурс + «База»).
- Билет также пропустил: **в базу для сверхурочных входит и сама сверхурочная работа** — у вида «Сверхурочные» (закладка «Базовые») отметить и «Сверхурочные» (в уроке 105 только оплата) — «все начисления за период» (оклад, отпуск, командировка, сверхурочные…).

## Курсы валют
- Справочник «Валюты» → **предопределённые элементы «ДолларСША» и «Евро»** (код: любой, на экзамене на него не смотрят: «843» / «978»); удалить созданные вручную (принудительное удаление); регистр сведений «КурсыВалют» (каркас; периодичность — день): доллар — 50, евро — 75; **курс доллара / курс евро = коэффициент конвертации** (меньше единицы: 100 долл. = меньше 100 евро; 300 USD × 50/75 = 200 EUR).

## Запрос курсов (одна строка)
Получить оба курса **в одной строке** (можно двумя запросами/двумя строками — «читабельно, но на экзамене жертвуем читабельностью в пользу эффективности»):
```bsl
ВЫБРАТЬ ЕСТЬNULL(СУММА(Т.КурсДоллара), 0) КАК КурсДоллара, ЕСТЬNULL(СУММА(Т.КурсЕвро), 0) КАК КурсЕвро ИЗ (
    ВЫБРАТЬ Курс КАК КурсДоллара, 0 КАК КурсЕвро ИЗ РегистрСведений.КурсыВалют.СрезПоследних(&ПериодРегистрации, Валюта = &Доллар)
    ОБЪЕДИНИТЬ ВСЕ
    ВЫБРАТЬ 0, Курс ИЗ РегистрСведений.КурсыВалют.СрезПоследних(&ПериодРегистрации, Валюта = &Евро)
) КАК Т
```
- Вложенные запросы удобно делать «ВЫБРАТЬ * ИЗ (…) КАК Т» — иначе конструктор не открывается.
- **`ЕСТЬNULL` — вокруг `СУММА`, а не внутри** (суммирование нулей/NULL при отсутствии среза возвращает NULL); без этого строка с NULL. При отсутствии курсов запрос всё равно возвращает **одну строку с нулями** — поэтому **`Если Выборка.Следующий()` не нужен**: строка есть всегда.
- Проверка: `Если Выборка.КурсДоллара = 0 Тогда Сообщить("Не задан курс доллара"); Отказ = Истина; Возврат; КонецЕсли;` — аналогично для евро.

## Расчёт
`КоэффициентКонвертации = Выборка.КурсДоллара / Выборка.КурсЕвро` (параметр расчёта в регистре — реквизит «КоэффициентКонвертации», 10/**больше знаков**, не округлять, 10/6 лучше); **`Движение.РезультатВЕвро = Движение.РезультатВДолларах * КоэффициентКонвертации`** — выполнять **после** расчёта результата в долларах (в тех же циклах расчёта оклада/допначислений: основные и дополнительные). Если валюта «рубль/доллар» — просто курс доллара срезом (можно через объектную модель — «не обязательно мутить запросы»).
- Результат: 300 USD → 200 EUR (курс 50/75).
- В запросе базы — только долларовое поле; в отчётах — две колонки.
