# Урок 98. Разбивка интервала больничного по месяцам (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=Aw6nZlomhqI · ~25 мин · [полный текст](../transcripts/098_Aw6nZlomhqI.md)

## О чём урок
Начало билета № 9 (по словам автора — «всего в одной задаче встречается»): **«больничный можно вводить интервалом, захватывающим несколько месяцев»**; а платформа не позволяет записывать в регистр расчёта запись с периодом действия, лежащим в разных месяцах («неверно заданный период действия»). Нужно **при проведении разбить такую строку на несколько записей по месяцам**.

## Условие (смысл)
- Вид расчёта **«Больничный»** — в плане «ОсновныеНачисления» (есть начало и конец, период действия).
- **Оклад вводится в пределах месяца** (если пользователь ввёл иначе — «пользователь идиот»), а **больничный — допускается вводить с переходом месяцев** (с 15 августа по 10 октября) → разбить на сегменты по месяцам: 15.08–31.08, 01.09–30.09, 01.10–10.10.
- Платформа проверяет, что период действия записи — в пределах одного месяца периода регистрации (ошибка «неверно заданный период действия»).

## Подготовка записей запросом
Вместо цикла по ТЧ — **запрос** (язык запросов считает «лишние месяцы»), затем цикл по выборке:
```bsl
ВЫБРАТЬ
    ТЧ.Сотрудник, ТЧ.Подразделение, ТЧ.ГрафикРаботы, ТЧ.ВидРасчета,
    ТЧ.ДатаНачала КАК ПериодДействияНачало,
    КОНЕЦПЕРИОДА(ТЧ.ДатаОкончания, ДЕНЬ) КАК ПериодДействияКонец,
    РАЗНОСТЬДАТ(НАЧАЛОПЕРИОДА(ТЧ.ДатаНачала, МЕСЯЦ), НАЧАЛОПЕРИОДА(ТЧ.ДатаОкончания, МЕСЯЦ), МЕСЯЦ) КАК КоличествоЛишнихМесяцев
ИЗ Документ.НачислениеЗарплаты.ОсновныеНачисления КАК ТЧ ГДЕ ТЧ.Ссылка = &Ссылка
```
- **`РАЗНОСТЬДАТ(Меньшая, Большая, МЕСЯЦ)`** — первой — меньшая дата; **считать от начала месяцев** (от `НАЧАЛОПЕРИОДА`), иначе 31.08→01.10 даст неверно. Оклад (в одном месяце): 0; сентябрь→октябрь: 1; август→октябрь: 2. «Всё работает» (проверка в консоли).
- Период регистрации — параметром `&ПериодРегистрации` (обращение через ссылку создало бы лишнее левое соединение — «сомнительный ход»).
- Длина строк кода — **не более 120 символов** (стандарт; с переносами в 1С бывают проблемы форматирования).

## Цикл разбивки
```bsl
Пока Выборка.Следующий() Цикл
    Если Выборка.ВидРасчета = Больничный И Выборка.КоличествоЛишнихМесяцев > 0 Тогда
        Для НомерИтерации = 0 По Выборка.КоличествоЛишнихМесяцев Цикл
            МесяцНачала = ДобавитьМесяц(НачалоМесяца(Выборка.ПериодДействияНачало), НомерИтерации);
            МесяцКонца  = КонецМесяца(МесяцНачала);
            Движение = Движения.ОсновныеНачисления.Добавить();
            ЗаполнитьЗначенияСвойств(Движение, Выборка);
            Движение.ПериодРегистрации    = ПериодРегистрации;
            Движение.ПериодДействияНачало = Макс(МесяцНачала, Выборка.ПериодДействияНачало);
            Движение.ПериодДействияКонец  = Мин(МесяцКонца,  Выборка.ПериодДействияКонец);
        КонецЦикла;
    Иначе
        Движение = Движения.ОсновныеНачисления.Добавить();
        ЗаполнитьЗначенияСвойств(Движение, Выборка);
        Движение.ПериодРегистрации = ПериодРегистрации;
    КонецЕсли;
КонецЦикла;
Движения.ОсновныеНачисления.Записать();
```
- Алгоритм: для каждой итерации — граница месяца (начало = начало месяца первой даты + номер итерации, конец = конец месяца); **начало сегмента = МАКС(начало месяца, начало интервала), конец сегмента = МИН(конец месяца, конец интервала)** — для 15.08–10.10: 15.08–31.08; 01.09–30.09; 01.10–10.10.
- Подготовка записей остаётся «подготовкой» — результат не заполняется.
- Тест: Бердыев: оклад с 1 по 31 октября (без разбивки), больничный с 15 августа по 10 октября → три записи.
