# Урок 90. Билет № 16: оклад из документа и фиксированная сумма (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=pfUtdImaCgs · ~35 мин · [полный текст](../transcripts/090_pfUtdImaCgs.md)

## О чём урок
Начало **билета № 16** (по словам автора — был на его экзамене): оклад (с первоначальным значением оклада, вводимым **в документе**) + **фиксированная сумма за каждый отработанный день** (компенсация за мобильный телефон). Заготовка — выгрузка 66.

## Условие
- Метод отклонений; **совместительство допускается**; все сотрудники по пятидневке, **но надо предусмотреть возможность работы по различным графикам** (поэтому график — реквизит регистра расчёта; регистр «ГрафикРаботы» — как в базе).
- Оплата по окладу — **пропорционально отработанному времени в часах**; **первоначальное значение оклада вводится в документе** «НачислениеЗарплаты» (не из регистра сведений).
- **За каждый отработанный день в течение периода начисления сотрудникам полагается фиксированная сумма денег (компенсация за мобильную связь)**; **ставка едина для всех сотрудников и должна быть зафиксирована в базе** → регистр сведений.

## Оклад
- Документ: в табличную часть «ОсновныеНачисления» добавить реквизит **«Параметр»** (число 10/2; безликое название — «в плане расчёта потом появятся другие виды, а оклад — только один из них»; проверку заполнения не включать — для одних видов расчёта параметр нужен, для других нет).
- Регистр расчёта «ОсновныеНачисления»: реквизиты «Параметр» (10/2), «НормоЧасов» (5/2), «ОтработаноЧасов» (5/2).
- Подготовка (как всегда): период регистрации, цикл, `ПериодДействияНачало = Строка.Дата…`, **`ПериодДействияКонец = КонецДня(...)`** (не «конец месяца»), `Записать()`.
- Запрос: `ДанныеГрафика(Регистратор = &Ссылка, ВидРасчета В (&ВидыРасчета))`: `НомерСтроки`, `ЕСТЬNULL(ЗначениеЧасовФактическийПериодДействия, 0)` → «ОтработаноЧасов», `ЕСТЬNULL(ЗначениеЧасовПериодДействия, 0)` → «НормоЧасов». **Первоначальный оклад не вытаскивать запросом — взять из `Движение.Параметр`.**
- Цикл: `Если ВидыРасчета.Найти(Движение.ВидРасчета) = Неопределено Тогда Продолжить; Выборка.Сбросить(); Выборка.НайтиСледующий(...)`; `Если Движение.ВидРасчета = Оклад Тогда Результат = ?(Выборка.НормоЧасов <> 0, Движение.Параметр / Выборка.НормоЧасов * Выборка.ОтработаноЧасов, 0);` **проверка деления на ноль обязательна** (график может быть не заполнен; автор забыл её на экзамене — возможная причина «4»); `ЗаполнитьЗначенияСвойств(Движение, Выборка, "НормоЧасов, ОтработаноЧасов")`; запись **`Записать(, Истина)`**. Тест: параметр 250 000 → Бердыев.
- Знак **`?(Условие, Если Истина, Если Ложь)`** — тернарный оператор («лаконичнее громоздкого `Если`»).

## Фиксированная сумма: структура
- **Ставка компенсации** — регистр сведений «ПоказателиРасчётаЗарплаты» (периодичность — месяц, ресурс «СтавкаКомпенсации» 10/2, неотрицательный, «Выдавать ошибку»); экзаменатор считает уместными и константу.
- **Вид расчёта «КомпенсацияЗаМобильный»** — **в «ДополнительныхНачислениях»**, а не в основных: **у компенсации нет собственных дат** — она берёт информацию об отработанных днях **из оклада**; период действия — нет; **зависимость от базы по периоду действия, базовый вид — «Оклад» из «ОсновныхНачислений»**.
- Нужна **база по отработанным дням**, а база считается только по **ресурсу** → в регистр расчёта «ОсновныеНачисления» добавить **ресурс «ОтработаноДней» (5/2)**; для заполнения — **добавить ресурс «Дней» в регистр графика**: «Часов» = 8, «Дней» = 1 в рабочий день, 0 — в выходной (в обработке заполнения графика: две строки записи — часы и дни); график заполнить на год, выходные «67» без запятой (совет зрителя).
- В запросе оклада: **`ЕСТЬNULL(ЗначениеДнейФактическийПериодДействия, 0)` → «ОтработаноДней»**; в цикле оклада: `ЗаполнитьЗначенияСвойств` получает и дни (ресурс копируется в движение).
- Регистр расчёта «ДополнительныеНачисления»: измерения «Сотрудник», «Подразделение»; **включить «Базовый период»**; реквизиты «СтавкаКомпенсации», «ОтработаноДней» (5/2); график, параметр, нормо-часы, отработано часов — не нужны; в подсистему, регистратор «НачислениеЗарплаты»; у измерений — флажок «Базовый» (в обоих регистрах).
- Документ: табличная часть «ДополнительныеНачисления» (сотрудник, подразделение, вид расчёта — тип «ДополнительныеНачисления»; без дат, графика); **убрать «Выдавать ошибку» с обеих таблиц; пустой документ — в `ОбработкаПроверкиЗаполнения`: `Если ОсновныеНачисления.Количество() = 0 И ДополнительныеНачисления.Количество() = 0 Тогда Сообщить(...); Отказ = Истина`** (замечание зрителя: условие «И», а не «ИЛИ» — документ с одной заполненной частью допустим).

## Расчёт компенсации
- Подготовка: цикл по ДополнительныеНачисления: `ЗаполнитьЗначенияСвойств`, `ПериодРегистрации`, **`БазовыйПериодНачало = ПериодРегистрации`, `БазовыйПериодКонец = КонецМесяца(ПериодРегистрации)`** (период расчёта = текущий месяц — база за тот же расчётный период), `Записать()`.
- Запрос: `ДополнительныеНачисления` (основная таблица, **`Регистратор = &Ссылка`, `ВидРасчета В (&ВидыРасчета)`**) **ЛЕВОЕ соединение** с `РегистрРасчета.ДополнительныеНачисления.База(&Измерения, , , Регистратор = &Ссылка И ВидРасчета В (&ВидыРасчета))` по `НомерСтроки` (**соединение обязательно** — иначе показатели не заполнятся; зритель Юрий Зайцев поймал забытое соединение), **`ЕСТЬNULL(ОтработаноДнейБаза, 0)`**; срез последних «ПоказателиРасчётаЗарплаты» на `&ПериодРегистрации` (соединение `ИСТИНА`, `ЕСТЬNULL(СтавкаКомпенсации, 0)`). Параметры: `Измерения` — массив из **«Сотрудник» и «Подразделение»** (два измерения: база по сотруднику в подразделении); `ВидыРасчета` — массив.
- Цикл: `Результат = Выборка.СтавкаКомпенсации * Выборка.ОтработаноДней`; `ЗаполнитьЗначенияСвойств(Движение, Выборка, "СтавкаКомпенсации, ОтработаноДней")`; запись **без «Истина»** (периода действия нет).
- Пример: ставка 100 ₽/день; сотрудники с 17 и 20 днями → 1 700 и 2 000.

## Диагностика (на экзамене — «прикольная ошибка 1С»)
При несовпадении настроек (в регистре расчёта **включён «Базовый период»**, а в плане видов расчёта **снят «Зависимость от базы»**) платформа выдаёт странную ошибку «В таблице ... нет вложенной таблицы...» (виртуальная таблица «База» не определена) — **это не глюк платформы**: вернуть настройку. И самое важное: если ставка/дни = 0, смотреть реквизиты движения — видно, какой показатель не подтянулся (поэтому реквизиты-показатели нужны — «удобно анализировать проблемы расчёта»).
Если не указан базовый вид расчёта — отработанные дни нулевые.

## Прочее
- В 16-м билете вторая половина — самая сложная в «жизни» (следующий стрим); автор рекомендует морально подготовиться.
- «Допуск к сдаче спеца» по «джуниору» не требуется (вопрос зрителя).
- Сюжет «Бердыев — Васина — Вагина» — шутки автора.
- Выгрузка: октябрьские документы; считаем за октябрь (не августа).
