# Урок 33. Измерение «Валюта» в регистре взаиморасчётов. Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=hOrlLVuILKQ · 34 мин · [полный текст](../transcripts/033_hOrlLVuILKQ.md)

## О чём урок
Дискуссионное занятие без новой задачи: (1) как правильно назвать общий модуль и функцию (стандарты 1С), (2) нужно ли измерение «Валюта» в регистре взаиморасчётов, и как его защитить от смены валюты в проекте. База — выгрузка урока 28/31.

## Имена общих модулей и функций
- Зритель заметил: модуль «ПриФиксацииОбъектов» с функцией «НомерНаПечать» (удаление ведущих нулей) назван неудачно: в нём нет работы с префиксами; такое имя из типовой конфигурации (УТ: «ПрефиксацияОбъектовКлиентСервер») вызывает у экзаменатора подозрения «решение где-то уже видели». **Не списывать бездумно**: имена должны быть осмысленными, своими.
- Переименовано: модуль **«РаботаСоСтроками»** (одна функция удаления нулей; варианты «ОбщегоНазначения» и т. п. допустимы), функция **«УдалитьВедущиеНулиИзСтроки»** (типовая — «УбратьВедущиеНули»).
- **Правила (Система стандартов и методик разработки)** для общих модулей — четыре контекста выполнения: 1) серверный; 2) серверный для вызова с клиента; 3) клиентский; 4) клиент-серверный. Комбинация флажков — по контексту. Модуль работы со строками, нужный и на клиенте, и на сервере, — **клиент-серверный** (флажки «Клиент (управляемое приложение)» и «Сервер»; «Вызов сервера» не нужен). Имя модуля с суффиксом: «РаботаСоСтрокамиКлиентСервер», «ОбщегоНазначенияВызовСервера» (серверный для вызова с клиента: флажки «Сервер» и «Вызов сервера»).
- **Имена функций:** в общем случае образуются от описания возвращаемого значения («ПолноеИмяПользователя», а не «ПолучитьПолноеИмяПользователя»); глагол в неопределённой форме допустим, когда важно, как получено значение («УдалитьВедущиеНулиИзСтроки»; либо «СтрокаБезВедущихНулей»).
- Параметры именуют по смыслу; называть параметр «Строка» допустимо (примеры есть в типовых). Параметр передают по значению (`Знач`).

## Валюта в регистре взаиморасчётов: аргументы автора
В проекте валюта задана, но в регистр взаиморасчётов добавлено **измерение «Валюта»**. Причины:
1. **Наглядность и скорость:** сразу видно, в какой валюте сумма; не нужно соединяться с проектом.
2. **Аванс** — запись с пустым проектом, и валюту из проекта взять нельзя. «Если проект пуст, валюта — рубль» нужно постоянно помнить — плохо.
3. **Смена валюты в проекте** (в билете запрета нет): без измерения «Валюта» вся история проекта «в долларах» превратится в «в африканских левах»; измерение сохраняет валюту на момент проведения. Но этого мало: при **перепроведении задним числом** документ возьмёт уже новую валюту проекта и сформирует другие движения.

### Полное решение: «зашить» валюту в документ
- Реквизит документа **«Валюта»** (проверка заполнения, «только просмотр» на форме), заполняется при изменении проекта: `Валюта = ОбщегоНазначенияВызовСервера.ВалютаПроекта(Объект.Проект)`.
- Ошибка в уроке: модуль имел флаг «Сервер» без «Вызов сервера», поэтому вызов с клиента не работал. Правильно: общий модуль **«ОбщегоНазначенияВызовСервера»** с флагами «Сервер» и «Вызов сервера».
- В обработке проведения вместо `ВалютаПроекта(Проект)` используется реквизит «Валюта» документа. Теперь смена валюты проекта не влияет на уже введённые документы.

### Когда валюта не нужна измерением
- Валюта берётся из реквизита, который всегда заполнен (например, договор), **и** в условии задачи **запрещено менять валюту** в договоре, если по нему были операции. Тогда измерение «Валюта» не нужно (и его добавление скорее всего приведёт к минус баллу). В типовых так и сделано (нельзя поменять валюту договора, по которому есть операции).

### Запрет смены валюты проекта при наличии операций
Если в условии есть запрет:
1. В `ПередЗаписью` справочника «Проекты»: старая валюта = `ОбщегоНазначенияВызовСервера.ВалютаПроекта(Ссылка)` (запросом, т. к. объект уже изменён); если она `Неопределено` — проект новый, проверка пропускается.
2. Если валюта изменилась — запрос к регистру «Взаиморасчёты» (`ВЫБРАТЬ ПЕРВЫЕ 1 1 ... ГДЕ Проект = &Проект`); если результат не пуст — сообщение «Невозможно изменить валюту проекта, по которому есть движения», `Отказ`.
3. Факультативно: **команда «Движения по проекту»** на форме проекта: параметр команды — ссылка на проект, открывает форму списка регистра с отбором по проекту (`ОткрытьФорму("РегистрНакопления.Взаиморасчеты.ФормаСписка", Новый Структура("Отбор", Новый Структура("Проект", ПараметрКоманды)))`). Чтобы поменять валюту, нужно снять проведение документов.

## Вывод
Измерение «Валюта» нужно в этой задаче; «зашитая» в документе валюта делает решение устойчивым к смене валюты проекта; при требовании запрета менять валюту — проверка в проекте.
