# Урок 122. Просмотр движений документа из форм (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=0gwJxZcAd-E · 11 мин · [полный текст](../transcripts/122_0gwJxZcAd-E.md)

## Условие (билет № 4, часть 1)
Для контроля правильности движений документа «РасходнаяНакладная» создать **управляемые основные формы документа и списка**, чтобы пользователь мог **просматривать движения документа по всем регистрам**, в которые он делает записи. Доступ к данным регистров: **в форме документа — из панели навигации; в форме списка — из командной панели формы**.

## Форма документа
- Автор замечает: можно смотреть движения и в пользовательском режиме (через «Перейти»), но Белоусов всегда выводит их в конфигураторе и ради этого создаёт форму; в этой задаче форму создать **явно просят**.
- В форме документа → закладка **«Командный интерфейс» → «Панель навигации»**: поставить флажки **«Видимость по умолчанию»** у команд регистров, в которые документ пишет (команды появляются автоматически, потому что документ — регистратор). Пользователь может изменить в пользовательском режиме.

## Форма списка
- Закладка **«Команды»**: рядом со «Своими командами» есть **«Стандартные команды»** и **«Глобальные команды»**. 
- Нужны **не** независимые «глобальные» команды (они открывают **весь** список движений регистра, без отбора по документу), а **команды в разделе «Команды параметра»** (параметризуемые): например, «Товары на складах», «Управленческий» (регистр бухгалтерии) — их можно **перетащить в командную панель формы**; они открывают список записей регистра **с автоматическим отбором по регистратору — документу текущей строки списка** (текущая строка — параметр команды).
- Результат: в списке расходных накладных, встав на документ и нажав «Управленческий», пользователь видит движения именно этого документа.
