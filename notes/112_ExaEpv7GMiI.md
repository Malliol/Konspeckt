# Урок 112. Табель на неделю с флажками — завершение СПР (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=ExaEpv7GMiI · ~25 мин · [полный текст](../transcripts/112_ExaEpv7GMiI.md)

## О чём урок
Последний урок по СПР — **билет № 14**: **«особый табель — заполняется еженедельно на весь список сотрудников компании»**; в билете остальное (оклад по рабочим дням, премия) — как в предыдущих. Автор «целиком делать не будет», показывает только особенности табеля.

## Условие и толкование
- Документ **«Табель»**: **заполняется еженедельно на весь список сотрудников компании** → **подразделение — не в шапке, а в табличной части** (совместительство допускается — иначе непонятно, по какому подразделению отработан день; кнопка автозаполнения не нужна). Для каждого сотрудника **каждый отработанный день недели отмечается флажком**.
- **Реквизиты шапки по скриншоту:** **«НачалоПериода»** (дата; «Выдавать ошибку» — день 1 отсчитывается от неё) и **«КонецПериода»** (на скриншоте — «просмотр»): конец = начало + 6 суток; делать реквизитом, если пригодится в отчёте; иначе — только на форме.
- Расчёт оклада — **пропорционально отработанным дням** (рабочие дни), премия — процент от оклада: «только дни, часы не нужны».

## Документ «Табель»
- ТЧ «ДанныеТабеля»: «Сотрудник», «Подразделение» (обе — «Выдавать ошибку»), **7 колонок «День1…День7» — тип «Булево»** (флажки); начало периода не обязано быть понедельником («такого требования нет»).
- Форма: «КонецПериода» — **вычисляется**: при изменении «НачалоПериода» — `Объект.КонецПериода = Объект.НачалоПериода + 6 * 24 * 60 * 60`; при открытии формы (`ПриОткрытии`) — тоже вычислить (клиентская процедура «ЗаполнитьКонецПериода»); поле конца — «только просмотр». Область «Обработчики событий формы/элементов» — как в типовых (удобно ориентироваться).
- **Регистр накопления «ДанныеТабеля»** — «Обороты»: измерения «Сотрудник», «Подразделение»; ресурс **«Дней»** (часы не нужны — «если в задаче только дни, часы в регистр не заводят»); **«ВидыВремени» не нужен** (либо явка есть, либо нет) — **справочник «ВидыВремени» удалить**.

## Проведение
```bsl
Движения.ДанныеТабеля.Записывать = Истина;
Для Каждого Строка Из ДанныеТабеля Цикл
    Для НомерДня = 1 По 7 Цикл
        Если Строка["День" + НомерДня] Тогда                      // булево: ни попыток, ни исключений
            Движение = Движения.ДанныеТабеля.Добавить();
            Движение.Период = НачалоПериода + (НомерДня - 1) * 24 * 60 * 60;
            Движение.Сотрудник     = Строка.Сотрудник;
            Движение.Подразделение = Строка.Подразделение;
            Движение.Дней          = 1;
        КонецЕсли;
    КонецЦикла;
КонецЦикла;
```
- **Расчёт** (на практике проще, чем в 109–111): один запрос — данные явки (оборотами за месяц с периодичностью «день», отбор по сотрудникам/подразделениям, «Дней») — без видов времени, массивов «явки/невыходы»; оклад: `Оклад / НормаДней × ОтработаноДней`; премия — «результат база» (**осторожно: поле называется `РезультатБаза`, а не реквизит «БазаНачислений»**).

## Замечания
- Документ заполняется **вручную** (список сотрудников в шапке не определён — кнопки нет).
- Для оклада по дням — график с «Дней» (см. урок 85/87).
- Конец цикла СПР: с 41-го по 65-й урок — бухгалтерия, **с 66-го — расчётные задачи (СПР)**; «подготовлено 16 билетов».
- Далее — **управляемые формы** (в субботу; маленькие стримы по ~20 минут, «5–6 анонсов в день»), потом бизнес-процессы; цель — закончить цикл «до конца года».
- Яндекс.Диск: документ-соответствие занятий и задач (сделал зритель).
- Выгрузка «после занятия 112».
