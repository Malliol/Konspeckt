# Урок 59. Себестоимость в разрезе партий — без учёта складов (БУ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=ATqdw2haglU · 58 мин · [полный текст](../transcripts/059_ATqdw2haglU.md)

## О чём урок
Бухгалтерская задача № 1 (из урока 43 — ФИФО/ЛИФО, склад — в табличной части прихода) в **новой версии**: **учёт ведётся в разрезе складов и партий, а себестоимость — только в разрезе партий** (без складов). Три способа решения («метод в лоб», **метод лосяша**, **метод буковки**). Плюс дополнение к уроку 58.

## Правило (дополнение к уроку 58)
**«Обороты»** — когда анализируем и дебетовые, и кредитовые обороты счёта; **«ОборотыДтКт»** — когда только дебетовые или только кредитовые. Пример: отчёт «Продажи между организациями» (урок 53) — там интересен **только дебет «Покупателей»** → правильнее **ОборотыДтКт** (исправлено в выгрузке урока 53); единственное место, где «Обороты» были не по адресу, кроме задачи урока 57.

## Условие
- Приход: склад указывается в табличной части; проводки как в уроке 43 (Дт «Товары» — Кт «Поставщики»).
- Расход: склад в шапке; списание **ФИФО/ЛИФО по партиям** (учётная политика на год); **себестоимость товара рассчитывается в разрезе партий поступления** (в билете 1 было «в разрезе складов и партий»).
- Складской учёт сохраняется: контроль остатков **по складу**; проводки как раньше.

## Пример проблемы
Приход № 1 на основной склад (1 апреля), приход № 2 на дополнительный (5 апреля). Продаём 10 шт. **с дополнительного склада**. Раньше подтягивалась партия № 2 (приход на этот склад). Теперь **списывать нужно партию № 1** (ФИФО по партиям поверх складов) — а остаток по складу контролируется отдельно.

## Способ 1 — «метод в лоб» (с отрицательными остатками)
1. План счетов: признак учёта субконто **«Суммовой»** (связан с ресурсом «Сумма»); у «Товаров» — суммовой учёт **по номенклатуре и партиям, не по складам** (количественный — по всем трём).
2. Запрос расходной накладной (старая методика):
   - `ВТ_Товары` ← `Остатки(… Субконто2 = &Склад …)` — **количество остатка на складе** (суммы здесь нет: при отборе по складу суммы пропадают);
   - левое соединение с **`Остатки(…)` по партиям** — **без отбора по складу** (`&ВидыСубконтоПоПартиям` — номенклатура и партии): партия, **количество остатка партии**, **сумма остатка партии**; упорядочить по партии (`МоментВремени`; приведение типа **не писать** — «партия потенциально составной тип»; в записке можно пояснить);
   - итоги по номенклатуре: количество — `МАКСИМУМ`, **количество остатка на складе** — `МАКСИМУМ` (не `СУММА`: на складе одно значение), остатки партии — `СУММА`/детально.
3. Блокировка: **склад не блокировать** (остатки по партиям получают без склада) — блокируются все склады: номенклатура и счёт.
4. Контроль остатков: по `КоличествоОстатокНаСкладе`; списание — по `КоличествоОстатокПартии`/`СуммаОстатокПартии`.
- **Недостаток:** приход делается по основному складу, расход — по дополнительному, а **ресурсы «Количество»/«Сумма» двигаются с разными наборами измерений** → остатки «не выводятся в ноль»: **отрицательный остаток** по партии/складу и ложный положительный; «Михаил Прохоров сдавал так — ничего не снизили», но у зрителя **−2 балла** (преподаватель увидел проблему уже по движениям прихода). Результат — «муть и компот» в регистре.

## Способ 2 — метод лосяша (рекомендован автором)
Идея из чата Прохорова: **два ресурса «Количество»**: «Количество» и **«КоличествоСклад»** (число 10/0, **не балансовый**) — второе заполняется на счетах со складом.
- Признаки учёта: **«Количественный»** (для «Количество») и **«КоличественныйСклад»** (для «КоличествоСклад»); аналогичные **признаки учёта субконто** («Количественный», «КоличественныйСклад», «Суммовой»); ресурсы связать с соответствующими признаками.
- Настройка счёта «Товары»: **по «Номенклатуре»** — суммовой + количественный + количественный склад; **по «Складам»** — **только «КоличественныйСклад»** (количества и суммы по складам для себестоимости нет); **по «Партиям»** — суммовой и количественный (в «КоличествоСклад» — нет).
- Обработки проведения: в приходе и расходе заполнять и `КоличествоДт/Кт`, и **`КоличествоСкладДт/Кт`** (для счёта «Товары»); запрос расходной накладной — **контроль остатка по полю `КоличествоСкладОстаток`** (по складу), себестоимость — по полям партий.
- **Подводный камень:** после изменения плана счетов в пользовательском режиме **флажки пропадают** — субконто «Номенклатура» перестаёт иметь «КоличественныйСклад» (в уроке не заполнялось → «недостаточно товара»): пересоздать субконто счёта в пользовательском режиме и проставить признаки.
- Результат: без отрицательных остатков при приходе на основной склад и расходе с дополнительного: остатки по партиям и по складам положительные.
- Автор называет способ **«наиболее предпочтительным»** (по мнению преподавателя Лосяша, активного в чате Прохорова). Ресурс «КоличествоСклад» пользователь видит в проводках только по «Товарам».

## Способ 3 — метод буковки
**Забалансовый счёт «ТоварыНаСкладах»** (активный; субконто: номенклатура + склады; количественный учёт; не «только обороты» — остатки нужны) — **для контроля остатков по складам**; на счёте «Товары» остаются **номенклатура и партии** (суммовой и количественный учёт; склады убрать из субконто).
- Приход: дополнительно **Дт «ТоварыНаСкладах»** (номенклатура, склад) — **без кредита** (забалансовый счёт — «просто доп. информация») и **без суммы** (иначе получим себестоимость по складам).
- Расход: **Кт «ТоварыНаСкладах»** (номенклатура, склад) вместе со списанием «Товаров».
- Запрос: остатки по складу берутся со счёта «ТоварыНаСкладах» (`Остатки(…, Счет = &ТоварыНаСкладах, &ВидыСубконтоПоСкладам …)`), остатки партий — по счёту «Товары».
- Отчёт для метода буковки сложнее (две таблицы остатков с соединением: сумма на забалансовом счёте не хранится).
- **Аргументы «за» и «против»:** лосяш считает, что на экзамене не примут (приход на два счёта — «странно»); формулировка «учёт товаров в разрезе мест хранения и партий» намекает на **один** счёт «Товары» (но не говорит этого прямо); возражение «в плане счетов создавать нельзя» неверно: в требованиях запрещено **удаление** счетов из плана; Белоусов: «для решения экзаменационных задач счета создавать не надо». Зрители в голосовании: воробей, имя фамилия, Айви Джи, буковка — за метод буковки; категорически против способа 1 (раздувает таблицу итогов). Автор: **безопаснее метод лосяша**; призывает пробовать на экзамене метод буковки и сообщать результат в чате Прохорова.

## Отчёт «Остатки товаров» (по методу лосяша)
- `Управленческий.Остатки(&Период, Счет = &Товары, &ВидыСубконто (номенклатура, склады))`: `Субконто1` — номенклатура, `Субконто2` — склад (`ВЫРАЗИТЬ` в справочники), **`КоличествоСкладОстаток`** (а не количество — на складах ведётся «количество склад»), сумма — отдельное поле (по номенклатуре); при методе в лоб — обычное «Количество».
- СКД: группировка по номенклатуре и **складу** (не детальные записи — иначе пустая строка), ресурсы: количество, сумма; итоги по вертикали отключить; расположение группировок — отдельно в итогах.
- **Кавычки «ёлочки»:** в представлении склада можно подставить угловые кавычки: Alt+0171 («) и Alt+0187 (»).
