# Урок 116. Форма контрагента: движения по регистру бухгалтерии (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=IA2GVSmXppE · 24 мин · [полный текст](../transcripts/116_IA2GVSmXppE.md)

## О чём урок
Билет по управляемым формам: **«В справочнике "Контрагенты" создать управляемую (основную) форму элемента, в которой пользователь увидит все движения с участием контрагента по регистру бухгалтерии; доступ — из панели навигации»**. Слово «основная» в условии неоднозначно — форму основной **не делаем**.

## Подготовка данных
- ПВХ «ВидыСубконто»: предопределённый элемент **«Контрагенты»**, тип значения `СправочникСсылка.Контрагенты`.
- В плане счетов «Управленческий» на счёт покупателей добавить субконто «Контрагенты» (**без** «только обороты»).
- Реквизит «Контрагент» в документе «РасходнаяНакладная» и в проводке: `Движение.СубконтоДт[ПланыВидовХарактеристик.ВидыСубконто.Контрагенты] = Контрагент`.
- Документ «ПриходДенег»: движение Дт касса / Кт покупатели.

## Форма «ФормаДвиженийБУ»
- Форма справочника «Контрагенты», **не основная**.
- Реквизит — **динамический список с произвольным запросом** по регистру бухгалтерии: период, регистратор, номер строки, активность, счёт Дт, субконто Дт1–3, количество Дт, счёт Кт, субконто Кт, количество Кт, сумма; флажок **«динамическое считывание данных»**.
- Убрать командную панель и автозаголовок.
- Активность: либо фильтровать и не выводить колонку, либо выводить — по желанию.

## Отбор по контрагенту
- В запросе — **параметр виртуальной таблицы**: `Субконто1 = &Контрагент ИЛИ Субконто2 = &Контрагент ИЛИ Субконто3 = &Контрагент`. Поля `Субконто1/2/3` есть **только в параметрах виртуальной таблицы**, не в полях; условие через `ВидСубконто…` не работало.
- В `ПриСозданииНаСервере`:
```bsl
Контрагент = Неопределено;
Если Параметры.Свойство("Контрагент", Контрагент) Тогда
    Список.Параметры.УстановитьЗначениеПараметра("Контрагент", Контрагент);
КонецЕсли;
```

## Доступ из панели навигации
- Команда формы элемента справочника «Контрагенты», группа **«Важное»** панели навигации.
- **Тип параметра команды — `СправочникСсылка.Контрагенты`** (тогда контрагент передаётся в форму как параметр `Контрагент`).
- Действие — открыть форму `Справочник.Контрагенты.Форма.ФормаДвиженийБУ`.
