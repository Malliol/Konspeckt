# Урок 13. Отчёт «Движение товаров». Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=82WX8eBHo3U · 36 мин · [полный текст](../transcripts/013_82WX8eBHo3U.md)

## О чём урок
Отчёт «Движение товаров» (ведомость по партиям: начальный остаток, приход, расход, конечный остаток) из билета № 3, воспроизведённый «один в один» по образцу, включая заголовок из трёх объединённых ячеек и границы. Используется база после урока 12.

## Источник данных
Такие отчёты называются **ведомостями**: для них всегда берут виртуальную таблицу **«Остатки и обороты»** регистра накопления (`РегистрНакопления.ОстаткиНоменклатуры.ОстаткиИОбороты`). В ней есть всё нужное: начальный остаток, приход, расход, конечный остаток — по количеству и по стоимости. Обороты (`КоличествоОборот`, `СтоимостьОборот`) в запрос не нужны. Запрос строят в консоли запросов и копируют в СКД.

## Настройка отчёта
1. Отчёт «ДвижениеТоваров», подсистема «Оперативный учёт», набор данных — запрос.
2. Ресурсы: все числовые поля (итогов в отчёте нет, но ресурсы полезны для гибкости пользователя).
3. Параметры: **«Период» — стандартный период**; «НачалоПериода» и «КонецПериода» берут `&Период.ДатаНачала` / `&Период.ДатаОкончания` и скрываются от пользователя, период обязателен (запрет пустых значений, использование всегда). Параметр по умолчанию — «Этот месяц» (в тесте февраль 2020). Сохранить выбранное значение — закрыть отчёт.
4. Структура: группировка «Номенклатура» → вложенные детальные записи (партии). Выбранные поля: в нужном порядке — количество и стоимость начального остатка, прихода, расхода, конечного остатка.
5. **Количество над суммой** (в образце они в разных строках): в «Выбранных полях» сгруппировать пары полей (группа), задать группе **название** (Начальный остаток, Приход, Расход, Конечный остаток) и расположение «Вертикально». Без названия группы отчёт выводит бессмыслицу.
6. Другие настройки: вывод параметров — «Не выводить»; расположение полей группировок — «Отдельно и только в итогах» (номенклатура и партия в разных колонках); общие итоги по вертикали — «Нет».
7. Условное оформление отчёта: горизонтальное положение «Влево», формат числа — 0 знаков после запятой; область использования — группировка и общий итог.

## Вывод партии «Номер от Дата»
В образце партия показана как «ПН 1 от 01.01.2020» (текст зависит от билета).
- Для поля «Партия» в наборе данных задают **выражение представления**: `"ПН " + НумерацияОбъектов.НомерНаПечать(Партия.Номер) + " от " + Формат(Партия.Дата, "ДФ=dd.MM.yyyy")`.
- Формат даты проще получить конструктором форматной строки (он доступен в любом модуле), а потом скопировать строку.
- Номер документа выводится без ведущих нулей: общий модуль **«НумерацияОбъектов»** (по аналогии с типовыми) с функцией **`НомерНаПечать(Номер)`**: пока первый символ равен «0», строка обрезается (`Сред(Строка, 2)`), в конце возвращается строка. Название функции типовое («при печати счетов-фактур ведущие нули и префиксы удаляют»).
- Ширину колонки можно ограничить свойством оформления «Максимальная ширина» (на экзамене не нужно, макет всё равно переопределяется).

## Заголовок из трёх ячеек: макеты
Заголовок, объединяющий несколько колонок (в образце «Количество/Стоимость» под общим названием), на СКД штатно не сделать: заголовок группы полей влияет только на свою ячейку. Нужно **переопределить макет**.
1. Задать группировке «Номенклатура» имя.
2. Закладка «Макеты» → «Добавить макет заголовка группировки» для группировки «Номенклатура». Нарисовать макет, как в образце (можно скопировать область из Excel; на экзамене копирования нет, ячейки рисуются вручную). Заголовок отчёта «ДВИЖЕНИЕ ТОВАРОВ с … по …» можно вывести в том же макете: ячейка-шаблон, параметры «НачалоПериода»/«КонецПериода», формат даты.
3. Свойство ячеек: заполнение — «Шаблон», формат даты, размер шрифта 9 (по умолчанию в СКД шрифт Arial 9), полужирный для заголовков.
4. **Границы:** при копировании из Excel границы могут остаться, и убрать их не удаётся (не вручную). Если границы нужны, их рисуют сами. В примере автор пересоздал ячейки вручную, и тогда границы исчезли; формат даты нужно задать заново.
5. Добавить **макет группировки «Номенклатура»** (область строки с данными: пустая партия, поля начального остатка, прихода, расхода, конечного остатка) и **макет детальных записей** (строка партии). Ячейки объединяют (Ctrl+M в редакторе), параметры подставляются по названиям полей. Имя группировки детальных записей задают явно (например, «ДетальныеЗаписи»). Для ячеек с текстом партии и номенклатуры задают «Переносить по словам».
6. Выключить «Макет оформления» для отчёта, чтобы СКД не рисовала собственные ячейки; границы нарисовать вручную в макетах. Если нужно, сдвиг текста от края — условным оформлением «Отступ» 1 символ.
7. Подсказка: настройки (условное оформление) можно переносить между группировками мышкой.

## Пустая партия
В отчёте за февраль выводится строка с пустой партией. Это не ошибка: при политике «Средняя» приход и расход идут с пустой партией, а при переходе ФИФО → средняя остатки перекидываются на пустую партию (урок 12). В билете пустой партии нет только потому, что подобран период (январь). Не выводить пустую партию неправильно: остатки на ней могут зависнуть.
