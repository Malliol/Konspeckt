# Урок 124. Загрузка картинки, часть 2 (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=nFZDL6bp6_w · 35 мин · [полный текст](../transcripts/124_nFZDL6bp6_w.md)

## Условие
То же, что в уроке 123, но **фото хранится либо в информационной базе, либо в виде отдельного файла** — в зависимости от желания пользователя (сохраняем **путь** к файлу и отображаем картинку, пока файл по этому пути лежит).

## Структура
- Дополнительный реквизит справочника **«ПутьКартинки»** (строка, неограниченной длины/500 — в Windows путь до 255 символов в проводнике); на форму — **нередактируемый**.
- Картинка либо в «Картинка» (ХранилищеЗначения), либо по пути.
- Флажок «ЗаписыватьКартинкуВБазу» из урока 123 — признак выбора «в базу».

## Диалог после выбора файла
В `ВыборФайлаЗавершение` (`ОписаниеПомещенногоФайла <> Неопределено`):
1. **Сразу показать картинку**: `АдресКартинки = ОписаниеПомещенногоФайла.Адрес` (до вопроса, чтобы отображалась в любом случае).
2. Задать вопрос: `ПоказатьВопрос(Новый ОписаниеОповещения("ВопросЗавершение", ЭтотОбъект, Новый Структура("ОписаниеПомещенногоФайла", ОписаниеПомещенногоФайла)), "Хотите записать картинку в базу данных?", РежимДиалогаВопрос.ДаНетОтмена)`.
3. **Дополнительные параметры** описания оповещения — способ передать данные между процедурами (структура; здесь — описание помещённого файла целиком).
```bsl
&НаКлиенте
Процедура ВопросЗавершение(Результат, ДополнительныеПараметры) Экспорт
    Если Результат = КодВозвратаДиалога.Да Тогда
        АдресКартинки = ДополнительныеПараметры.ОписаниеПомещенногоФайла.Адрес;
        ЗаписыватьКартинкуВБазу = Истина;
        Объект.ПутьКартинки = "";                 // очистить путь, иначе будет брать из пути
    ИначеЕсли Результат = КодВозвратаДиалога.Нет Тогда
        Объект.ПутьКартинки = ДополнительныеПараметры.ОписаниеПомещенногоФайла.ПолноеИмя;
        АдресКартинки = …Адрес;                    // отобразить в любом случае
    КонецЕсли;   // Отмена — ничего не делаем
КонецПроцедуры
```
- На «Отмена» картинку из формы не очищаем (автор оставил адрес как есть; можно хранить предыдущий — «перебор»).
- Полное имя — свойство **`ПолноеИмя`** структуры описания помещённого файла (найти через отладчик).
- Альтернативы (зрители): запоминать выбор в настройке/константе («хранить в базе или нет») — удобнее по интерфейсу, но «желание пользователя» в условии, скорее, про выбор конкретного пользователя на форме.

## Запись и чтение
- `ПередЗаписьюНаСервере`: если `ЗаписыватьКартинкуВБазу` → записать `ТекущийОбъект.Картинка = Новый ХранилищеЗначения(ПолучитьИзВременногоХранилища(АдресКартинки))` и сбросить флаг; иначе — ничего (путь уже записан через `Объект.ПутьКартинки`).
- `ПриЧтенииНаСервере`: **брать картинку из хранилища значений только если `ТекущийОбъект.ПутьКартинки` пустой** (иначе картинка по пути).
- **Показ картинки по пути при открытии формы** — на клиенте в **`ПриОткрытии`** (клиентский метод `НачатьПомещениеФайлаНаСервер` на сервере в `ПриСозданииНаСервере` не вызовешь):
```bsl
Если Не ПустаяСтрока(Объект.ПутьКартинки) Тогда
    ОписаниеОповещения = Новый ОписаниеОповещения("ПоказатьКартинкуПоПутиЗавершение", ЭтотОбъект);
    НачатьПомещениеФайлаНаСервер(ОписаниеОповещения,,, Объект.ПутьКартинки, УникальныйИдентификатор);
КонецЕсли;

Процедура ПоказатьКартинкуПоПутиЗавершение(ОписаниеПомещенногоФайла, ДополнительныеПараметры) Экспорт
    Если ОписаниеПомещенногоФайла <> Неопределено Тогда
        АдресКартинки = ОписаниеПомещенногоФайла.Адрес;
    КонецЕсли;
КонецПроцедуры
```
(по заданному `ПолноеИмяФайла` собственный диалог не показывается; уникальный идентификатор — обязательно).
- Если файла по пути нет — **возникает исключение**, форма не открывается → **`Попытка … Исключение Сообщить(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())) КонецПопытки`** (подробное — `ПодробноеПредставлениеОшибки`).
- При выборе «в базу» **очищать `ПутьКартинки`** — путь служит признаком, откуда читать.
