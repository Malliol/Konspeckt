# Урок 123. Загрузка картинки, часть 1 (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=IdDXqvuwEtY · 46 мин · [полный текст](../transcripts/123_IdDXqvuwEtY.md)

## Условие (задача с картинкой)
Для кадрового учёта для каждого сотрудника хранить **фотографию**; просмотр — из формы элемента справочника «Сотрудники»; **картинка хранится в информационной базе**; **запись в базу — только при записи самого элемента**; отображение на форме — **сразу после выбора, до записи**.

## Структура
- Реквизит справочника **«Картинка»** типа **«ХранилищеЗначения»** (дата/булево не подходят).
- ХранилищеЗначения **нельзя вывести на форму** (в данных формы недоступно) → добавить **реквизит формы «АдресКартинки» (строка)**; на форму — как **«Поле картинки»** (вид — поле картинки; заголовок можно скрыть; **размер картинки** — «растянуть» / «пропорционально»).
- Поле картинки: чтобы работало событие **«Нажатие»** — **флажок «Гиперссылка»**; **стандартную обработку отключить**. (Альтернатива — кнопка «Загрузить картинку»; клик по картинке — «спортивнее».)
- В базе картинки лучше хранить в отдельном регистре/присоединённых файлах (иначе через точку тянется весь объект с картинкой), но **на экзамене — просто реквизит ХранилищеЗначения**.

## Выбор файла: `НачатьПомещениеФайлаНаСервер`
```bsl
&НаКлиенте
Процедура АдресКартинкиНажатие(Элемент, СтандартнаяОбработка)
    СтандартнаяОбработка = Ложь;
    ОписаниеОповещения = Новый ОписаниеОповещения("ВыборФайлаЗавершение", ЭтотОбъект);
    НачатьПомещениеФайлаНаСервер(ОписаниеОповещения,,,, УникальныйИдентификатор);
КонецПроцедуры

&НаКлиенте
Процедура ВыборФайлаЗавершение(ОписаниеПомещенногоФайла, ДополнительныеПараметры) Экспорт
    Если ОписаниеПомещенногоФайла <> Неопределено Тогда   // при отмене — Неопределено!
        АдресКартинки = ОписаниеПомещенногоФайла.Адрес;
    КонецЕсли;
КонецПроцедуры
```
- **`ОписаниеОповещения`** — описание процедуры, вызываемой после завершения асинхронного действия; **процедура обязательно `Экспорт`**, параметры — как в справке (первый — результат, второй — дополнительные параметры); второй параметр конструктора — модуль (`ЭтотОбъект`/`ЭтаФорма`).
- Если выбор отменён, **`ОписаниеПомещенногоФайла = Неопределено`** → обязательная проверка, иначе исключение.
- **Файл помещается во временное хранилище**; параметр **уникальный идентификатор формы** (`УникальныйИдентификатор`) — **обязателен**: иначе значение удаляется **перед следующим серверным вызовом из формы** (в т. ч. при записи), и `ПолучитьИзВременногоХранилища` вернёт `Неопределено`.

## Запись при записи элемента (`ПередЗаписьюНаСервере(Отказ, ТекущийОбъект, ПараметрыЗаписи)`)
- **В `ПередЗаписью` (клиент) и `ПриСозданииНаСервере` объекта нет** (только данные формы); настоящий объект — **`ТекущийОбъект`** в серверных обработчиках записи/чтения.
```bsl
&НаСервере
Процедура ПередЗаписьюНаСервере(Отказ, ТекущийОбъект, ПараметрыЗаписи)
    Если ЗаписыватьКартинкуВБазу Тогда
        ДвоичныеДанные = ПолучитьИзВременногоХранилища(АдресКартинки);
        ТекущийОбъект.Картинка = Новый ХранилищеЗначения(ДвоичныеДанные);
        ЗаписыватьКартинкуВБазу = Ложь;   // «одноразовая акция»
    КонецЕсли;
КонецПроцедуры
```
- Нужна **явная конвертация** `Новый ХранилищеЗначения(ДвоичныеДанные[, СжатиеДанных])` (само не конвертируется).

## Показ картинки при открытии (`ПриЧтенииНаСервере(ТекущийОбъект)`)
- `ПриСозданииНаСервере` не подходит (нет настоящего объекта). В **`ПриЧтенииНаСервере`** (есть `ТекущийОбъект`): `ДвоичныеДанные = ТекущийОбъект.Картинка.Получить();` `Если ДвоичныеДанные <> Неопределено Тогда АдресКартинки = ПоместитьВоВременноеХранилище(ДвоичныеДанные, УникальныйИдентификатор);`
- (Иначе, при `ПоместитьВоВременноеХранилище(...)` с пустым значением — получаем `Неопределено`.) Для нового элемента `ПриЧтенииНаСервере` не вызывается.
- Реквизит формы действует как глобальная переменная модуля формы, доступная из клиентских и серверных процедур — поэтому «процедуры знают адрес картинки».

## Оптимизация: флажок «ЗаписыватьКартинкуВБазу»
- Проблема: при каждой записи картинка снова пишется в базу.
- Решение курсов 1С.рф: в `АдресКартинки` при открытии класть **навигационную ссылку** на реквизит (`ПолучитьНавигационнуюСсылку(Объект.Ссылка, "Картинка")`) и в `ПередЗаписью` проверять, что адрес — адрес временного хранилища (`ЭтоАдресВременногоХранилища`); автор считает это костылём (смешение понятий).
- **Решение автора (понятнее):** реквизит формы «ЗаписыватьКартинкуВБазу» (Булево): в `ПриСозданииНаСервере`/открытии = Ложь; в `ВыборФайлаЗавершение` = Истина; в `ПередЗаписьюНаСервере` — если Истина, записываем и сбрасываем в Ложь.
- (Для регистра сведений подход тот же.)

## Фильтр выбора файла: `ДиалогВыбораФайла`
- Через `НачатьПомещениеФайлаНаСервер` фильтр задать нельзя. Для фильтра — **диалог выбора файла**: `Диалог = Новый ДиалогВыбораФайла(РежимДиалогаВыбораФайла.Открытие); Диалог.Заголовок = "Выберите картинку:"; Диалог.Фильтр = "Картинки (*.jpg)|*.jpg|Все файлы|*.*"` (формат: `Текст|маска|Текст2|маска2…`).
- Метод **`Выбрать()`** — синхронный; если в свойствах конфигурации запрещены синхронные вызовы — ошибка. Обходить: **«Режим использования синхронных вызовов расширений платформы» = «Использовать»** (в каркасе; **режим использования модальности включать не надо — снизят оценку**). В веб-клиенте нужно расширение работы с файлами. На экзамене асинхронные методы могут быть недоступны (зависит от версии платформы).
- Асинхронный вариант: `Диалог.Показать(Новый ОписаниеОповещения("ВыборФайлаДиалогЗавершение", ЭтотОбъект))`; процедура `…Завершение(ВыбранныеФайлы, ДополнительныеПараметры) Экспорт`; проверка **`ВыбранныеФайлы <> Неопределено`** (отмена) и `ВыбранныеФайлы.Количество() > 0`; полное имя — `ВыбранныеФайлы[0]` (множественный выбор выключен).
- Затем **передаём имя файла** в `НачатьПомещениеФайлаНаСервер(ОписаниеОповещения, , ПолноеИмяФайла, УникальныйИдентификатор)` — тогда собственный диалог не показывается.
- **На экзамене можно ограничиться `НачатьПомещениеФайлаНаСервер`** (диалог — факультатив).

## Прочее
Автор целый час боролся со звуком (стрим — 4-я попытка). Удаление картинки на экзамене не требуется; частично будет в следующем видео (урок 124). Короткие комментарии: зарплата менеджера по продажам у франчайзи 1С — широкий разброс.
