# Урок 42. Формирование проводок регистра бухгалтерии (поступление). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=1ekAJkT8Fh8 · 28 мин · [полный текст](../transcripts/042_1ekAJkT8Fh8.md)

## О чём урок
Первая бухгалтерская задача — билет по нумерации автора № 15 (купля-продажа: купили товар → продали товар). Сегодня — только **поступление**: расширить субконто счёта «Товары» и сформировать проводки в приходной накладной. Расход — на следующем занятии. База — выгрузка занятия 41.

## Условие (часть 1)
Нужно вести учёт товаров **в разрезе мест хранения (склады) и партий** (партия = документ «Приходная накладная») в дополнение к номенклатуре.

## Настройка субконто
1. ПВХ «ВидыСубконто» → **составной тип** значений характеристик: добавить справочник «Склады» и документ «ПриходнаяНакладная».
2. Предопределённые элементы ПВХ: **«Склады»** и **«Партии»** (множественное число; в уроке оговорка «склады, а не склад»).
3. План счетов → «Максимальное количество субконто» = **3** (больше на экзамене не ставят); у счёта «Товары» добавить виды субконто «Склады» и «Партии». Флажок «Только обороты» **не** ставят — нужны остатки по складам и партиям.
4. Приходная накладная: реквизит «Склад» (справочник «Склады», проверка заполнения «Выдавать ошибку», на форме).

## Проводка поступления (обработка проведения)
- В задаче проводки **заданы** — запоминать не нужно: **Дт «Товары» — Кт «Поставщики»**. Бухучёт на экзамене фактически не изучают — только базовое понимание.
- Заполняется через конструктор движений или вручную (автор советует **пока писать вручную**, чтобы запомнить, а не копипастить конструктор).
- Движение: `Движение = Движения.Управленческий.Добавить()`:
  - `Движение.Период = Дата`;
  - `Движение.СчетДт = ПланыСчетов.Управленческий.Товары` (счёт — **всегда предопределённый элемент плана счетов**), `Движение.СчетКт = ПланыСчетов.Управленческий.Поставщики`;
  - **Субконто по дебету** (только у «Товаров»; у «Поставщиков» субконто нет — по кредиту не заполняют): `Движение.СубконтоДт[ПланыВидовХарактеристик.ВидыСубконто.Номенклатура] = Выборка.Номенклатура`; аналогично «Склады» = склад, «Партии» = `Ссылка` (текущая приходная накладная);
  - **Количество**: `Движение.КоличествоДт = Выборка.Количество` (только по дебету: количественный учёт включён только у «Товаров»; по кредиту поставщиков количества нет);
  - **Сумма** (балансовый ресурс) — `Движение.Сумма = Выборка.Сумма`.
- **Свёртка табличной части**: запрос по табличной части приходной накладной (`ВЫБРАТЬ Номенклатура, Склад (из шапки), СУММА(Количество), СУММА(Сумма) … ГДЕ Ссылка = &Ссылка СГРУППИРОВАТЬ ПО Номенклатура, Склад`) — **необязательно** (дубли строк не ошибка: так делает Белоусов «когда лень», так и в типовой «Бухгалтерии»), но удобно: потом проще списывать (запрос в расходной накладной). Не забыть **отбор по ссылке документа** (параметр `&Ссылка`; было упущено в уроке).
- Результат: проводка Дт «Товары» (номенклатура, склад, партия) / Кт «Поставщики»; одинаковые позиции сворачиваются, разные склады — раздельные строки.

## Три способа записи субконто (результат одинаков)
1. `Движение.СубконтоДт[ПланыВидовХарактеристик.ВидыСубконто.Номенклатура] = Значение` — как даёт конструктор и как пишет Белоусов; **автор будет использовать этот способ**, «чтобы не расстраивать экзаменатора».
2. Через точку: `Движение.СубконтоДт.Номенклатура = Значение` (имя предопределённого элемента ПВХ как имя свойства) — работает без исключений.
3. `Движение.СубконтоДт.Вставить(ВидСубконто, Значение)` — тоже есть в типовой.
4. В типовой «Бухгалтерии» чаще — метод общего модуля `БухгалтерскийУчет.УстановитьВидСубконто` (проверяет дополнительные условия).

## Признак учёта и субконто — в чём разница
- **Признак учёта** (количественный, суммовой) **включает/выключает ресурс** для конкретного счёта (по «Товарам» количество вести можно, по «Поставщикам» — нельзя; система не даст заполнить).
- **Субконто** — **дополнительный разрез аналитики** (аналог измерений регистра накопления «номенклатура, склад, партия»). Без субконто нельзя было бы сказать, на какой склад и какой товар пришёл.
- Количественный признак сделан **на счёте**, а не как «признак учёта субконто», потому что количество нужно по всем субконто счёта; «признак учёта субконто» создают, если количество нужно только по части видов субконто.

## Актуализация документа «Операция»
После изменения плана счетов (максимум субконто 3) табличная часть проводок в документе «Операция» остаётся с прежним числом колонок субконто. Нужно: **удалить с формы реквизит-таблицу «Движения Управленческий» и перетащить заново**, удалить колонку «Период». Тогда для счёта «Товары» вводятся три субконто (номенклатура, склад, партия), для «Поставщиков» — недоступны. Документ «Операция» удобно использовать для **проверки настройки счетов** (если вводится правильно, значит план счетов настроен верно).

## Планы
- Следующее занятие — расходная накладная (списание, баланс по партиям), отчёты. В плане автора — 16 билетов (из группы Михаила Прохожего); дополнительные задачи не берутся. На майские праздники будет марафон из 3–4 стримов.
- Выгрузка «после занятия 42» публикуется сразу на занятии.
