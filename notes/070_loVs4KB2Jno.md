# Урок 70. Отчёт «Анализ премий» (СПР). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=loVs4KB2Jno · 45 мин · [полный текст](../transcripts/070_loVs4KB2Jno.md)

## О чём урок
Последняя часть билета № 1: отчёт **«Анализ премий»** (по данным регистра расчёта «ДополнительныеНачисления») и длинное отступление об убирании «пустой строки» между заголовком и таблицей — автор не рекомендует тратить на это время на экзамене.

## Образец отчёта
«Для анализа полученных сотрудниками предприятия премий необходимо предусмотреть отчёт»: **заголовок «Месяц: Август 2021 г.»**, затем таблица: **сотрудник, трудовой стаж, процент премии, сумма премии** (и итог по сумме премии внизу). Отчёт — за **один месяц** (пользователь не может получить за период).

## Запрос
- Обычная таблица **регистра расчёта**: `РегистрРасчета.ДополнительныеНачисления` (физическая таблица записей — **не** «База», «ДанныеГрафика» и т. п.; для анализа начислений обычно нужны «просто записи»): `Сотрудник`, **`Стаж`** (реквизит регистра: число 5/2 — для отчёта стаж хранится в реквизите регистра расчёта, поэтому его туда и записывали), `ПроцентПремии`, `Результат` (сумма премии).
- **Отбор:** `ПериодРегистрации = &ПериодРегистрации` (параметр — месяц; «пользователь должен получать отчёт за один месяц»), **`ВидРасчета = &Премия`** (параметр со значением «Премия» плана «ДополнительныеНачисления» — отчёт анализирует именно премии; предопределённое значение через параметр) и **`Результат > 0`** (нулевые премии не анализируются).
- **Активность записей** в отчёте **не учитывают** (`Активность = ИСТИНА` не пишут: «Белоусов и курсы 1С.рф так не делают; в расчётных регистрах записи не деактивируются — документ «Операция» с ними не работает»).

## СКД
- Отчёт «АнализПремий» (подсистема «Расчёты»), набор данных «запрос»; **заголовки колонок** можно задать **прямо в наборе данных** (в поле «Заголовок»): «Трудовой стаж», «Процент премии», «Сумма премии».
- **Параметр «ПериодРегистрации»**: убрать флажок ограничения доступности, «Всегда использовать», в выражении — **приведение к началу месяца**: `НачалоПериода(&ПериодРегистрации, "Месяц")` (в выражениях СКД — **в кавычках**: «пробуем без кавычек — не пошло, с кавычками — пошло») — пользователь указывает любой день месяца; значение по умолчанию — начало месяца; в пользовательские настройки включить; параметры вывода — «Не выводить».
- Структура: **детальные записи** (без группировок: «все четыре колонки в одну строку» — приемлемо); **ресурсы:** «Сумма премии» (итог внизу); для «Стажа» и «Процента» — **не суммировать**: итоги нужны только по сумме; но в образце в итоговой строке четыре ячейки, поэтому «стаж» и «процент» можно сделать ресурсами и затереть условным оформлением — «для любителей четырёх ячеек» (странный приём — может смутить экзаменатора; **не обязателен**).
- **Условное оформление:** **минимальная ширина колонки 15 символов**, область — группировка (без «заголовка»); выравнивание — как в образце (по левому краю у заголовков/числа можно не выравнивать); **отступ** (условное оформление) — задавать только для поля «Сотрудник» (иначе отступ появляется и у других колонок и заголовка).
- **Заголовок отчёта «Месяц: Август 2021 г.»:** отдельная группировка «заголовок» (детальные записи) — **вариант использования «Дополнительная информация»** (иначе для неё рисуются итоги) с макетом группировки: «Месяц: [ПериодРегистрации]»; формат даты в макете: **`ДФ='ММММ гггг "г."'`** — в формате даты месяц словом — «4 буквы M» (`MMMM`), год цифрами — «4 буквы y» (`yyyy`), и `"г."` в кавычках; **локальный формат (`ДЛФ`) не использовать** — при установке другого языка ОС формат «плывёт» (печатные формы). Для заголовка отключить «макет оформления», чтобы не было ячеек; ширину ячейки заголовка — широкое поле без переноса.
- **Сортировка:** по сотруднику (авто / явно).

## Пустая строка между заголовком и таблицей
Автор показал «черную магию» и **не рекомендует** делать это на экзамене:
- Попытка: **подчинить таблицу заголовку** (заголовок — группировка с вариантом использования «авто», детальные записи — подчинённая): ломает итоги, ячейки, ширину, выводит значения месяца для каждой записи — «дорога в ад»; два часа убирал пустую строку Белоусов; у Прохорова — «ответ в чате».
- Результат компромисса: «заголовок» как группировка; для **итогов** (подвал) определяют **макет «Подвал» (общий итог)** отдельно: вывести четыре ячейки в подвале через параметр «Сумма премии»; границы ячеек в подвале рисуют в макете (**цвет границы — 230, 230, 230**: пипеткой «взять с экрана» целиться надо **кончиком пипетки** — сначала взяли «не тем концом»); стиль линии «сплошная». Недостаток: если пользователь поменяет колонки местами — подвал не совпадёт.
- Вывод: **«если нужно убрать пустую строку — нарисуйте макет для заголовка (с месяцем и заголовками колонок); подчинение группировок не использовать»**; «формат с копейками» (2 знака) не требуется.

## Прочее
- Расчёт «первого билета» полностью разобран («от и до»); следующая суббота — перерыв; потом «может быть, 4 стрима».
- Реплики зрителей: «время ушло на пустую строку — так выглядит реальный экзамен», «определите макет заголовка — это быстро».
