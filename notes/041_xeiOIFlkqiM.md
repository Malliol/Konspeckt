# Урок 41. Подготовка к решению бухгалтерских задач. Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=xeiOIFlkqiM · 38 мин · [полный текст](../transcripts/041_xeiOIFlkqiM.md)

## О чём урок
Начало блока **бухгалтерского учёта**: подготовка базовой конфигурации (выгрузка после занятия 2 — каркас без оперативного учёта) для всех бухгалтерских задач: план счетов, регистр бухгалтерии, субконто, документ «Операция». По словам автора, бухгалтерские задачи «проще оперативных» и построены на тех же алгоритмах, но с проводками; хватает базового понимания бухучёта.

## Очистка каркаса
Убрать склад из приходной и расходной накладных, обработки проведения обеих, регистр накопления «ОстаткиНоменклатуры» (и из подсистемы). **Бухгалтерские задачи решают только на регистре бухгалтерии; решение на регистре накопления — нарушение требований экзамена («сразу двойка»).**

## План счетов и регистр бухгалтерии
- План счетов «Управленческий» (в каркасе) с предопределёнными **счетами** (например, «Товары», «Поставщики», «Покупатели»); на экзамене достаточно **одного** плана счетов и **одного** регистра бухгалтерии (с тем же именем «Управленческий», связан с планом счетов).
- **Флажок «Корреспонденция»** в регистре бухгалтерии — **всегда включён** (в российском учёте проводка = счёт Дт + счёт Кт). Без корреспонденции — один счёт + вид движения (приход/расход).
- Ресурсы регистра: **«Количество»** (10/3 — в уроке «10 и 0»; не «неотрицательное» — возможно сторно) и **«Сумма»** (12/2). **«Балансовый»**: сумма — **балансовый ресурс** (указывается по дебету и по кредиту, суммы должны совпадать: иначе баланс «разойдётся»); количество — **небалансовый** (указывается только у одного из счетов: у товаров есть, у поставщиков нет).
- **Признаки учёта:** в плане счетов создают признак учёта **«Количественный»** (булево) и привязывают его к ресурсу «Количество» (в свойстве ресурса «Признак учёта»). Для каждого счёта флажок включают (у «Товаров» — да; у «Поставщиков» — нет): система не позволит вводить количество там, где учёта нет.
- Регистраторы плана счетов/регистра: документы «Операция», приходная и расходная накладные.
- Проверка заполнения у ресурсов регистра бухгалтерии не задаётся (нет такого свойства; предложение зрителя о запрете незаполненных значений — не подходит).

## Субконто
- **Субконто** — дополнительный разрез аналитики внутри счёта (по счёту «Товары» — номенклатура; без субконто нельзя сказать, какие именно товары).
- В плане счетов (закладка «Субконто»): указывается **план видов характеристик «ВидыСубконто»** (создан разработчиками каркаса) и **максимальное количество субконто** (по задаче — 1; в «Бухгалтерии предприятия» — 3; больше 3 не нужно; ставят столько, сколько требует задача).
- В ПВХ «ВидыСубконто» тип значения характеристик содержит возможные типы (номенклатура); предопределённый элемент «Номенклатура». Для новых аналитик (склады, партии и т. п.) расширяют тип значения и добавляют предопределённые элементы.
- У каждого счёта выбирается набор видов субконто; флажок **«Только обороты»** — если не нужно хранить остатки по субконто (для номенклатуры нужен контроль остатков → флажок **не** ставить). Аналог выбора «остатки/обороты» у регистра накопления.
- Для субконто также есть **признаки учёта субконто** (например, «количественный»/«суммовой»): можно, например, не вести количество по номенклатуре, но вести по складам; в этом уроке не используется.

## Короткая теория счетов
- Счета делятся на **активные** (товары, покупатели — активно-пассивный), **пассивные** (обязательства) и **активно-пассивные**. Активный счёт: **дебет — увеличение, кредит — уменьшение**, остаток (сальдо) — **дебетовый**; кредитовый остаток по активному счёту — «отрицательный остаток» (как «минус» в регистре накопления). У пассивных — наоборот: кредит увеличивает.
- «Покупатели»: Дт — увеличение долга покупателя перед нами, Кт — уменьшение; **кредитовый остаток по покупателям — аванс** (как отрицательный остаток «Взаиморасчётов»). «Поставщики»: Кт — увеличение нашего долга.
- Пример: Дт «Товары» Кт «Поставщики»: товаров больше и наш долг перед поставщиком больше. **На экзамене проводки задаются в условии** — запоминать бухгалтерию не требуется, достаточно знать, что дебет «Товаров» увеличивает товар, а кредит «Поставщиков» — долг.

## Интерфейс и подсистема
Подсистема «Бухгалтерский учёт»: справочники (валюта, номенклатура, контрагенты, подразделения, физические лица — на всякий случай), документы (приходная, расходная, «Операция»), перечисления, план счетов, регистр бухгалтерии, ПВХ видов субконто и свойств объектов, курсы валют, учётная политика (перечисление — только в группу команд). Группы команд: добавить «Перечисления», «Планы счетов», «Регистры бухгалтерии». Оперативный учёт скрыть из интерфейса. Автор поменял вид окон: панели открытых/разделов — вверх (для широких проводок).

## Документ «Операция» (ручной ввод проводок) — обязателен в каждой бухгалтерской задаче
Условие каждой бухгалтерской задачи начинается с «создать документ “Операция”, где пользователь вводит проводки с произвольной корреспонденцией». База — урок 20 (документ «РучнаяКомплектация»).
1. Документ «Операция» — в подсистему, в группу команд документов; в **«Движения» — запретить проведение**, регистратор регистра «Управленческий» (движения набираются вручную).
2. На форме — «Движения регистра Управленческий» (перетащить на форму) — таблица проводок: счёт Дт, субконто Дт, счёт Кт, субконто Кт, количество, сумма и т. д. Поле «Период» убрать из таблицы; брать **из даты документа**: в `ПередЗаписью` — `Для Каждого Движение Из Движения.Управленческий Цикл Движение.Период = Дата; КонецЦикла`.
3. Субконто/количество по счёту доступны только если настроены в плане счетов (у «Товаров» — субконто «Номенклатура» + количество; у «Поставщиков» — ни того, ни другого).
4. **Активность проводок при пометке на удаление:** `Движение.Активность = Не ПометкаУдаления` для всех проводок. Нюанс: при нажатии «Записать» набор прочитан и флаг записи автоматически `Истина`; при «Пометить на удаление» набор записей **пуст** и `Записывать = Ложь`. Поэтому в `ПередЗаписью` нужно **прочитать набор** (`Движения.Управленческий.Прочитать()`) и **установить `Записывать = Истина`**, затем выставить активность — тогда пометка/снятие метки гасит/включает проводки.
5. Копирование документа (факультативно, «если останется время»): в `ПриКопировании(ОбъектКопирования)` — `ВыборкаПоРегистратору = РегистрыБухгалтерии.Управленческий.Выбрать(, , , , ОбъектКопирования.Ссылка)` (метод «ВыбратьПоРегистратору»), цикл по выборке, `Движения.Управленческий.Добавить()` и `ЗаполнитьЗначенияСвойств(…, Выборка)`; проверка F9 — копируются и проводки.
