# Урок 108. Документ «Табель»: ввод и проведение (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=m0UcnzWGPa0 · ~35 мин · [полный текст](../transcripts/108_m0UcnzWGPa0.md)

## О чём урок
Первая часть билета **«Табель»** (осталось три билета с табелем). Заготовка — выгрузка 66. **Документ «Табель»**: ввод отработанных часов за месяц и **разбор значений ячеек в регистр накопления**.

## Условие
- Совместительство **допускается** (сотрудник + подразделение); все — по пятидневке, **но возможна работа по нескольким графикам**.
- **Количество фактически отработанных часов вводится документом «Табель»; документ формируется на список сотрудников только определённого подразделения; для каждого сотрудника на каждый день месяца вводится количество фактически отработанных часов на основном месте работы и в командировке.** На скриншоте: «8» — часы, «8к» — командировка (буква «к» после числа).
- Дробные часы допускаются (8,25), поэтому колонки — число 5/2 (на экзамене чаще целые).

## Документ «Табель»
- Подсистема «Расчёты»; **оперативное проведение — отключить** (несколько табелей в месяц; будущие даты); реквизит **«Подразделение»** (шапка, «Выдавать ошибку»); табличная часть «Данные табеля»: «Сотрудник» (физлицо, «Выдавать ошибку») и **31 колонка «День1»…«День31»** — **строки (не числа)**, чтобы вводить «8к», «8,25к» (можно «К»/«к»); «Выдавать ошибку» у колонок **не ставить** (пустое значение — выходной).
- **Кнопки «Заполнить сотрудниками подразделения» не делаем**: нигде не хранится соответствие «сотрудник — подразделение» (регистр «СведенияОСотрудниках» хранит ставки/оклады, а не принадлежность; приёма/перемещения нет). На экзамене такой кнопки не будет.
- Прочее: автор отказался от динамического скрытия колонок вне месяца (30 сентября — «31 число» не обрабатывается).

## Регистр накопления «ДанныеТабеля»
- **Обороты** (не остатки: нужна информация за каждый день — «сколько часов»). Измерения: «Сотрудник», «Подразделение» (запрет незаполненных), **«ВидВремени» (справочник «ВидыВремени» с предопределёнными элементами «Явка», «Командировка»; запрет незаполненных)**; ресурс «Часов» (5/2).
- **Вариант Белоусова/Прохорова/1С.рф** — отдельный **ресурс «ЧасовКомандировки»** («проще»). Автор предпочитает **вид времени**: для каждой новой «буквы» (больничный, прогул, выходной) — не новый ресурс, а новый вид времени — «более логично»; считает, что Белоусов не подумал о расширяемости (он так и делает).
- Справочник «ВидыВремени» — в подсистему «Расчёты»; **предопределённые элементы** — «Явка», «Командировка» (имена — по одному в справочнике; «проще».)
- Регистратор — «Табель»; документ — в подсистему, регистры — в подсистему и в интерфейс.

## Проведение: цикл в цикле
```bsl
Движения.ДанныеТабеля.Записывать = Истина;
ПериодРегистрации = НачалоМесяца(Дата);
ПоследнийДень = День(КонецМесяца(Дата));             // 28/29/30/31 — не бежим по лишним колонкам
Для Каждого Строка Из ДанныеТабеля Цикл
    Для НомерДня = 1 По ПоследнийДень Цикл
        Значение = СокрЛП(ВРег(Строка["День" + НомерДня]));   // Строка колонки "День1" и т.д.; привести к верхнему регистру, убрать пробелы
        Если ПустаяСтрока(Значение) Тогда Продолжить; КонецЕсли;
        Если Прав(Значение, 1) = "К" Тогда                    // русская «К» — командировка
            ВидВремени = Справочники.ВидыВремени.Командировка;
            Часы = Число(Лев(Значение, СтрДлина(Значение) - 1));
        Иначе
            ВидВремени = Справочники.ВидыВремени.Явка;
            Часы = Число(Значение);
        КонецЕсли;
        Движение = Движения.ДанныеТабеля.Добавить();
        Движение.Период    = ПериодРегистрации + (НомерДня - 1) * 24 * 60 * 60;   // секунды! — не дни
        Движение.Сотрудник = Строка.Сотрудник;
        Движение.Подразделение = Подразделение;
        Движение.ВидВремени = ВидВремени;
        Движение.Часов = Часы;
    КонецЦикла;
КонецЦикла;
```
- «Цикл в цикле» возникает в любом решении (строки × колонки) — не из-за «вида времени».
- **Дата дня** = начало месяца + (номер дня − 1) × 86 400 секунд (не «дни»).

## Защита от некорректных значений
Пользователь может ввести «%» вместо «;» и т.п. — «Не удаётся преобразовать значение к типу Число». Решение — **`Попытка … Исключение`**:
```bsl
Попытка
    … Число(…) …
Исключение
    Сообщить("Некорректный ввод данных: строка " + Строка.НомерСтроки + ", день " + НомерДня);
    Отказ = Истина;
    Продолжить;
КонецПопытки;
```
(сообщение — «строка N, день M»; код в 120 символов). Автор считает: «Белоусов не делает попытки; но лучше сделать — иначе некорректные данные при вводе принимаются».

## «Часы командировки определяются по пятидневке, исходя из 40-часовой рабочей недели»
- Если в «Табеле» вводится **только буква «К»** (без часов) — часы берём **из графика «Пятидневка»** на эту дату (иначе, когда пользователь вводит «8к», условие избыточно); в цикле запросы к данным графика **нельзя (−3 балла и «дальше можно не смотреть»)**.
- Решение: **до цикла один запрос**: `РегистрСведений.ГрафикРаботы`: `Дата`, `Часов` — `ГрафикРаботы = &Пятидневка`, `Дата МЕЖДУ &НачалоПериода И &КонецПериода` (месяц документа) → выборка (можно и **таблицу значений**, но «экзаменатор может придираться»; лучше **выборка**: в цикле — `Выборка.Сбросить(); Если Выборка.НайтиСледующий(Дата, "Дата") Тогда Часы = Выборка.Часов; Иначе Часы = 0`).
- **«Пятидневка» — предопределённый элемент** справочника «ГрафикиРаботы» (в коде — `Справочники.ГрафикиРаботы.Пятидневка`). (В видео: не хватало элемента — удаление пересозданного элемента, затем **заполнить график заново**: выходные 6, 7; для выходного дня часы командировки = 0.)
- Для значения «К»: `ВидВремени = Командировка`, `Часы` из графика; `Если Значение = "К"` (всё значение, а не последний символ).
- Тест: 31 октября — командировка; 1 октября «8,25» — «за первое число 8,25, за 2 — 0» и т. п.; в табеле два сотрудника (Бердыев и Жупиков с 10 часами), чтобы ловить ошибки соединений.
