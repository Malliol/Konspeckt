# Урок 115. Функциональная опция «доступ к старшим менеджерам» по пользователю и дате (УФ). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=MVSYQG35GyU · ~25 мин · [полный текст](../transcripts/115_MVSYQG35GyU.md)

## О чём урок
Билет № 8 по УФ (ещё одна задача на функциональные опции): **ФО с параметром «Пользователь» и периодичностью** (зависит от даты документа). Заготовка — выгрузка 114.

## Условие
«В компании продажами занимаются **обычные менеджеры и старшие менеджеры**. С целью дополнительного контроля при продаже **в документах «ПриходДенег» и «РасходнаяНакладная» может быть указан ответственный старший менеджер**, контролирующий операцию. **Указывать эту информацию может не каждый пользователь, а только обладающие соответствующими привилегиями**; если у пользователя нет информации об ответственном менеджере — поле **невидимо**; **управление видимостью должно быть реализовано с помощью функциональных опций**. **Внесение данных об ответственном сотруднике может меняться не чаще раза в день**, и информация в документе должна отображаться **только если на дату документа пользователь имел права**».

## Заготовка
- Документы: «РасходнаяНакладная» (реквизит «СтаршийМенеджер» — «Выдавать ошибку» **не ставить**: не все видят поле), **«ПриходДенег»** (новый: «Контрагент», «СуммаДокумента» 12/2, «СтаршийМенеджер»); подсистема «УправляемыеФормы».
- **Должности для этой задачи не нужны** — убрать конструкции билета 16 (константы «ИспользоватьСклады»…, регистр «ДоступКПодсистемам», параметр «Должность», форму констант, лишние ФО).

## Реализация
1. **Регистр сведений «ДоступКСтаршимМенеджерам»** — **периодический, периодичность «В пределах дня»** (данные меняются не чаще раза в день), **независимый**; подсистема; **измерение «Пользователь»** (физлицо), **ресурс «Доступ»** (булев).
2. **Функциональная опция «ДоступКСтаршимМенеджерам»**: «Хранение» — ресурс «Доступ» регистра; **«Состав»: реквизит «СтаршийМенеджер» документов «РасходнаяНакладная» и «ПриходДенег»**.
3. **Параметр функциональных опций «Пользователь»** (тип «СправочникСсылка.ФизическиеЛица»); «Использование» — **измерение «Пользователь» регистра**; **«Период»** — в параметре функциональных опций поля «Период» нет: **период** передаётся в структуре параметров отдельным **ключом «Период»** («система сразу поймёт: берётся срез последних на дату»).
4. Установка параметров — **на форме документа** (серверная процедура `ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)` формы документа):
```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    Параметры = Новый Структура("Пользователь, Период", ПараметрыСеанса.ТекущийПользователь, Объект.Дата);
    УстановитьПараметрыФункциональныхОпцийФормы(Параметры);       // именно «ФОРМЫ» (не «ИНТЕРФЕЙСА»)
КонецПроцедуры
```
   - Для **«ПриходДенег»** — **создать форму документа** (её нужно создавать явно) и записать тот же код; для **«РасходнойНакладной»** — в имеющейся форме.
   - Автор сначала установил параметры в модуле приложения («УстановитьПараметрыФункциональныхОпцийИнтерфейса» — структура с «Пользователем» без периода): ФО «берёт последнее значение» — для нашей задачи нужна **дата документа**; поэтому — `УстановитьПараметрыФункциональныхОпцийФормы` + «Период».
   - **Параметры ФО применяются при открытии**; при **изменении самого регистра/должности** нужно перезапустить программу (или устанавливать параметры на форме при изменении).
5. **Формы списков**: чтобы пользователь не видел «секретное» поле в списках, **создать собственные формы списка** («Дата», «Номер», «Контрагент», «СуммаДокумента») **без «СтаршегоМенеджера» и без ссылки** — тогда поле нигде в списке нет (форма списка у автоформы использует последнюю запись регистра, а не дату документа); аналогично для «ПриходДенег».

## Проверка
- Бельдыев (физлицо) получил «Доступ = Истина» с 1 мая: в майской расходной накладной поле видно; в октябрьской (после снятия доступа с 1 октября/1 ноября) — поле скрыто; для Жупикова — «нет данных → поле скрыто».
- Для списков (динамический список) поле не отображается — «всё нормально».
