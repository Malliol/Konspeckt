# Урок 129. Бизнес-процессы, часть 3 (БП). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=yPFKJWPhCI0 · 34 мин · [полный текст](../transcripts/129_yPFKJWPhCI0.md)

## О чём урок
Завершающие обязательные требования к бизнес-процессам. **Штрафы:** не сделан бизнес-процесс — −1 балл; не отражено текущее состояние в форме процесса — до −2,5 (все вместе); **не реализована форма списка невыполненных задач текущего пользователя — −1**; **избыточные признаки адресации** (лишние записи в регистре адресации) — −0,5; **отсутствие возможности просмотра полного списка задач — −0,5** (полный список — стандартная форма списка задачи, команда подсистемы).

## Отображение текущего состояния (карта маршрута на форме процесса)
- Форма бизнес-процесса: реквизит **«КартаМаршрута»** типа **«ГрафическаяСхема»**, вынести на форму (в «компактную» группу вместе с номером/датой/флажками — для экономии места).
- В `ПриСозданииНаСервере` настоящий объект получаем **конвертацией**: `БизнесПроцессОбъект = РеквизитФормыВЗначение("Объект"); КартаМаршрута = БизнесПроцессОбъект.ПолучитьКартуМаршрута();` — метод **`ПолучитьКартуМаршрута()`** есть у объекта бизнес-процесса (но «Объект» формы — данные формы, поэтому конвертация обязательна).
- Закладка «Командный интерфейс» формы: **флажок быстрой навигации к задачам процесса** — появляется ссылка на задачи этого процесса.
- **Обновление после старта/записи** — серверная процедура **`ОбновитьКартуМаршрута()`** (конвертация + присвоение), вызывается из `ПриСозданииНаСервере` и **`ПослеЗаписиНаСервере(ТекущийОбъект, ПараметрыЗаписи)`**. В «ПослеЗаписи» уже есть настоящий объект → можно сразу `КартаМаршрута = ТекущийОбъект.ПолучитьКартуМаршрута()` (без лишней конвертации; экзаменатор может придраться к лишнему преобразованию — оба варианта допустимы).
- При выполнении задачи в другом окне карта сама не перерисуется (реквизит формы — просто «переменная» в памяти сеанса); другой пользователь не увидит; надёжнее всего — переоткрыть/записать.

## Автоматическое обновление карты при выполнении задачи (необязательно, «познавательно»)
- Форма задачи (создать форму «ФормаЗадачи»); в **`ПослеЗаписи`** на клиенте — `Оповестить("ЗадачаВыполнена", Объект.БизнесПроцесс, Объект.Ссылка)` (событие, параметр — бизнес-процесс, источник — любой).
- В форме бизнес-процесса **`ОбработкаОповещения`**: `Если ИмяСобытия = "ЗадачаВыполнена" И Параметр = Объект.Ссылка Тогда ОбновитьКартуМаршрутаНаСервере();` — ловим только свои задачи.
- **Ловушка:** при завершении процесса платформа ставит флажок «Завершён» у объекта, и форма становится **неактуальной** → «Операция не может быть выполнена… из-за версии или отсутствия записи в базе данных». Перед обновлением карты **`Прочитать()`**: `ЭтаФорма.Прочитать();` (актуализирует форму) и только потом `ОбновитьКартуМаршрута()`.
- Можно ли перехватить сигнал из другого окна/сеанса — не получилось.
