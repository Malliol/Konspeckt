# Урок 27. Расчёт себестоимости без учёта сроков годности. Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=G3lN2BbVEMo · 81 мин · [полный текст](../transcripts/027_G3lN2BbVEMo.md)

## О чём урок
Решение задачи урока 24 (оборудование, сроки годности/эксплуатации) в другой трактовке: **себестоимость считается в разрезе номенклатуры без учёта сроков годности**. Отдельный регистр себестоимости, два регистра в проведении. Основа — выгрузка после урока 24.

## Зачем второй вариант
Формулировка «себестоимость рассчитывается как среднее» **не указывает разрез**. Автор опросил зрителей: большинство считает, что имеется в виду номенклатура без сроков годности (в уроке 24 считалось с разрезом по срокам годности). На экзамене экзаменатор может потребовать именно так, поэтому нужно уметь решать оба варианта; в задаче без указания разреза допустим любой. Автору сообщили, что Белоусов говорил: «на экзамене будет указано, как считать».

## Работа над ошибками (урок 26)
В запросе проведения «Прихода денег» контрагента добавили параметром, но не добавили в условие соединения и не индексировали: индекс «контрагент + накладная» использовался не полностью. Решение: контрагента передавать параметром и использовать в условии остатков (индекс используется целиком). Второй вариант — отбор по накладной и контрагенту отдельно (частичное использование индекса) — тоже допустим (так делают Белоусов и курсы).

## Конфигурация
- Регистр «ОстаткиНоменклатуры» остаётся для количества с измерением «СрокГодности». Стоимость из него убирается: себестоимость нельзя хранить в регистре с разрезом по срокам годности.
- Новый регистр накопления **«Себестоимость»** (копия «ОстатковНоменклатуры» без измерения «СрокГодности»): измерение «Номенклатура», ресурсы «Количество» и «Стоимость» (12/2, без «Неотрицательное», без проверок заполнения); вывести в подсистему и группу команд. Количество в двух регистрах всегда движется синхронно.
- «ОборудованиеВЭксплуатации» остаётся без изменений.

## Приходная накладная
Добавляется запись в «Себестоимость» (`Записывать = Истина`).
- Запрос с **итогами**: на уровне итоговых записей — номенклатура, количество, стоимость (суммы) и период (максимум): итоговая запись формирует **приход** в «Себестоимость» (свёрнутый по номенклатуре), детальные записи (по срокам годности) — приход в «ОстаткиНоменклатуры».

## Ввод в эксплуатацию (старая методика)
1. `ВТ_Товары` (номенклатура, количество; индекс по номенклатуре).
2. Остатки номенклатуры на момент времени: `Остатки(&МоментВремени, Номенклатура В (...) И СрокГодности >= &НачалоДняДокумента)`; просроченные остатки не учитываются (смысл формулировки — исключить просрочку из остатков, а не запретить проведение).
3. Левое соединение с `Себестоимость.Остатки(&МоментВремени, Номенклатура В (...))`; поля «ИтоговоеКоличествоОстаток», «ИтоговаяСтоимостьОстаток» (`ЕСТЬNULL`).
4. Срок эксплуатации дней: `ДОБАВИТЬКДАТЕ(&НачалоДня, ДЕНЬ, СрокЭксплуатацииДней)` (параметр называют «НачалоДняДокумента»).
5. **Итоги** по номенклатуре: `МАКСИМУМ(Количество)` (количество в документе), `СУММА(КоличествоОстатокПоСроку)` (не просроченные), `МАКСИМУМ(ИтоговоеКоличествоОстаток)` и `МАКСИМУМ(ИтоговаяСтоимостьОстаток)` (общие по номенклатуре), `МАКСИМУМ(Период)`.
6. Проверки: количество > суммы не просроченных остатков → «Недостаточно товара %1 в количестве %2», `Отказ`; срок эксплуатации не указан → «Не указан срок эксплуатации по номенклатуре %1» (подсказал зритель).
7. **Блокировки** — для **каждого** регистра отдельно (два элемента блокировки в одном объекте `БлокировкаДанных`): исключительный режим; «ОстаткиНоменклатуры» — по номенклатуре и по сроку годности (`Новый Диапазон(НачалоДня, )`); «Себестоимость» — по номенклатуре. **Правило:** блокируем те же поля, по которым накладывается отбор при получении остатков (отбор в параметрах виртуальной таблицы = поля блокировки).
8. Движения (ФИФО по сроку годности):
   - расход «ОстатковНоменклатуры» на количество по сроку (детальные записи);
   - расход «Себестоимость» — по итоговой записи: **если списываемое количество равно общему остатку номенклатуры**, берётся вся стоимость остатка (условие последнего списания), иначе `ИтоговаяСтоимостьОстаток / ИтоговоеКоличествоОстаток * Количество`;
   - приход «ОборудованияВЭксплуатации» (срок годности, срок эксплуатации, количество и **стоимость**, рассчитанная как себестоимость единицы × количество по этому сроку).
9. **Погрешность округления:** себестоимость единицы округляется (`Окр(..., 2)`), и сумма стоимостей по срокам годности может разойтись с суммарным списанием по «Себестоимости» на копейку. Решение: накопить `ИтогоСебестоимостьОборудования`; после цикла вычислить разницу со списанной себестоимостью и **скорректировать последнюю запись** набора «ОборудованияВЭксплуатации». Зрители возражали: корректировка последней записи может привести к неверным результатам (отрицательная стоимость), а «округление» могут посчитать упрощённым алгоритмом. Автор попросил аргументы в комментариях.
10. Замечание «Белоусов рекомендует обрабатывать регистры последовательно, а не одним запросом» — автор не знает аргументов и не видит смысла.

## Выбытие оборудования
Добавляется регистр «Себестоимость» (расход).
- Запрос: просроченные записи (`СрокГодности < &НачалоДня`) из «ОстатковНоменклатуры` (детальные), левое соединение с «Себестоимость» (итоговое количество и стоимость остатка по номенклатуре), **итоги** по номенклатуре (`МАКСИМУМ`). Для оборудования в эксплуатации — прежний запрос.
- Расход «Себестоимость»: по итоговой записи — **если количество просроченного равно общему остатку**, вся итоговая стоимость; иначе пропорционально.
- Расход «ОстатковНоменклатуры» — по детальным записям (количество — просроченное).
- Блокировки: «Себестоимость» — весь регистр (срока годности в нём нет); остальные — как в уроке 24 (диапазоны сроков).
- В коде нужно задавать «Период» (максимум итоговой записи) и количество в движениях (из «КоличествоОстатокПоСроку»).

## Замечания
- «Пояснительная записка» — место для обоснования выбора разреза себестоимости.
- Белоусов и курсы 1С используют упрощения; на экзамене допустима любая методика, если она не противоречит условию.
