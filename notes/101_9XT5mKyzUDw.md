# Урок 101. Диаграмма Ганта (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=9XT5mKyzUDw · ~15 мин · [полный текст](../transcripts/101_9XT5mKyzUDw.md)

## О чём урок
Последнее условие билета № 15: **«С помощью диаграммы Ганта показать фактический период действия записей с разбивкой по сотрудникам и для каждого сотрудника — по видам расчёта.»** Это **единственный отчёт, для которого не нужна СКД**: отчёт — обычный объект без схемы компоновки, на форме размещается элемент **«ДиаграммаГанта»**.

## Создание
1. Отчёт «ДиаграммаГанта» (подсистема «Расчёты»), **без схемы компоновки**, форма отчёта (можно под произвольной формой).
2. Реквизит формы — **«Период» (`СтандартныйПериод`)** (не обязателен, но удобно); поле «Период» на форме; **«Автоматическое сохранение данных в настройках» = «Использовать»** (в свойствах формы; для поля «Период» появляется флажок «Сохранять») — период запоминается при закрытии формы («в 90 % случаев полезно для служебных полей»).
3. **Реквизит «ДиаграммаГанта»** (тип «ДиаграммаГанта») — разместить на форме; заголовок формы: «Диаграмма Ганта» (убрать авто-заголовок).
4. **Команда «Сформировать»** (не называть командой с типовым именем метода «Сформировать» — имя занято? автор отметил, что у метода типового объекта такое есть, и «лучше не повторять имена метаданных»; клиентская процедура → серверная `СформироватьНаСервере`), кнопка по умолчанию рядом с периодом.
5. На сервере: запрос → **очистить диаграмму** (`ДиаграммаГанта.Очистить()` — **обязательно перед заполнением**, иначе остаются старые интервалы) → заполнить.

## Запрос
`ФактическийПериодДействия` регистра расчёта «ОсновныеНачисления»: `Сотрудник`, `ВидРасчета`, `ПериодДействияНачало`, `ПериодДействияКонец` (+ `Регистратор` для расшифровки). **Отбор — по периоду ДЕЙСТВИЯ, а не по периоду регистрации** («единственный отчёт, где период — действие»): `ПериодДействияНачало >= &НачалоПериода И ПериодДействияКонец <= &КонецПериода` (параметры — `Период.ДатаНачала`, `Период.ДатаОкончания`; «начало периода» — перед концом). Если отобрать по периоду регистрации — вместо осмысленной диаграммы «дичь» (сентябрьский больничный, введённый в октябре, пропадёт).
- Условие «ошибку занёс специально»: период регистрации давал «странный» результат — показ только октябрьских записей.

## Заполнение диаграммы
Принцип (запомнить как заклинание): **«установить точку → установить серию → получить значение»**:
```bsl
ДиаграммаГанта.Очистить();
Пока Выборка.Следующий() Цикл
    Точка = ДиаграммаГанта.УстановитьТочку(Выборка.Сотрудник);      // ТОЧКА — сущность, по которой отслеживаем (сотрудник)
    Серия = ДиаграммаГанта.УстановитьСерию(Выборка.ВидРасчета);      // СЕРИЯ — показатель (вид расчёта)
    Значение = ДиаграммаГанта.ПолучитьЗначение(Точка, Серия);        // значение на пересечении
    Интервал = Значение.Добавить();                                  // Интервал — отрезок на диаграмме
    Интервал.Начало = Выборка.ПериодДействияНачало;
    Интервал.Конец  = Выборка.ПериодДействияКонец;
КонецЦикла;
```
- «**Белоусов не пишет больше ни одного слова**» — этого достаточно (диаграмму включают в подсистему «Расчёты»).
- **Цвета:** по умолчанию случайные; можно задать `Интервал.Цвет = WebЦвета.ЗеленаяЛужайка` (оклад) / `Синий` (больничный) по виду расчёта (`ПланыВидовРасчета.ОсновныеНачисления.Оклад`); «Белоусов не делает — можно не заморачиваться». Легенду и тексты не трогать.
- **Расшифровка:** `Интервал.Расшифровка = Выборка.Регистратор` — по клику по отрезку открывается документ (если отрезок — пересечение, система предлагает выбор: «оклад» или «больничный, вытеснивший оклад»).
- Октябрь: оклад (красненький/зелёный), больничный, вытеснение, сторно-оклад — интервалы разного цвета; сентябрь — сторнирование оклада задним числом.
