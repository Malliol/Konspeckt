# Урок 125. Задачи и регламентные задания (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=nrABKx05IkA · 84 мин · [полный текст](../transcripts/125_nrABKx05IkA.md)

## Условие
С помощью **регламентного задания по расписанию каждый день формировать задачи сотрудникам** на создание **отчёта о проделанной работе**. Задача создаётся для сотрудников, числящихся в регистре сведений «СведенияОСотрудниках» на момент формирования. **По мере возникновения задач у пользователя автоматически открывается форма каждой его невыполненной задачи.**

## Объект «Задача» («ЗадачаИсполнителю»)
- Подсистема «Управляемые формы»; «Адресация» не трогать (достаточно реквизита **«Исполнитель»**, ссылка на «Сотрудники», «Выдавать ошибку»).
- Реквизит **«ПеречньРабот»** — строка неограниченной длины, **многострочный режим**. Длина наименования — 100.
- Для различения отчётных задач — **реквизит-флажок «ОтчетОПроделаннойРаботе» (булево)** (иначе не отличить задачи от ручных; идея автора).

## Создание задач (обработка «СозданиеЗадач» → команда → серверный метод)
- Запрос: `РегистрСведений.СведенияОСотрудниках.СрезПоследних(&ТекущаяДата)` (**сотрудники без дублей** — РАЗЛИЧНЫЕ); **левое соединение** с задачами за сегодня: `Задача.ДатаСоздания >= &НачалоДня` (и `ОтчетОПроделаннойРаботе = Истина`), оставить записи **`Задача.Ссылка ЕСТЬ NULL`** — чтобы **не создавать дубли** при повторном запуске.
- В цикле: `ЗадачаОбъект = Задачи.ЗадачаИсполнителю.СоздатьЗадачу(); ЗадачаОбъект.Дата = ТекущаяДата(); ЗадачаОбъект.Наименование = "Отчет о проделанной работе"; ЗадачаОбъект.Исполнитель = Выборка.Сотрудник; ЗадачаОбъект.ОтчетОПроделаннойРаботе = Истина; ЗадачаОбъект.Записать();`
- Параметры запроса: `НачалоДня(ТекущаяДата())`.
- Для проверки — наполнить «СведенияОСотрудниках» (3 сотрудника).

## Автоматическое открытие формы задачи (модуль управляемого приложения)
```bsl
Процедура ПриНачалеРаботыСистемы()
    ПодключитьОбработчикОжидания("ПоказатьФормыЗадач", 300);   // для проверки — 5 сек
КонецПроцедуры

Процедура ПоказатьФормыЗадач() Экспорт     // без параметров, обязательно Экспорт
    Задачи = РаботаСЗадачамиВызовСервера.СписокЗадачТекущегоПользователя();
    Для Каждого Задача Из Задачи Цикл
        ОткрытьФорму("Задача.ЗадачаИсполнителю.ФормаОбъекта", Новый Структура("Ключ", Задача));
    КонецЦикла;
КонецПроцедуры
```
- `ПодключитьОбработчикОжидания("Имя", Интервал[, Однократно])` — таймер; процедура — **без параметров, экспортная** (иначе ошибка). Исполняется весь сеанс, так что новые задачи, появившиеся позже, тоже откроются.
- **Серверная часть — общий модуль с флажком «Вызов сервера»** (напр. «РаботаСЗадачамиВызовСервера»), экспортная функция `СписокЗадачТекущегоПользователя()`: запрос — `Исполнитель = &ТекущийПользователь` (**параметр сеанса «ТекущийПользователь»**; по условию выбирает соответствие), `НЕ Выполнена`, `НЕ ПометкаУдаления`, `ОтчетОПроделаннойРаботе`; результат — **массив ссылок** (не колонка выгрузки — экзаменаторам не нравится).
- Параметр формы **«Ключ»** — ссылка на задачу, чтобы открылась форма именно этой задачи.

## Проблема: форма открывается снова и снова
Каждые 5 секунд появляются новые окна для той же задачи. Варианты:
1. **Для экзамена (достаточно):** подключать обработчик **однократно** (`Однократно = Истина`).
2. Режим открытия окна **«Независимый»** (`РежимОткрытияОкнаФормы.Независимый`) — «вариант для бедных»: окна не плодятся (но если на скриншоте внутри главного окна, может не подойти).
3. **Флажок «Показано»** в задаче (решение курсов 1С.рф): отмечать при показе. Автор считает странным: получение списка изменяет данные.
4. **Уникальность** — 5-й параметр `ОткрытьФорму` (`КлючУникальности`): по описанию повторного открытия **не** должно быть (форма активируется), но в эксперименте **не сработало** (идентификаторы окон «слетают»; через `ПолучитьФорму` тоже нет). Причина не выяснена.
5. **Надёжный (но длинный) вариант** — через **`ПолучитьОкна()`**: в цикле по окнам взять `Окно.Содержимое[0]` (форма клиентского приложения), прочитать `Форма.Параметры.Свойство("Ключ", Ключ)` (не у всех форм есть ключ — только у форм элементов; ключ **по ссылке**, а не по `УникальныйИдентификатор`/ключу уникальности, которые нестабильны); если ключ равен ссылке на задачу — `ОкноНайдено = Истина`; форму открывать только если `Не ОкноНайдено`. Лишние условия на тип (`Окно.Содержимое.Количество() > 0`, `ТипЗнч(...) = Тип("ФормаКлиентскогоПриложения")`) — для страховки.

## Регламентное задание
- Метаданные: «РегламентныеЗадания → СозданиеОтчетовОВыполненнойРаботе»; **имя метода** — обязательно; метод должен быть в **серверном общем модуле** (флажки «Сервер», «Внешнее соединение»; имя модуля **не «РегламентныеЗадания»** — служебное слово), процедура **экспортная** (без этого её не будет видно при выборе). В методе — весь код создания задач (из обработки не вызывается). Предопределённое можно не ставить (иначе расписание берётся из настроек и всё равно править).
- Создание задания программно (команда обработки «СоздатьЗадание», `&НаСервере`):
```bsl
Отбор = Новый Структура("Метаданные", Метаданные.РегламентныеЗадания.СозданиеОтчетовОВыполненнойРаботе);
Для Каждого Задание Из РегламентныеЗадания.ПолучитьРегламентныеЗадания(Отбор) Цикл
    Задание.Удалить();                                 // чтобы не плодить копии
КонецЦикла;
Задание = РегламентныеЗадания.СоздатьРегламентноеЗадание(Метаданные.РегламентныеЗадания.СозданиеОтчетовОВыполненнойРаботе);
Задание.Расписание.ПериодПовтораДней = 1;              // каждый день
Задание.Расписание.ВремяНачала = ВремяНачала;           // реквизит формы (дата-время)
Задание.Использование = Истина;
Задание.Записать();
```
- **Проблемы:** по клику создаётся новое задание без удаления прежних — старые продолжают работать (получилось 3 задания) — **удалять задания перед созданием** (кнопка «Удалить задание»: `ПолучитьРегламентныеЗадания(Отбор)` → `Удалить()`). Отбор поддерживает уникальный идентификатор, ключ, метаданные.
- **Расписание** (`РасписаниеРегламентногоЗадания`): период повтора дней = 1, время начала; для интерактивного редактирования — **диалог расписания** `Новый ДиалогРасписанияРегламентногоЗадания(Расписание)`.
- Проверка: создали задание на ближайшие минуты — форма задачи открылась после времени начала; в боевом варианте — интервал 300 секунд.
