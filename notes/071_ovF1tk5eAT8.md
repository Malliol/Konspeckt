# Урок 71. Расчёт командировки (СПР). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=ovF1tk5eAT8 · 72 мин · [полный текст](../transcripts/071_ovF1tk5eAT8.md)

## О чём урок
Работа над ошибками по билету № 1 (премия) и разбор **билета № 3 по СПР**: оклад + **командировка**, которая вытесняет оклад и считается по средней часовой ставке за два предыдущих месяца. Автор сдал экзамен в прошлую субботу (поэтому был пропуск).

## Работа над ошибками (билет № 1)
- **Стаж «на момент начала ведения учёта в базе»**: вместо даты приёма использовать **константу «ДатаНачалаУчётаВБазе»** (включить в подсистему: ПКМ → «дополнительно»). Стаж = `РАЗНОСТЬДАТ(ДатаНачалаУчёта, ПериодРегистрации, ДЕНЬ) + НачальныйСтажДней`; при пустой константе — сообщение и выход (в «РассчитатьНачисления»).
- Документ «НачислениеЗарплаты»: **запретить оперативное проведение**.
- **Флажок «Базовый»** поставить у измерений (сотрудник и др.), участвующих в получении базы, **в обоих регистрах** (основные и дополнительные начисления) — для индексов.
- В отчёте «Анализ премий» при обращении к основной таблице движений (не к виртуальной) лучше писать **Активность = ИСТИНА**.
- Убрать `Отказ = Истина` в процедурах, где нет параметра Отказ.
- Вывод сообщения из обработки проведения без отказа — через форму объекта (лайфхак, для экзаменатора сомнительно).

## Билет № 3: условие
- Метод отклонений; **совместительство допускается** → «Подразделение» — измерение в регистре расчёта, документе, «СведенияОСотрудниках» (ведущее, проверка); оклад берётся по паре сотрудник + подразделение.
- Все по пятидневке, но предусмотреть другие графики.
- Оклад — пропорционально отработанным дням.
- **Командировка**: протяжённый вид расчёта в «Основных начислениях» (период действия), **вытесняет оклад**.
- **Часы командировки считаются по шестидневному графику**.
- **Часовая ставка** = начисления по окладу за два предыдущих месяца / отработанные часы за эти месяцы (по основному месту работы — не моделируется).

## Реализация
- **Вытеснение:** у вида расчёта «Оклад» флажок «Вытесняющий»-связь (вытесняется командировкой); проверка по таблице `ФактическийПериодДействия`: оклад 1–4, командировка 5–10, оклад 11–31.
- **График командировки:** предопределённый элемент «Шестидневка» справочника графиков; в движении для командировки: `Движение.ГрафикРаботы = Справочники.ГрафикиРаботы.Шестидневка`.
- **Регистр «ГрафикРаботы»:** ресурсы **«Дней»** (переименовано из «Значение») и **«Часов»**; обработка заполнения графика пишет две строки (рабочий день = 1 день / 8 часов); правки запроса расчёта оклада (брать дни). Подразделение в «ГрафикРаботы» не нужно.
- **База командировки:** план «Основные начисления» — «ЗависимостьОтБазы» по периоду действия, база — оклад (сам на себя); в регистре расчёта включить «Базовый период».
- **Ресурс «ОтработаноЧасов» (5/2)** в регистре расчёта (реквизит нельзя — база суммирует только ресурсы); заполняется из `ЗначениеФактическийПериодДействия` (часы).
- **Базовый период командировки:** `БазовыйПериодНачало = ДобавитьМесяц(ПериодРегистрации, -2)`, `БазовыйПериодКонец = ПериодРегистрации − 1 секунда` (два предыдущих полных месяца).
- Для тестов: нужны документы за предыдущие месяцы с датой действия в этих месяцах (не забыть менять даты).

## Запрос командировки
- Таблица `База` с отбором `ВидРасчета = &Командировка`, массив измерений (сотрудник, подразделение); поля `РезультатБаза` (начислено оклада) и `ОтработаноЧасовБаза`.
- Соединение базы с основными данными **по НомеруСтроки**; **левое соединение + `ЕСТЬNULL`** обязательны.
- Псевдонимы: «НачисленоОкладаЗаБазовыйПериод», «ОтработаноЧасовЗаБазовыйПериод».
- Формула: `Результат = (НачисленоОклада / ОтработаноЧасовБаза) × ОтработаноЧасов`, с проверкой деления на ноль. Пример: 177 272,73 / 312 × 40.
- Реквизит «значение графика» в регистре расчёта не важен (график получаем запросом, объектную модель не используем).

## Что можно не делать на экзамене
Условное оформление / недоступность графика для командировки в документе — времени нет, не требуется.
