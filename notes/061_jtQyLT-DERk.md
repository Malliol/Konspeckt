# Урок 61. Продажи через агентов (БУ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=jtQyLT-DERk · 48 мин · [полный текст](../transcripts/061_jtQyLT-DERk.md)

## О чём урок
Бухгалтерская задача про **агентское вознаграждение**: продажа товара самостоятельно или **через агента**; агенту начисляется **20 % от прибыли** (продажа − себестоимость), **в валюте агента**, не подлежащей пересмотру; выплата — «Операцией». База — выгрузка занятия 41. Автор впервые вставил **готовую заготовку** обработки проведения расходной накладной (контроль остатков и списание «как всегда»), сосредоточившись на новой части.

## Условие
- Торговля **самостоятельно или через агента**; в обоих случаях — документ «Расходная накладная»; при продаже через агента заполняется **реквизит шапки «Агент»** (необязательный). «Контрагент» в расходной накладной можно не заводить (подразумевается реальный покупатель; оценку не снизят).
- В табличной части — цены, по которым покупатель приобретает позиции. Учёт — по складам (в шапке склад).
- **Агент получает 20 % от разницы между суммой продажи и себестоимостью**; начисление вознаграждения — проводкой при проведении расходной накладной; **выплата** вознаграждения — **вручную «Операцией»**.
- Учёт в рублях, **с агентами дополнительно ведётся в валюте**; **для каждого агента установлена своя валюта, не подлежащая пересмотру**. Валютная сумма = **рублёвая сумма / курс валюты агента** (регистр «КурсыВалют»). Отчёт «Задолженность перед агентами».

## Настройка
- Справочник **«Агенты»** (отдельный; реквизит «Валюта» — справочник «Валюты», проверка заполнения). В расходной накладной реквизит «Агент» (ссылка, **не** обязательный), на форме.
- План счетов: **новый счёт «Агенты»** (активно-пассивный, как поставщики; остатки нужны); субконто — **агент** (вид «Агенты»; составной тип «Агенты» в ПВХ «ВидыСубконто», также «Склады»); **валютный признак учёта** (признак учёта «Валютный» связан с ресурсом **«СуммаВал»** (12/2, **не балансовый** — указывается только на стороне счёта «Агенты»; у других счетов флажок не ставят)); для счёта «Товары»: номенклатура + склады (максимум субконто 2, количественный учёт).
- **Требование «валюта не подлежит пересмотру»:** валюту «зашивают» **в агента** — **не создавать измерение «Валюта» и не добавлять реквизит валюты в документ и регистр** (иначе балл снизят: «если валюта подлежит пересмотру — зашивают в документы/регистр; если не подлежит — только в справочник агентов»). Для надёжности можно **запретить менять валюту у агента**: в `ПередЗаписью` справочника «Агенты» — `Валюта` сравнивается со старой валютой из базы; изменение → «сообщить», `Отказ`.
  - Общий модуль «ОбщегоНазначения» (серверный; флаги «Сервер», «Внешнее соединение»; по стандартам): функция **`ВалютаАгента(Агент)`** — запрос `ВЫБРАТЬ Агенты.Валюта ИЗ Справочник.Агенты ГДЕ Ссылка = &Агент` (результат — валюта или `Неопределено`); автор не обращается «через точку» (допустимо на экзамене, но «не хочется»). В `ПередЗаписью`: `СтараяВалюта = ВалютаАгента(Ссылка)`; **если `СтараяВалюта <> Неопределено` и `СтараяВалюта <> Валюта` → «Нельзя менять валюту», `Отказ`** (ошибка в уроке — забыли `Отказ`). Совет автора: в реальной системе запрещать менять валюту только если агент уже использован; на экзамене можно «в лоб». Критика Дмитрия: можно проверить на форме при записанном объекте — автор отвергает: **программная смена валюты агента испортит все движения** (миллион записей «в другой валюте»).
- Начальные остатки: закупка «Операцией» — Дт «Товары» (кинокамеры, основной склад, 100 шт. по 50 000) — Кт «Поставщики».
- Документ «Операция» — обновить (убрать таблицу движений и вернуть).

## Расходная накладная (заготовка + агентское вознаграждение)
Основная часть (скопирована): очистка движений, `Записывать = Истина`, запрос остатков со складом из шапки, блокировка товаров и склада, контроль остатков, списание по средней, **накопление `СебестоимостьИтого`**, проводка Дт «Покупатели» — Кт «Прибыли и убытки» на продажу; затем **если агент заполнен**:
1. **Валюта агента:** `Валюта = ОбщегоНазначения.ВалютаАгента(Агент)`.
2. **Курс:** `РегистрыСведений.КурсыВалют.ПолучитьПоследнее(Дата, Новый Структура("Валюта", Валюта)).Курс` — структура **всегда** возвращается; **для рубля курса нет → 0**: если `Валюта <> Рубль И Курс = 0` → «Не указан курс валюты агента», `Отказ`, `Возврат`; для рубля `Курс = 1` (т. к. курс 0 → заменить на 1 — деление). Ноль курса невозможен для остальных (у ресурса «Курс» «неотрицательное, мин. 1»).
3. **Вознаграждение (₽)** = `Окр(0,2 × (СуммаПоДокументу − СебестоимостьИтого), 2)`; **в валюте агента** = `Окр(ВознаграждениеРуб / Курс, 2)`. **Проводку делают только если оба > 0:** при отрицательной прибыли («штрафовать агента нельзя») — вознаграждения нет; при очень малой сумме округление до 2 знаков даёт 0 — **строки с нулевой суммой не формируют** (ошибки в уроке: «две тысячные» → записывается 0 / 20 копеек → 0 центов).
4. Проводка: **Дт «Прибыли и убытки» — Кт «Агенты»** (`СубконтоКт[Агенты] = Агент`, `Сумма = ВознаграждениеРуб`, **`СуммаВал = ВознаграждениеВал`** — по кредиту, на стороне счёта «Агенты»).
- Замечание зрителя «имя фамилия»: `Отказ` внутри условия — переносить: после проверки курса — `Если Отказ Тогда Возврат`.

## Выплата вознаграждения («Операция»)
Дт «Агенты» (`СубконтоДт`: агент; **сумма в валюте — 125**, сумма в рублях — 10 000) — Кт «Касса» (счёт кассы — **рублёвый, без валютного учёта**; «валюта — только на «Агентах»»; на кассе всегда рубли).
- Корреспонденция — **с кассой**, а не с «Прибылями и убытками» (убыток уже отражён при начислении).

## Отчёт «Задолженность перед агентами»
- `Управленческий.Остатки(&МоментВремени, Счет = &Агенты, &ВидыСубконто (агенты))`: агент (`ВЫРАЗИТЬ(Субконто1 КАК Справочник.Агенты)` — **обязательно**, иначе лишние левые соединения: для составного типа), **валюта = `Агент.Валюта`** (после приведения), **`СуммаВалОстатокКт`**, **`СуммаОстатокКт`** (нужен только **кредитовый остаток** — «задолженность перед агентами»; дебетовый — «агент нам должен»).
- СКД: параметр «Период» (начало завтрашнего дня), счета, виды субконто; детальные записи: агент, валюта, валютная сумма, рублёвая сумма. Заголовки и оформление — самостоятельно.
