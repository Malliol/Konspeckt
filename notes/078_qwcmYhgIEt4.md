# Урок 78. Сменный график (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=qwcmYhgIEt4 · 35 мин · [полный текст](../transcripts/078_qwcmYhgIEt4.md)

## О чём урок
Новый билет по СПР, решаемый **заново с выгрузки занятия 66** (первая подготовленная конфигурация): **три смены по графику «сутки через двое»**, **оплата по часовому тарифу**, тарифная ставка задаётся **для каждой смены отдельно** и может меняться каждый день.

## Условие
- Начисление зарплаты — **метод отклонений**; **совместительство допускается** (в регистре расчёта и документе — «Сотрудник» + «Подразделение»).
- Сотрудники каждого подразделения работают **в три смены по графику «сутки через двое»**.
- Оплата **по часовому тарифу: сумма = тарифная ставка × фактически отработанные часы**.
- **Тарифная ставка** задаётся **для каждой смены** и **может меняться каждый день** → периодический регистр сведений по дню.

## Графики работы
- В справочнике «ГрафикиРаботы» удалить «Пятидневка/Шестидневка», завести **«Смена 1», «Смена 2», «Смена 3»**.
- Часы: **24 часа** в рабочий день (в графике нужны часы — считаем фактически отработанные часы), **0 — в двух выходных**; смены сдвинуты на день (все три вместе дают круглосуточную работу): смена 1 работает 1, 4, 7…; смена 2 — 2, 5, 8…; смена 3 — 3, 6, 9…
- **Обработка «ЗаполнениеГрафика»** (цикл по дням от даты начала до даты окончания): вместо проверки «выходной день недели» вводится **«шаг» цикла (1–2–3)**: шаг 1 → `Значение = 24`, иначе 0; после записи — `Если Шаг = 3 Тогда Шаг = 1; Иначе Шаг = Шаг + 1`. Выходные заполняются нулями — как в каркасе для пятидневки.
- **Вариант зрителя (метод Юрия Зайцева):** писать только рабочие дни, а дату сдвигать **сразу на 3 суток** (`Дата = Дата + 3 * 86400`) — проще, ошибкой не будет (у Прохорова так), но выходные в графике не заполняются. Автор предпочитает нули в выходные «по аналогии с каркасом». В обработку добавлен флаг «Заполнение по методу Зайцева» для сравнения; в своём цикле автор сначала забыл, что шаг дат нужно умножать на 3.
- Для смены 2 и 3 заполнять отдельно со сдвигом начальной даты (2 и 3 августа).

## План видов расчёта и регистр
- Вид расчёта **«Оплата по часовому тарифу»** (в «Основных начислениях», период действия — полная аналогия с окладом; **не оставлять название «Оклад»**: «распишитесь в непонимании» — оклад и часовая ставка — разные вещи). Длинные строки кода переносить (не более ~120 символов — стандарты).
- Связь регистра расчёта с графиком: реквизит «ГрафикРаботы» ↔ одноимённое измерение регистра «ГрафикРаботы».
- **Регистр сведений «ТарифныеСтавки»** (периодический, в пределах дня; подсистема «Расчёты»): измерение **«ГрафикРаботы»** (ведущее, запрет незаполненных, «Выдавать ошибку»), ресурс **«ТарифнаяСтавка»** (10/2, неотрицательное, «Выдавать ошибку»). Данные: смена 1 — 1 500, смена 2 — 2 000, смена 3 — 3 000 (с 01.01.2020).

## Подготовка записей и расчёт
- Подготовка (по шаблону, «на автомате»): `ПериодРегистрации = НачалоМесяца(Дата)`; `Движения.ОсновныеНачисления.Записывать = Истина`; для каждой строки: `ЗаполнитьЗначенияСвойств`, `ПериодДействияНачало = Строка.ДатаНачала`, `ПериодДействияКонец = КонецДня(Строка.ДатаОкончания)`; запись.
- Запрос:
  1. `ВТ_Начисления` ← `ОсновныеНачисления.ДанныеГрафика(Регистратор = &Ссылка)`: `НомерСтроки`, `ГрафикРаботы`, `ЕСТЬNULL(ЗначениеФактическийПериодДействия, 0)` → «ОтработаноЧасов»; **индекс по графику**.
  2. Левое соединение со **срезом последних** `ТарифныеСтавки.СрезПоследних(&ПериодРегистрации, ГрафикРаботы В (ВЫБРАТЬ ГрафикРаботы ИЗ ВТ…))` по графику; `ЕСТЬNULL(ТарифнаяСтавка, 0)`. **Срез — только по нужным сменам** (в запросе, не по всем).
- Цикл: `Выборка.Сбросить(); Если Выборка.НайтиСледующий(Движение.НомерСтроки, "НомерСтроки") Тогда ЗаполнитьЗначенияСвойств(Движение, Выборка); Движение.Результат = Выборка.ОтработаноЧасов * Выборка.ТарифнаяСтавка`. Запись **`Записать(, Истина)`**.
- Реквизиты регистра расчёта (параметры): «ОтработаноЧасов» (15/2), «ТарифнаяСтавка» (10/2).
- Пример: Бердыев (смена 1) — 240 часов × 1 500 = 360 000; Васина (смена 2) — больше (ставка 2 000).

## Ошибка «необходим перерасчёт фактического периода действия» (вопрос зрителя Рафаэля)
Возникает при `Записать(, Истина)`, если **в запросе вытащили измерение** (сотрудник/подразделение) и `ЗаполнитьЗначенияСвойств` перезаписало измерение в движении. Правило: **в запросе расчёта выбирать только параметры, нужные для расчёта и реквизитов**, но не измерения и не график.

## Прочее
- Билетов решить предстоит 16 (по «фразам»), занятий ещё порядка 20–30.
- **Меняющаяся несколько раз в месяц ставка** — отдельная тема на потом (расчёт «по методу Зайцева», будет сложнее).
- Автор после сдачи экзамена считает решения «известными»; пользоваться Telegram-чатом для вопросов (меншн автора).
