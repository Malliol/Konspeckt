# Урок 117. Навигационные ссылки (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=oZw58jy8ntM · 15 мин · [полный текст](../transcripts/117_oZw58jy8ntM.md)

## О чём урок
Условие: **в форме документа «ПриходнаяНакладная» пользователь может вводить произвольный текстовый комментарий; текст может содержать навигационную ссылку (не более одной) на документ оплаты; переход по ссылке — при нажатии кнопки открытия соответствующего элемента управления формы.**

## Навигационная ссылка
Строка вида `e1cib/data/Документ.РасходДенег?ref=...` — есть у каждого объекта (Показать ссылку / Копировать ссылку). Идея: передать ссылку коллеге, он вставляет её в «Перейти по ссылке» и открывается объект. На практике почти не используется, но на экзамене может встретиться.

## Реализация
1. Реквизит документа «Комментарий» — строка (в уроке 500).
2. Поле на форме; чтобы растянуть на всю ширину — снять «Авто максимальная ширина».
3. Кнопка открытия у поля (две «квадратика») — свойство **«Кнопка открытия» = Истина**, обработчик **`ПриОткрытии`/«Открытие»** (событие открытия поля). По умолчанию обработчик что-то показывает; нужно **отключить стандартную обработку**: `СтандартнаяОбработка = Ложь`.
4. Документом оплаты приходной накладной является **«РасходДенег»** (а не «ПриходДенег» — оплата поступления = расход денег). Создать тестовый документ «РасходДенег» (поставщик, 600 000), скопировать его ссылку и вставить в комментарий: `Документ оплаты: <ссылка>`.
5. Разбор: комментарий разбить по пробелам, пройти по словам; слово, начинающееся с префикса ссылки на документ расхода (`e1cib/data/Документ.РасходДенег`), — переход; после первой найденной ссылки — **сразу `Возврат`** (не более одной).

```bsl
&НаКлиенте
Процедура КомментарийОткрытие(Элемент, СтандартнаяОбработка)
    СтандартнаяОбработка = Ложь;
    Слова = СтрРазделить(Объект.Комментарий, " ", Ложь);
    Для Каждого Слово Из Слова Цикл
        Если СтрНачинаетсяС(Слово, "e1cib/data/Документ.РасходДенег") Тогда
            ПерейтиПоНавигационнойСсылке(Слово);
            Возврат;
        КонецЕсли;
    КонецЦикла;
КонецПроцедуры
```
- `СтрРазделить(Строка, Разделитель, ВключатьПустые)` — третий параметр необязателен (по умолчанию Истина); пустые строки пропускаем (Ложь).
- `ПерейтиПоНавигационнойСсылке(Ссылка)` — при неверной ссылке выбрасывает исключение. Для красивого сообщения — `Попытка … Исключение Сообщить(КраткоеПредставлениеОшибки(ИнформацияОбОшибке())); КонецПопытки` (можно подробное; на экзамене допустимо и без обработки — исключение платформы тоже информативно).
