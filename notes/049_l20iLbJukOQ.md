# Урок 49. Порча товара (БУ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=l20iLbJukOQ · 55 мин · [полный текст](../transcripts/049_l20iLbJukOQ.md)

## О чём урок
Бухгалтерская задача (билет № 16 по нумерации автора): учёт товаров по партиям (ФИФО/ЛИФО по учётной политике) **без складов**, плюс **состояние товара** (испорченный / неиспорченный) и документ «Операция» для списания порчи; отчёт «Продажи» с разделением списанного и проданного. База — выгрузка занятия 43 (расходная накладная ФИФО/ЛИФО по партиям и складам); склады убираются.

## Подготовка (из урока 43)
- Удалить склад: реквизит в приходной накладной и расходной накладной, обращения в коде (блокировка по складу, отбор по складу), субконто «Склады» в плане счетов (**в пользовательском режиме склады не уберутся — удалить вручную**, иначе будет ошибка «превышение максимального количества видов субконто»); партии становятся **Субконто2**. Если запрос читает `Субконто3` — удалить (после удаления складов субконто3 нет).
- Тестовые данные: приход 10 шт. 1 апреля и 10 шт. 5 апреля; расход 15 шт. 1 мая; учётная политика ФИФО/ЛИФО меняет порядок списания.

## Условие (по тексту)
- **Порча товара:** товар периодически портится; испорченный товар **учитывается на счёте «Товары»**, но при продаже **необходимо отгружать только неиспорченный**; факт порчи фиксируется **пользователем вручную документом «Операция»**; списание испорченного — **тоже вручную**, проводкой Дт «Прибыли и убытки» — Кт «Товары».
- Проводки приходной/расходной — как в 43-м (Дт «Товары» — Кт «Поставщики»; Дт «Прибыли и убытки» — Кт «Товары» на себестоимость; Дт «Покупатели» — Кт «Прибыли и убытки»), **списание по партиям** в зависимости от учётной политики (на год).
- Отчёт: номенклатура, количество и сумма **списанного (испорченного)**, **проданного**, себестоимость.

## Состояние товара
- Нужен дополнительный разрез на счёте «Товары» → **субконто «СостоянияТоваров»**. Тип — **перечисление «СостоянияТоваров»** (значения «Неиспорченный», «Испорченный») — не булево/строка («примитивные типы без необходимости не добавляют»). Перечисление — в подсистему «Бухгалтерский учёт».
- ПВХ «ВидыСубконто» → составной тип: перечисление; предопределённый вид «СостоянияТоваров»; в плане счетов — у «Товаров»: номенклатура, партии, состояния товаров (3 субконто).
- **Приход:** `СубконтоДт[СостоянияТоваров] = Перечисления.СостоянияТоваров.Неиспорченный` (купили — значит неиспорченный). **Расход:** в запросе остатков отбор по состоянию — только неиспорченный (`Субконто3 = &Неиспорченный`), в проводке — `СубконтоКт[СостоянияТоваров] = Неиспорченный`. Виды субконто в массиве обновить (добавить состояния).
- Для отчёта «Продажи»: на счёте **«Прибыли и убытки»** добавляют субконто **«Номенклатура»** (только обороты) — состояние ему не нужно (отчёт не требует).

## Расходная накладная: изменения
- Запрос: `ВТ_Товары` (номенклатура, количество, **сумма** — для отчёта); соединение с `Остатки(&МоментВремени, Счет = &Товары, &ВидыСубконто, Субконто1 В (…), Субконто3 = &Неиспорченный)`; порядок — по моменту времени партии (`ВЫРАЗИТЬ(Субконто2 КАК Документ.ПриходнаяНакладная).МоментВремени`); ФИФО/ЛИФО по учётной политике (меняется порядок упорядочивания, см. урок 43).
- Движения: списание себестоимости — Дт «Прибыли и убытки» (**СубконтоДт[Номенклатура] = Выборка.Номенклатура**) — Кт «Товары» (номенклатура, партия, состояние). **Выручка — в цикле по номенклатуре** (Дт «Покупатели» — Кт «Прибыли и убытки» с субконто Кт «Номенклатура»), сумма — из итоговой записи (`МАКСИМУМ(Сумма)` в итогах).

## Документ «Операция» — порча
Порча = **перевод** товара из «неиспорченного» в «испорченное» состояние на **том же счёте**:
- Дт «Товары» (номенклатура, **партия та же**, состояние **«Испорченный»**, количество 3, сумма 30 000) — Кт «Товары» (номенклатура, партия, состояние **«Неиспорченный»**, количество 3, сумма 30 000).
- Затем отдельной «Операцией» **списание испорченного**: Дт «Прибыли и убытки» (номенклатура) — Кт «Товары» (испорченный, количество 3, сумма 30 000).
- **Важная проверка:** если не указать **количество** в операциях — остатки по количеству не изменятся (ошибка, найденная зрителями «имя фамилия» и др.: «почтальон Печкин не указал количество»). Операция не контролирует ввод; «через неё всякую ахинею можно вбить» — на практике частая причина проблем закрытия периода.
- Результат: порча 3 из партии №1 → последующая расходная на 15 шт. с ФИФО спишет 7 из партии 1 и 8 из партии 2.

## Отчёт «Продажи»
- Нужно: количество/сумма **продано**, количество/сумма **списано** (испорченное), себестоимость.
- Ошибка автора: сначала «обороты по счёту «Товары» с корсчётом» — неправильно; нужны **обороты по счёту «Прибыли и убытки»** (дебет: себестоимость + списание испорченного; кредит: сумма продажи).
- Запрос: `Управленческий.Обороты(&Начало, &Конец, , Счет = &ПрибылиИУбытки, &ВидыСубконто, , КорСчет В (&Товары), &КорВидыСубконто, КорСубконто … )` — **по счёту «Прибыли и убытки» с корсчётом «Товары» и корсубконто «Состояния товаров»** (КорСубконто3 = состояние); разделение:
  - `КоличествоСписано = ВЫБОР КОГДА КорСубконто1 = &Испорченный ТОГДА КоличествоОборотДт ИНАЧЕ 0 КОНЕЦ` и `КоличествоПродано` — иначе; аналогично `СуммаСписано` / себестоимость по `СуммаОборотДт` (испорченный → «списано», неиспорченный → себестоимость).
  - **Сумма продажи** — оборот по кредиту с корсчётом **«Покупатели»**. **У «Покупателей» нет субконто «Состояния товаров»**, поэтому запрос с корсубконто состояний теряет обороты по покупателям (**«сумма продано пропала»** — замечание зрителей). Решение: **отдельный запрос** оборотов с корсчётом «Покупатели» (без `КорВидыСубконто`) и **ОБЪЕДИНИТЬ ВСЕ** (в нём остальные колонки — нулевые).
  - Корсчета указывать обязательно (−баллов); виды субконто — только нужные (передача лишнего — медленнее); корсубконто используем только третье → в запросе «корсубконто 1» (так как массив из одного вида).
- Параметры в запросах — через **параметры** (а не значения в тексте): универсально; массив видов можно передать только параметром (Белоусов, литература, типовые — всегда параметры).
- `ВЫРАЗИТЬ(Субконто1 КАК Справочник.Номенклатура)`.
- СКД: параметры «Период», счета, виды субконто, состояния; **группировка по номенклатуре** (не детальные записи — иначе не схлопнется), **ресурсы** объявить; итоги по вертикали — отключить; заголовки колонок: «Количество списано», «Сумма списано», «Количество продано», «Сумма продано», себестоимость.
- Проверка: сменить сумму операции порчи на 50 000 — отчёт изменится; пометка удаления операции — спишется 0.

## Замечания
- Колонка статуса и «рассчитать по» — не применимо: итогов по группировкам нет. «Рассчитать по» нужно, чтобы выбрать группировки для итогов ресурсов.
- Комментарий автора: количественный учёт на «Товарах» нужен всегда (иначе остаток по количеству не получить); на экзамене можно использовать решения занятия 46. Просит присылать замечания экзаменаторов.
