# Урок 121. Форма подбора и перетаскивание (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=JwnqDvUQ5jg · 96 мин · [полный текст](../transcripts/121_JwnqDvUQ5jg.md)

## Условие
В форме документа «РасходнаяНакладная» — **специальная форма подбора**: пользователь выбирает произвольное число позиций номенклатуры, которые отображаются в таблице **«Отобранные товары»** (товар, количество); **перетаскивание мышью** из списка товаров в таблицу; по окончании подбора в табличной части документа появляются строки со всеми выбранными товарами в указанном количестве (замещение или добавление — формулировка неясна; автор делает добавление/суммирование по существующим строкам). **Полтора балла**, по словам зрителя, решается за 12–15 минут. Расположение таблиц — **как на скриншоте экзамена** (сверху/снизу/справа).

## Заготовка формы подбора
- Кнопка команды «Подбор» в командной панели табличной части документа; открывает форму подбора.
- Форма — общая форма «ФормаПодбора» (можно и форму документа/обработку; «в типовых по-разному»); **«Использовать стандартные команды» не ставить**, в подсистему не включать — самостоятельно не вызывается.
- Реквизиты: **динамический список «СписокНоменклатуры»** (основная таблица — справочник «Номенклатура», запрос не нужен, поля: код, наименование, «динамическое считывание данных», командную панель убрать, заголовок сверху) и **таблица значений «ОтобранныеТовары»** (колонки «Номенклатура» — `СправочникСсылка.Номенклатура`, «Количество» — число 10/0, не отрицательное; заголовок сверху).
- Форма должна **блокировать окно владельца** (свойство формы «Режим открытия окна») — иначе её можно оставить независимой; высоту списка номенклатуры можно ограничить (8 строк).
- Кнопка **«ПеренестиВДокумент»** — команда, **кнопка по умолчанию**.
- Код желательно разбивать по областям (обработчики событий формы / элементов / команд / служебные) — на экзамене не обязательно.

## Выбор двойным кликом (событие «Выбор» списка номенклатуры)
- «Выбор» — двойной клик/Enter; «ВыборЗначения» — только в режиме выбора (здесь режима выбора нет → не сработает). Используем **«Выбор»**.
- Для **групп** оставляем стандартную обработку (раскрытие/сворачивание), для **элементов** — `СтандартнаяОбработка = Ложь` (не открывать форму элемента) и добавляем в таблицу.
- Проверка «это группа» — **серверная функция `ЭтоГруппаНоменклатуры(Номенклатура)`** (на клиенте реквизиты не прочитать): запрос по ссылке с полем `ЭтоГруппа`; `Если Выборка.Следующий() Тогда Возврат Выборка.ЭтоГруппа; Иначе Возврат Ложь`. Предпочтительнее запроса — чтение одного поля, а не всего объекта (`Номенклатура.ЭтоГруппа` через точку читает все поля; на экзамене за это не снижают).
- Добавление: `НайденныеСтроки = ОтобранныеТовары.НайтиСтроки(Новый Структура("Номенклатура", ВыбраннаяСтрока))`; если 0 — новая строка с количеством 1, иначе `НайденныеСтроки[0].Количество = … + 1`.

## Перетаскивание
- Таблица списка: разрешить **«Разрешить начало перетаскивания»** (источник), запретить «Разрешить перетаскивание» (приёмник) и обратное — у таблицы отобранных товаров (приёмник: «Разрешить перетаскивание» вкл., «Начало перетаскивания» выкл.).
- Обработчик **«Перетаскивание»** приёмника (у приёмника; «ПроверкаПеретаскивания» — проверка допустимости, «ОкончаниеПеретаскивания» — в источнике, «НачалоПеретаскивания» — в источнике). В `ПараметрыПеретаскивания.Значение` — **массив ссылок** на перетаскиваемые строки (каталоги — тоже).
- **Вариант 1 (допустим на экзамене):** если элементов больше одного — сообщение «можно выбрать только одну позицию».
- **Вариант 2 (без запроса в цикле):** серверный метод `ПеренестиСписокНоменклатурыВОтобранные(СписокНоменклатуры)` — **один запрос** `ВЫБРАТЬ Ссылка ИЗ Справочник.Номенклатура ГДЕ Ссылка В (&Список) И НЕ ЭтоГруппа`; в цикле по выборке — серверный (`&НаСервере`) метод `ПеренестиТоварВОтобранные(Номенклатура)` (используется и в «Выборе» по двойному клику). Лишний серверный вызов в «Выборе» — не критично; **запрос в цикле — критично** (поэтому функцию `ЭтоГруппа` в цикле перетаскивания не вызываем).
- Обратное перетаскивание (уменьшение количества) — не просят, не делать.

## Передача данных в документ: оповещение
Способ 1 (часто в типовых): форма подбора открыта с **владельцем** — табличной частью; по «Перенести в документ» — **`ОповеститьОВыборе(Данные)`**, в документе ловится «ОбработкаВыбора».
Способ 2 (в уроке): **`Оповестить("ПодборТовара", Адрес, ЭтаФорма)`** — оповещаются **все открытые формы** (событие «ОбработкаОповещения» у любой формы, в т.ч. «ПриходДенег», других накладных):
- Открывать форму подбора с **владельцем = формой документа** (`ОткрытьФорму("ОбщаяФорма.ФормаПодбора",, ЭтаФорма, ЭтаФорма.УникальныйИдентификатор)`) → оповещение получит только владелец (если владелец — табличная часть, то лишних форм тоже нет, но форма-владелец надёжнее). Уникальность — `УникальныйИдентификатор` владельца (чтобы не открывалось несколько форм подбора; здесь окно блокируется, но в типовых указывается).
- В `ОбработкаОповещения` проверять `ИмяСобытия = "ПодборТовара"` и источник — `Источник.ВладелецФормы.ИмяФормы = ЭтаФорма.ИмяФормы` (защита от чужих событий) и **`ТипЗнч(Параметр) = Тип("Строка")` (адрес временного хранилища)**.
- Типовая закрытие формы: `Закрыть()` после оповещения (в типовых — флажок «ПеренестиВДокумент» и отправка в `ПриЗакрытии`; можно передать аргумент в `Закрыть`, оповещение о закрытии — усложнение).

## «Отобранные товары» — не настоящая таблица значений
- В отладчике реквизит формы типа «ТаблицаЗначений» (в скобках: **ДанныеФормыКоллекция**) — это **имитация**: настоящей таблицы значений на тонком/веб-клиенте нет. Её **нельзя** поместить во временное хранилище на клиенте и нельзя вызвать `.Выгрузить()` на клиенте (метод недоступен).
- Решение — **серверная функция** `ПоместитьОтобранныеТоварыВХранилище()`: `Возврат ПоместитьВоВременноеХранилище(ОтобранныеТовары.Выгрузить(), …);` либо **`РеквизитФормыВЗначение("ОтобранныеТовары")`** (получаем настоящую таблицу значений; результат тот же, автор склоняется к этому способу). Адрес вернуть на клиент и передать оповещением.
- Аналогично **реквизит «Объект» — не настоящий объект, а `ДанныеФормыСтруктура`**: методов объекта на клиенте нет («метод объекта не обнаружен»). Для вызова экспортного метода объекта — на сервере `ДокументОбъект = РеквизитФормыВЗначение("Объект"); ДокументОбъект.Метод(); ЗначениеВРеквизитФормы(ДокументОбъект, "Объект")`.

## Загрузка данных в документ
`ОбработкаОповещения` → серверная `ОбработатьДанныеПодбора(Адрес)`: `ДанныеПодбора = ПолучитьИзВременногоХранилища(Адрес);` для каждой строки подбора — отбор по номенклатуре в `Объект.СписокНоменклатуры`: нет строки — `Добавить()` и `ЗаполнитьЗначенияСвойств`; есть — **увеличить количество** (вариант «замещение» — `Объект.СписокНоменклатуры.Загрузить(ДанныеПодбора)`). Не забыть **пересчитать сумму** (на клиенте — вручную `Количество × Цена`; серверные расчёты в клиентском методе недоступны). Проверять, что параметр — адрес временного хранилища.

## Временное хранилище и параметр «Адрес/УникальныйИдентификатор»
- `ПоместитьВоВременноеХранилище(Значение, УникальныйИдентификаторИлиАдрес)` возвращает **адрес**.
- Если **передан уникальный идентификатор формы** — значение удаляется при закрытии этой формы (в типовых подбор так и сделан; данные успеваем обработать до удаления).
- Если **параметр не указан** — значение удаляется **перед обработкой следующего серверного запроса** (любой серверный вызов из формы/общего модуля — «чистка при следующем серверном вызове»); поэтому адрес повторно использовать нельзя. Можно не указывать идентификатор — работает.
- Чтобы данные жили, пока жива форма документа, передать **`ВладелецФормы.УникальныйИдентификатор`**; после обработки можно удалить вручную: `УдалитьИзВременногоХранилища(Адрес)`.
- Опыт на экзамене: без идентификатора форма подбора закрывается и значение исчезает; «ничего нет» → `ПолучитьИзВременногоХранилища` вернёт `Неопределено` (итератор не определён) — проверять.
