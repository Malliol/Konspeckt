# Урок 113. Пользователи и параметры сеанса (УФ). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=LUAUIl9euz8 · 27 мин · [полный текст](../transcripts/113_LUAUIl9euz8.md)

## О чём урок
Начало блока **«Управляемые формы» (УФ)** — 8–9 задач (билетов), «самый полезный раздел экзамена». Пользователи, роли и **параметр сеанса «ТекущийПользователь»** нужны в большей части задач УФ (и бизнес-процессов). Заготовка — **выгрузка после занятия 43** («расчёт себестоимости в разрезе складов и партий» — «волшебная выгрузка, подходящая под все случаи»).

## Что решаем дальше (билет № 16 по УФ)
«Доступ для пользователей по основным подсистемам нужно ограничить с помощью **функциональных опций**: возможность работы с подсистемой должна быть установлена **в соответствии с должностью сотрудника** (бухгалтер видит одно, менеджер — другое, директор — третье); **пользователь не должен получить доступ к секретному регистру этой подсистемы**» (само решение — в следующем уроке).

## Порядок сдачи
Задачи **УФ и бизнес-процессов — в конце** (по остаточному принципу): «ОУ + БУ + СПР — это уже 3 балла; перестанет запускаться после УФ — не сдал»; перед сдачей проверять запуск.

## Должность сотрудника
- Подсистема «УправляемыеФормы» (включить «оперативный учёт», добавить объекты).
- Справочник «Должности» (бухгалтер, менеджер, директор…); в справочник «ФизическиеЛица» — **реквизит «Должность»** (ссылка на «Должности», «Выдавать ошибку»).
- Физические лица Бельдыев/Жупиков и пр. заводят в справочнике (код = наименование = имя пользователя: **«код равен имени пользователя информационной базы»** — по нему сопоставляем).

## Пользователи и роль
- Конфигуратор → «Администрирование» → «Пользователи»: **создание пользователя требует хотя бы одного пользователя с административными правами** — нужна **роль «ПолныеПрава»** (в ветке «Роли»): «Подсистемы — доступ ко всем», флажки «Администрирование данных», «Администрирование», «Интерактивное удаление» (флажок «интерактивное удаление» — удобен на экзамене); **«Устанавливать права для новых объектов» (чёрный флажок «Все новые объекты») — для роли с полными правами обязателен** (иначе к новым справочникам нет доступа). Права — **«Установить все права»** (совет зрителя Андрея Кота: правой кнопкой по корню — одной кнопкой). На экзамене права почти не проверяют — «бездумно ставить все флажки».
- Пользователь: «Имя» (например, «Бельдыев»), «Полное имя», **роль «ПолныеПрава»**; **аутентификация — стандартная**, пароль — по желанию; тестовый пользователь «Жупиков» («Новиков»).

## Параметр сеанса «ТекущийПользователь»
- В конфигурации → «Параметры сеанса» → «ТекущийПользователь» — тип **«СправочникСсылка.ФизическиеЛица»** (отдельный справочник «Пользователи» не создавать); хранить **ссылку на физическое лицо**, соответствующее вошедшему пользователю (в типовых: текущий пользователь — в параметре сеанса, используется и в RLS, но на экзамене RLS нет).
- Установка — в **модуле сеанса** (корень конфигурации → «Модуль сеанса» → `УстановкаПараметровСеанса(ТребуемыеПараметры)`):
```bsl
Процедура УстановкаПараметровСеанса(ТребуемыеПараметры)
    ИмяПользователя = ПользователиИнформационнойБазы.ТекущийПользователь().Имя;   // менеджер пользователей — «глобальный контекст»
    ФизЛицо = Справочники.ФизическиеЛица.НайтиПоКоду(ИмяПользователя);
    Если ФизЛицо.Пустая() Тогда                       // не нашли — создаём (например, при входе нового пользователя)
        ФизЛицоОбъект = Справочники.ФизическиеЛица.СоздатьЭлемент();
        ФизЛицоОбъект.Наименование = ИмяПользователя;
        ФизЛицоОбъект.Код          = ИмяПользователя;
        ФизЛицоОбъект.Записать();
        ФизЛицо = ФизЛицоОбъект.Ссылка;
    КонецЕсли;
    ПараметрыСеанса.ТекущийПользователь = ФизЛицо;
КонецПроцедуры
```
- **Менеджер пользователей информационной базы** — «глобальный контекст»; `ТекущийПользователь().Имя`. Искать **по коду**, а не по наименованию (по коду «правильнее»; по реквизиту — смысла нет).
- Проверка: параметры сеанса нигде не видно (ни в консоли) — отладочная выдача `Сообщить(ПараметрыСеанса.ТекущийПользователь)`; вход под «Новиков» → в справочнике «ФизическиеЛица» создаётся запись (значок без кружочка = создан кодом).
