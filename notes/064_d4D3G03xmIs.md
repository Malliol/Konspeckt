# Урок 64. Отчёт по взаиморасчётам (БУ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=d4D3G03xmIs · 43 мин · [полный текст](../transcripts/064_d4D3G03xmIs.md)

## О чём урок
Завершение задачи № 3 (уроки 62–63): отчёт **«Взаиморасчёты за период»** с начальным/конечным остатком, оборотами и **регистратором**, в строках — контрагент и договор (отбор по валюте). Автор делает отчёт «с фотографической точностью» образца — на экзамене столь тщательное оформление, по его мнению, не нужно.

## Образец
Параметры: период, **валюта** (отбор: по умолчанию рубль; параметр обязателен); колонки: контрагент, договор, документ (регистратор), для каждой суммы — «в рублях / в валюте»: **начальный остаток**, **оборот**, **конечный остаток** (рублёвая над валютной); в первой строке группы показан контрагент, во всех остальных — пусто; «в образце зашита ошибка при составлении» — контрагент в той же строке, что и детальные записи.

## Запрос
- Таблица **`Управленческий.ОстаткиИОбороты(&НачалоПериода, &КонецПериода, Регистратор, ДвиженияИГраницыПериода/ДвиженияБезГраниц…, , Счет = &Покупатели, &ВидыСубконто, Валюта = &Валюта)`**: **периодичность «Регистратор»** (чтобы появилось поле регистратора), **метод дополнения — «Движения» (а не «Движения и границы периода» по умолчанию)** — иначе в отчёте появляются **пустые строки «граница месяца»**; отбор по валюте — в параметрах/условии (валюта — измерение).
- Поля: контрагент (`ВЫРАЗИТЬ(Субконто1 КАК Справочник.Контрагенты)`), договор (`ВЫРАЗИТЬ(Субконто2 КАК Справочник.Договоры)`), регистратор, `СуммаНачальныйОстаток`, `СуммаВалНачальныйОстаток`, `СуммаОборот`, `СуммаВалОборот`, `СуммаКонечныйОстаток`, `СуммаВалКонечныйОстаток`.
- **Оборот всегда положительный:** в одном поле `СуммаОборот` хранится дебетовый (+) и кредитовый (−) оборот; приход денег в образце показан положительной суммой — в запросе: `ВЫБОР КОГДА СуммаОборот > 0 ТОГДА СуммаОборот ИНАЧЕ -СуммаОборот КОНЕЦ` (аналогично для `СуммаВалОборот`).
- Выражения: `ВЫРАЗИТЬ` для субконто (обязательно: «аргумент “нет времени” — слабый»).

## СКД
1. Параметры: «Период» (стандартный, с выражениями начала/конца периода; «всегда», флажок), «Валюта» (**запрет не использовать, не указывать**; значение по умолчанию — российский рубль; у параметра **снять составной тип** — оставить только «Справочник.Валюты», иначе в выборе лишние типы), счета, виды субконто (покупатели и договоры).
2. Структура: **группировка «Контрагент» → детальные записи** (в образце контрагент и договор в строках; «контрагент в той же строке, что детальные записи» — приём буковки). Расположение группировок — «Отдельно и только в итогах»; параметры вывода — «Не выводить»; итоги по вертикали — «Нет»; условное оформление: влево, отступ, формат даты, 2 знака.
3. **Контрагент выводится только в первой строке группы:** в выбранных полях контрагент **не** выводится выражением «номер по порядку в группировке»: `ВЫБОР КОГДА НомерПоПорядкуВГруппировке = 1 ТОГДА Контрагент ИНАЧЕ "" КОНЕЦ` (системные поля → «Номер по порядку в группировке»); у группировки отключить «Расположение» (так не выводится лишняя строка контрагента).
4. **Парные поля (рубли над валютой)** группируют «Вертикально» в «Выбранных полях» (по паре на колонку: начальный остаток, оборот, конечный остаток).
5. **Регистратор:** выражение представления: `ВЫБОР КОГДА ТИПЗНАЧЕНИЯ(Регистратор) = ТИП(Документ.РасходнаяНакладная) ТОГДА "Расходная накладная №" + ПОДСТРОКА? (номер без ведущих нулей) + " от " + дата … КОГДА … ПриходДенег ТОГДА "Приход денег №" … КОГДА ТИП(Документ.Операция) ТОГДА "Корректировка долга №" … КОНЕЦ` (оптимизация Ника Биллова: `ВЫБОР Регистратор КОГДА Документ.… ТОГДА`); (на экзамене автор это бы пропустил — «жалко время»). **Удаление ведущих нулей из номера** — общий модуль «РаботаСоСтроками» (серверный; флаги «Сервер», «Внешнее соединение»), функция `УдалитьВедущиеНули(Строка)` — `Пока Лев(Строка, 1) = "0" Цикл Строка = Сред(Строка, 2); КонецЦикла; Возврат Строка;`.
6. **Макеты**, чтобы повторить образец:
   - Шапка отчёта — группировка «детальные записи» (вариант использования «дополнительная информация», имя «Заголовок»); макет группировки: «Взаиморасчёты по контрагентам за период с [Начало] по [Конец], валюта [Валюта]» (шаблон, параметры; формат даты `ДФ=dd.MM.yyyy`); таблицу подчинить заголовку (без пустой строки).
   - Заголовок таблицы — **макет группировки «детальные записи»** (имя группировки + «Макет группировки», не «заголовка»): ячейки «Контрагент», «Договор», «Документ», пары «руб./вал.» над группами; границы рисуют **в макете**; чтобы они работали: **макет оформления отключить** для отчёта («без оформления»), иначе действует оформление и границы не рисуются; шапка таблицы — жирный, по центру; **ширина** — двойной клик по границе колонки (автоширина).
   - Границы между рублёвой и валютной суммой убрать (в макете у двух ячеек границы не рисуют).
   - Формат даты в оформлении группировки и в макете заголовка не должны конфликтовать — условное оформление (формат «в области заголовка») перебивает формат макета: перенести/удалить.
   - Валюту выводить кратко («USD»): дополнительное поле «КраткоеНаименование» у валют или просто переименовать валюту.
   - Нулевые значения (начальный остаток 0) в образце показаны «0» — настроить условным оформлением.

## Проверка по данным уроков 62–63
Расход (5 млн ₽ / 100 000 $) → оплата (6 млн ₽ / 100 000 $) → корректировка: **минус 1 млн ₽ (переплата по курсу) закрыт корректировкой на 1 млн прибыли** — конечный остаток в рублях и валюте стал **0**; для «красного пролетария» оплата «всё, что есть» (максимум 4 500 → 90 000 $).

## Прочее
- Автор советует подписаться на чат Прохорова (Лосяш и буковка — «опора» группы); `буковка` предложила способ вывода контрагента.
- Дальше — **двухнедельный перерыв**; следующая суббота — интервью, разговорный стрим.
