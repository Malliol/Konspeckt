# Урок 105. Сверхурочная работа «по плану, установленному заранее» (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=3wEUtcrLWgE · ~1 ч 20 мин · [полный текст](../transcripts/105_3wEUtcrLWgE.md)

## О чём урок
**Билет № 8** (валюты — в следующем уроке): оплата по часовому тарифу + компенсация за мобильные (уже разбирали) + **сверхурочная работа**. Новая в билетах (последние месяцы) формулировка — «**сотрудники могут работать сверхурочно по плану, установленному заранее**» — неоднозначная, автор обсуждает варианты и выбирает отдельный регистр сведений.

## Условие
- Метод отклонений; **все сотрудники работают по графику, установленному для каждого подразделения** (график = подразделение; совместительство не допускается/допускается — по билету).
- **Оплата по часовому тарифу** (ставка задана; в билете — в валюте, см. урок 106).
- **Сотрудники могут работать сверхурочно по плану, установленному заранее. За каждый час сверхурочно отработанного времени начисляется сумма в размере 150 % от средней часовой ставки за предыдущий месяц; средняя часовая ставка = сумма всех начислений за прошлый месяц / количество рабочих часов в прошлом месяце.**
- Процент 150 % → **константа «ПроцентОплатыСверхурочных»** (5/2).

## Конфигурация
- Вид расчёта **«Сверхурочные»** — «ДополнительныеНачисления» (нет начала и конца), **база — «ОплатаПоЧасовомуТарифу»** (по периоду действия; **«Базовый период» — предыдущий месяц**): `БазовыйПериодКонец = ПериодРегистрации − 1` (последняя секунда прошлого месяца), `БазовыйПериодНачало = НачалоМесяца(БазовыйПериодКонец)`; **для остальных видов — не заполнять** (условие `Если ВидРасчета = Сверхурочные`).
- Регистр «ДополнительныеНачисления»: измерения сотрудник, подразделение; реквизиты **«СверхурочныхЧасов»**, «БазаНачислений», «БазаРабочихЧасов», «ПроцентОплаты» (5/2); флажок «Базовый период»; ТЧ «ДополнительныеНачисления» в документе (без дат); **проверка пустого документа** в `ОбработкаПроверкиЗаполнения` (обе ТЧ пусты → ошибка).
- Регистр «ГрафикРаботы»: в билете график = подразделение; ресурсы «Часов» и «Дней».

## Три толкования «плана, установленного заранее»
1. **Ресурс «СверхурочноЧасов» в регистре сведений «ГрафикРаботы»** (решение Kate, «успешно применено на экзамене»; оценка неизвестна). **Недостаток:** график = подразделение → план можно задать только **для всего подразделения**; один сотрудник «не захочет работать сверхурочно» — нельзя. Автор не любит.
2. **Документ «ПланСверхурочныхРабот» + регистр накопления** (по аналогии с оплатами пассажиров): нормально, «на экзамене проканает», но «лишний документ, которого не просили».
3. **Новый непериодический регистр сведений «ПланСверхурочных» (рекомендует автор)** — **без документа**: измерения «Сотрудник» (ведущее, запрет незаполненных, «Выдавать ошибку»), «Подразделение» (аналогично), **«Дата»** (дата без регистра периодичности — как в «ГрафикеРаботы»; ведущее, запрет незаполненных); ресурс «Часов» (5/2, неотрицательное, «Выдавать ошибку»; «нулевую запись разрешить»). **Не периодический** (история изменений нам не нужна — «в такой-то день столько-то часов»).
   - Также вариант: количество сверхурочных часов — **параметр вида расчёта в документе** («Параметр» в ТЧ допначислений) — «вполне нормально, теплее».
   - Не добавлять функционал в документы «НачислениеЗарплаты» ради новых данных — лучше регистр.

## Подготовка записей
`Движения.ДополнительныеНачисления.Записывать = Истина;` цикл: `ЗаполнитьЗначенияСвойств(Движение, Строка)`, `ПериодРегистрации`, **базовый период (для «Сверхурочных»)**, `Записать()`.

## Запрос расчёта
Пакет:
1. `ВТ_Основная` ← записи «ДополнительныеНачисления» по документу: `НомерСтроки`, `Сотрудник`, `Подразделение`; `ВидРасчета = &Сверхурочные`; индексы.
2. **Рабочие часы за прошлый месяц — из регистра сведений «ГрафикРаботы»**, **в разрезе подразделений, а не строк**: `ГрафикРаботы В (ВЫБРАТЬ Подразделение ИЗ ВТ_Основная)`, `Дата МЕЖДУ &НачалоПрошлогоМесяца И &КонецПрошлогоМесяца`, `СУММА(Часов)` → «БазаРабочихЧасов» (ВТ «ДопДанныеГрафика», индекс по графику/подразделению). (Допначисления — без периода действия, «ДанныеГрафика» недоступны → **таблицы регистра сведений здесь допустимы**, пояснение в записке.)
3. **База** `База(&Измерения, , , Регистратор = &Ссылка И ВидРасчета В (&ВидыРасчета))`: `РезультатБаза` → «БазаНачислений» (левое соединение по номеру строки, `ЕСТЬNULL`).
4. **Сверхурочные часы:** `ВТ_ПланСверхурочных` ← `РегистрСведений.ПланСверхурочных`: `Сотрудник`, `Подразделение`, **`СУММА(Часов)`** → «СверхурочныхЧасов» (`(Сотрудник, Подразделение) В (…)`, **`Дата МЕЖДУ &НачалоПериодаРегистрации И &КонецПериодаРегистрации`** — **за текущий месяц**; «сверхурочные — текущего месяца»), индекс по обоим полям (порядок индекса не важен).
5. Константа «ПроцентОплаты» — соединение `ИСТИНА`.
6. Итоговая выборка: основная таблица ЛЕВОЕ соединение с базой, данными графика, планом и константой; **все `ЕСТЬNULL`**; параметры: `НачалоПрошлогоМесяца`, `КонецПрошлогоМесяца`, `НачалоПериодаРегистрации`, **`КонецПериодаРегистрации = КонецМесяца(Дата)`** — **параметрами**, а не функциями в условиях соединения.
- Параметры в консоли: списки значений (сотрудник, подразделение), ссылка документа, даты.

## Цикл
```bsl
Если ВидыРасчета.Найти(Движение.ВидРасчета) = Неопределено Тогда Продолжить;
Выборка.Сбросить(); Выборка.НайтиСледующий(Движение.НомерСтроки, "НомерСтроки");
Если Движение.ВидРасчета = Сверхурочные Тогда
    Движение.Результат = ?(Выборка.БазаРабочихЧасов <> 0,
        Выборка.СверхурочныхЧасов * Выборка.БазаНачислений / Выборка.БазаРабочихЧасов * Выборка.ПроцентОплаты / 100, 0);   // × 150 %
    ЗаполнитьЗначенияСвойств(Движение, Выборка, "СверхурочныхЧасов, БазаНачислений, БазаРабочихЧасов, ПроцентОплаты");
КонецЕсли;
Движения.ДополнительныеНачисления.Записать();
```
(Ошибка в видео: сначала вытащили «отработано дней» «по инерции» — вместо **сверхурочных часов**; убрать ненужные «ОтработаноДней» из запроса оплаты.)
- Пример: база сентября 7 040 / 176 ч = 40 ($/ч) × 5 сверхурочных × 150 % = 300.
- **Ошибка «поле не обнаружено»:** параметры расчёта не были заполнены → `ЗаполнитьЗначенияСвойств`; «не заданы параметры» — забыли `УстановитьПараметр`.

## Прочее
- Автор не будет сдавать «эксперта», устал; на экзамене ИТОГ пересчитывается из базы (оплата по часовому тарифу «заранее и правильно» рассчитана).
- Дальше: расчёт зарплаты **в валютах** (доллары/евро), «Табель» (4–5 билетов), затем «управляемые формы и бизнес-процессы».
- Выгрузка «после занятия 105».
