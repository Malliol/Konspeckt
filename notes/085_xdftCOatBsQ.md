# Урок 85. Расчёт отпуска (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=xdftCOatBsQ · ~45 мин · [полный текст](../transcripts/085_xdftCOatBsQ.md)

## О чём урок
Билет «про автомобили» (билет № 6): **оплачиваемый отпуск = количество дней отпуска × средняя дневная ставка.** Особенность: **дни отпуска считаются по пятидневке, а рабочие дни базовых 3 месяцев — по графику автомобиля.** Решение — **дополнительный ресурс «ДнейПятидневки» в регистре графика**.

## Условие
«**Один календарный месяц в году** сотрудникам предоставляется оплачиваемый отпуск, размер которого определяется как количество дней отпуска, умноженное на среднюю дневную ставку; **дни отпуска рассчитываются по пятидневке**; **средняя дневная ставка = сумма всех начислений за три предыдущих месяца / количество рабочих дней за предыдущие три месяца**».
- **«Один календарный месяц»** — не контролируем («фигура речи»; хотят запутать). **Задним числом отпуск не вводится** → период действия отпуска всегда совпадает с периодом регистрации (нет переходящих отпусков) — поэтому тип зависимости от базы почти безразличен; «ставим по периоду действия» (зависимость по периоду регистрации — для удержаний, их на экзамене практически не бывает).
- Рабочие дни за 3 месяца — **по графику автомобиля** (иначе поле «автомобиль» нигде бы не использовалось — «подозрительно»).
- Расчёт отпуска — **в основных начислениях** (протяжённый, период действия).

## Конфигурация
- Вид расчёта «**Отпуск**» (вместо «Оклад»), план «ОсновныеНачисления»: **зависимость от базы** — по периоду действия, **базовые виды расчёта: все (в т. ч. сам отпуск)**; регистр расчёта «ОсновныеНачисления» — флажок **«Базовый период»**; **«Базовый»** у измерений (сотрудник) в **обоих** регистрах (основные и дополнительные).
- Регистр сведений «ГрафикРаботы» (измерение «Автомобиль»): ресурсы — **«Дней»** (переименовать «Значение») и **новый ресурс «ДнейПятидневки» (5/2)**. В обработке заполнения графика: день недели > 5 → выходной → `ДнейПятидневки = 0`, иначе = 1; «Дней» — по графику автомобиля (жигули — шестидневка: суббота =1, воскресенье =0). Регистр перезаполнить.
- Реквизиты регистра расчёта (показатели): «ДнейОтпуска» (5/2), «БазаНачислений» (10/2), «БазаРабочихДней» (5/2). Связь с графиком — «Автомобиль» ↔ измерение «Автомобиль».
- Ресурс «ДнейПятидневки» — **общий приём**: «добавить любое число ресурсов, которые по разным принципам заполняются» (если нужен подсчёт по двум разным графикам).

## Подготовка записей
```bsl
Для Каждого Строка Из ОсновныеНачисления Цикл
    Движение = Движения.ОсновныеНачисления.Добавить();
    ЗаполнитьЗначенияСвойств(Движение, Строка);
    Движение.ПериодРегистрации    = ПериодРегистрации;
    Движение.ПериодДействияНачало = Строка.ДатаНачала;
    Движение.ПериодДействияКонец  = КонецДня(Строка.ДатаОкончания);
    Если Строка.ВидРасчета = ПланыВидовРасчета.ОсновныеНачисления.Отпуск Тогда
        Движение.БазовыйПериодНачало = ДобавитьМесяц(ПериодРегистрации, -3);
        Движение.БазовыйПериодКонец  = ПериодРегистрации - 1;
    КонецЕсли;
КонецЦикла;
```
Базовый период заполняют **только для отпуска** (вне цикла можно посчитать один раз). Основные начисления можно считать **до дополнительных** (отпуск зависит от прошлых периодов).

## Запрос расчёта отпуска
1. `ВТ_ДанныеГрафика` ← `РегистрРасчета.ОсновныеНачисления.ДанныеГрафика(Регистратор = &Ссылка, ВидРасчета = &ВидыРасчета)`:
   - `НомерСтроки`;
   - **`ЕСТЬNULL(ДнейПятидневкиФактическийПериодДействия, 0)` → «ДнейОтпуска»** — дни отпуска по пятидневке;
   - **`ЕСТЬNULL(ДнейБазовыйПериод, 0)` → «БазаРабочихДней»** — рабочие дни по графику автомобиля за базовый период (поле «…БазовыйПериод» появляется после включения базового периода).
2. Левое соединение с **базой по основным начислениям** (`РегистрРасчета.ОсновныеНачисления.База(&Измерения, , , Регистратор = &Ссылка И ВидРасчета В (&ВидыРасчета))`) и с **базой по дополнительным** (`ДополнительныеНачисления.База(...)`) **по номеру строки**; `ЕСТЬNULL(РезультатБаза, 0)` у обеих → `БазаНачислений = БазаОсновных + БазаДополнительных` (**сумма всех начислений**, включая надбавку и фиксированную).
3. **Массив измерений — только «Сотрудник»** (если бы автомобиль был измерением, пришлось бы суммировать по автомобилю, на которых сотрудник уже не ездит — «полный бред» → поэтому автомобиль — реквизит).
4. Отбор по виду расчёта (массив `ВидыРасчета = {Отпуск}`), цикл: `Если ВидыРасчета.Найти(Движение.ВидРасчета) = Неопределено Тогда Продолжить`.

## Цикл расчёта
```bsl
Для Каждого Движение Из Движения.ОсновныеНачисления Цикл
    Если ВидыРасчета.Найти(Движение.ВидРасчета) = Неопределено Тогда Продолжить; КонецЕсли;
    Выборка.Сбросить();                                // не забывать
    Выборка.НайтиСледующий(Движение.НомерСтроки, "НомерСтроки");   // условие не нужно: левое соединение
    Если Выборка.БазаРабочихДней <> 0 Тогда            // проверка деления на ноль (автор забыл на экзамене)
        Движение.Результат = Выборка.ДнейОтпуска * Выборка.БазаНачислений / Выборка.БазаРабочихДней;
    Иначе
        Движение.Результат = 0;
    КонецЕсли;
    ЗаполнитьЗначенияСвойств(Движение, Выборка, "ДнейОтпуска, БазаНачислений, БазаРабочихДней");
КонецЦикла;
Движения.ОсновныеНачисления.Записать(, Истина);   // есть период действия → Истина
```

## Пример и проверка
- Базовые периоды: «ПериодРегистрации − 3 месяца» и «− 1 секунда»: август → май–июль (замечание зрителя: «почему −1?» — это последняя секунда прошлого месяца).
- Бердыев (жигули — шестидневка) в отпуске 9–15 августа: дней отпуска = 5 (пятидневка), база рабочих дней — по шестидневке. Для Вагиной (москвич, пятидневка) база дней меньше → отпускные выше; для автомобиля со шестидневкой/семидневкой отпускные **занижены** (числитель занижен, знаменатель завышен), для «2 через 2» — завышены.
- Проверка: 50 000 / 7? дней × 5 (калькулятор). Автомобиль может меняться по месяцам (жигули/москвич) — базу это не ломает.
- Расчёт перед выгрузкой нужно проверять «на лету»: если не сошлось — проверить, внесён ли июльский документ.
