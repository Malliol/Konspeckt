# Урок 118. Привязка сообщения к полю формы (УФ). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=IN3ZIWWjm4Q · 35 мин · [полный текст](../transcripts/118_IN3ZIWWjm4Q.md)

## Условие
При проведении документа «РасходнаяНакладная» при нехватке товара выводится сообщение с реальным количеством; сообщение **привязано к полю «Количество» соответствующей строки** табличной части (двойной клик по сообщению активизирует поле). При дублях номенклатуры сообщение связывается с **первой** строкой, содержащей проблемную номенклатуру.

## Привязка сообщения
`Сообщение.Поле` + `Сообщение.УстановитьДанные(Объект)` (или `Сообщение.КлючДанных`):
```bsl
Сообщение = Новый СообщениеПользователю;
Сообщение.Текст = "...";
Сообщение.УстановитьДанные(ЭтотОбъект);
Сообщение.Поле = "СписокНоменклатуры[" + Формат(ИндексСтроки, "ЧГ=") + "].Количество";
Сообщение.Сообщить();
```
- Привязываем **не к элементу формы, а к реквизиту** объекта: путь `Объект.СписокНоменклатуры[Индекс].Количество` (в модуле объекта `Объект.` в поле не пишут, если данные установлены через `УстановитьДанные(ЭтотОбъект)` — альтернативный вариант: тогда поле `"СписокНоменклатуры[0].Количество"`).
- **В квадратных скобках — индекс строки (с 0), а не номер (с 1)** → `НомерСтроки − 1`.
- **Числа в строку — через `Формат(…, "ЧГ=")`** (без группировки разрядов!): при `Строка(1005)` получается «1 005» с разделителем → платформа не распознаёт индекс и привязывает к строке 1 (баг, на который указал зритель; на экзамене важно не забывать).

## Способ 1 (старая методика проведения): номер строки в запросе
- В запросе-шапке по товарам — группировка по номенклатуре с **`МИНИМУМ(НомерСтроки)`** (первое вхождение; `МАКСИМУМ` — последнее; в итогах — тоже минимум).
- В итоговой записи использовать `НомерСтроки − 1` как индекс.

## Способ 2 (новая методика проведения)
- В цикле по выборке нехватки: `НайденныеСтроки = СписокНоменклатуры.Найти(Выборка.Номенклатура, "Номенклатура")`, номер строки — `НайденнаяСтрока.НомерСтроки − 1` (проверка на `Неопределено` не нужна — в запросе только номенклатуры из документа). `Найти` возвращает **первую** строку.
- Альтернатива: вытащить `НомерСтроки` во временную таблицу «ВТ_Товары» (с описанием колонок: номенклатура, количество, номер строки), соединить с остатками левым соединением (с `ЕСТЬNULL` «для страховки») и взять минимум/максимум в запросе (так можно выбирать и первое, и последнее вхождение).

## Метод «Найти» ≠ запрос в цикле
- `Найти` — просто **перебор коллекции в памяти**, обращений к БД нет; в цикле использовать можно. Проверка: «Текущие вызовы» (серверные вызовы) показывают 3 вызова с поиском и без него. Серьёзную оценку снижает именно запрос в цикле (в т. ч. обращение к реквизиту через точку у ссылки — получение представления/реквизитов ссылки), а не `Найти`.
- Для проверки запросов в цикле есть технологический журнал/профайлер, но на экзамене не нужен.
