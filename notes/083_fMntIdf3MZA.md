# Урок 83. Автомобили и фиксированная сумма (СПР). Подготовка к специалисту по платформе 1С
Видео: https://www.youtube.com/watch?v=fMntIdf3MZA · ~30 мин · [полный текст](../transcripts/083_fMntIdf3MZA.md)

## О чём урок
Билет «про автомобили» — по словам автора, самая обсуждаемая задача: «все встают в тупик из-за одного момента — **автомобиль: измерение или реквизит?**». Заготовка — выгрузка после занятия 66. Разобрано условие про автомобили и **вид расчёта «Фиксированная сумма»**; надбавка (процент от…) — в следующих уроках.

## Условие (фрагменты)
- Метод отклонений.
- **Сотрудники работают на автомобилях предприятия, поэтому возможен обмен между водителями.**
- **Все сотрудники работают по графику работы, установленному для каждого автомобиля отдельно.**
- Начисление: **фиксированная сумма денег** — размер одинаков для всех сотрудников и **не меняется в течение расчётного периода**, **не зависит от отработанного времени**.
- Отчёт требует разреза «сотрудник + автомобиль» → **автомобиль должен быть в каждом регистре расчёта**, где что-то считаем (даже без графика и периода действия).
- Подразделений в задаче нет → совместительства нет → убрать «Подразделение» из регистра сведений, регистра расчёта, документа.

## Автомобиль — реквизит, не измерение (главное)
- **Измерение** (как «Подразделение») нужно, когда сотрудник одновременно может работать в нескольких местах (совместительство — независимый расчёт по каждому).
- **Автомобиль** — аналогичен **графику работы**: сегодня жигули, завтра москвич, но **в один момент — один**. Условие «возможен обмен между водителями» и «один сотрудник одновременно двумя автомобилями не ездит» → **реквизит регистра расчёта** (как «ГрафикРаботы»; «график — никогда не измерение»).
- Если сделать измерением — проблемы: при расчёте отпуска (база по прошлым месяцам, если сотрудник ездил на 10 разных автомобилях → 10 строк); «автомобиль как подразделение» (идея зрителя) — ошибка. Версия «в течение дня сотрудник может менять автомобиль» — домысливание; **если в условии не сказано — не додумывать**.
- **Справочник «Автомобили»** (нужно завести), **график работы для автомобиля**: два варианта — (а) поле «График работы» в справочнике автомобилей; (б) **предпочтительнее (так любит Белоусов): автомобиль выступает вместо графика** — справочник/регистр «ГрафикРаботы» **заменить на «Автомобиль»**.

## Реализация
1. **Регистр сведений «ГрафикРаботы»:** измерение «ГрафикРаботы» → «**Автомобиль**» (справочник «Автомобили»); обработка заполнения графика — заменить везде «ГрафикРаботы» на «Автомобиль» (форма, реквизит, модуль; поиск/замена Ctrl+H). Справочник «ГрафикиРаботы» можно удалить. Заполнить график (напр. «жигули»: шестидневка, выходной — воскресенье).
2. **План видов расчёта «ДополнительныеНачисления»:** вид расчёта **«ФиксированнаяСумма»** (период действия — нет; зависимость от базы — нет).
3. **Регистр расчёта «ДополнительныеНачисления»:** измерение «Сотрудник»; ресурс «Результат»; **реквизит «Автомобиль»** (**связь с графиком — не настраивать**: период действия нет; автомобиль нужен только для отчёта); реквизит «ФиксированнаяСумма» (10/2 — «показатель расчёта»); период действия/базовый период — нет.
4. **Документ «НачислениеЗарплаты»:** табличная часть «ДополнительныеНачисления» (сотрудник, **автомобиль** — «Выдавать ошибку», вид расчёта — тип плана «ДополнительныеНачисления»; без дат, без графика); в «ОсновныеНачисления» «График работы» → «Автомобиль»; проверку заполнения таблиц — отключить; при желании — `ОбработкаПроверкиЗаполнения`: если обе таблицы пусты — `Отказ = Истина` (пустой документ).
5. **Регистр сведений «ПоказателиРасчётаЗарплаты»:** **периодичность — в пределах месяца** (сумма не меняется в течение расчётного периода, но может меняться по годам); без измерений; ресурс «ФиксированнаяСумма» (10/2, неотрицательная, «Выдавать ошибку»). Данные: с 01.01.2020 — фиксированная сумма (символическая).
6. **Подготовка записей** (как всегда): `Движения.ДополнительныеНачисления.Записывать = Истина`; цикл по строкам: `Движение = …Добавить(); ЗаполнитьЗначенияСвойств(Движение, Строка); Движение.ПериодРегистрации = ПериодРегистрации`; запись. Период действия/дат нет.

## Расчёт фиксированной суммы
Запрос (конструктор с обработкой результата), как расчёт без графика/базы:
- Записи регистра «ДополнительныеНачисления»: **`Регистратор = &Ссылка` и `ВидРасчета = &ФиксированнаяСумма`** (**отбор по активности — не делать** в расчёте: «считаем даже неактивные»; активность проверяем только в отчётах и «ещё в одном месте»);
- **левое соединение** с **`РегистрСведений.ПоказателиРасчетаЗарплаты.СрезПоследних(&ПериодРегистрации)`**; **условие связи обязательно** (даже без общих измерений — например `ИСТИНА`, иначе при отсутствии записей среза левое соединение не даст строки с NULL), `ЕСТЬNULL(ФиксированнаяСумма, 0)`.
- Цикл: `Если Движение.ВидРасчета <> ФиксированнаяСумма Тогда Продолжить;` — чтобы не считать виды, для которых не получали данных; `Выборка.Сбросить()` (**обязательно**; зрители поймали); `Выборка.НайтиСледующий(Движение.НомерСтроки, "НомерСтроки")` (проверку «если» можно не писать — таблица регистра заполнена); `Движение.Результат = Выборка.ФиксированнаяСумма; ЗаполнитьЗначенияСвойств(Движение, Выборка, "ФиксированнаяСумма")` (**перечислять копируемые показатели строкой**, чтобы не копировать номер строки); `Записать()`.
- Расчёт в первом же цикле (при подготовке) — нельзя: **логика «этап 1 — подготовка, этап 2 — расчёт»** (Белоусов); смешивание — «бардак», автор снизил бы оценку.
- Не забыть: регистры и справочник «Автомобили» — в подсистему «Расчёты» («причесать интерфейс»).

## Ответы зрителям
- **Совместительство** — работа **одновременно** в двух подразделениях (полставки/полный оклад в каждом); перевод в другое подразделение — не совместительство.
- Книга: «Разработка прикладных решений для 1С:Предприятие 8» / «Реализация прикладных задач…» — для подготовки к спецу; при изучении 1С «вообще» книги не нужны.
- Минимальная оценка на экзамене — **3 балла** (скорее «3 с минусом»).
- Билет «автомобили»: следующие стримы — надбавка (процент от…), потом ещё условия; бизнес-процессы тоже планируются.
