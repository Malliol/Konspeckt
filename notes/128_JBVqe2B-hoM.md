# Урок 128. Бизнес-процессы, часть 2 (БП). Подготовка к специалисту по платформе 1С

Видео: https://www.youtube.com/watch?v=JBVqe2B-hoM · 11 мин · [полный текст](../transcripts/128_JBVqe2B-hoM.md)

## О чём урок
**Билет № 15 — бизнес-процесс с условным блоком.** Метаданные (задача, регистр адресации, параметр сеанса) остаются прежними — меняется только карта маршрута и содержимое регистра адресации.

## Карта маршрута
1. Действие «**ЗаказТовара**» — любой сотрудник отдела закупок (указываем только **подразделение «Отдел закупок»**, должность пустая).
2. **Условный блок** (элемент «Условие»; имя, например, «ОплатаНаличными») — две ветки:
   - **ложь → влево:** «**ОплатаЧерезБанк**» — любой бухгалтер из подразделения «Бухгалтерия» (должность «Бухгалтер»);
   - **истина → вправо:** «**ОплатаИзКассы**» — любой **кассир** из «Бухгалтерии» (завести должность «Кассир»);
3. Затем действие «**ОприходованиеТовара**» — **исполнитель непосредственно Сидоров** (основной реквизит адресации указан — регистр адресации не используется) → завершение.
- При рисовании: чтобы переименовать, сначала задать «заголовок», потом имя.

## Условие перехода (обработчик «Проверка условия» условного блока)
В бизнес-процессе завести реквизит-флажок **«ОплатаНаличными»** (булево), вывести на форму процесса; в обработчике условия:
```bsl
Процедура ОплатаНаличнымиПроверкаУсловия(ТочкаМаршрутаБизнесПроцесса, Результат)
    Результат = ОплатаНаличными;   // Истина — вправо, Ложь — влево
КонецПроцедуры
```
(Решение курсов 1С.рф; автор не усложняет.) Включить бизнес-процесс в подсистему (иначе предупреждение при запуске).

## Регистр адресации для этого билета (заново)
- **Очистить регистр** от записей билета № 1 и заполнить заново.
- **Сотрудники отдела закупок** (Паненко, Петренко, Бердыев, Рахимов, Мансуров, Жупиков, Сидоров…) — **подразделение «Отдел закупок», должность пустая**; для действия «ЗаказТовара» адресация только по подразделению.
- **Бухгалтеры** (Мишина, Кротов): должность «Бухгалтер», подразделение «Бухгалтерия».
- **Кассиры** (Васина, Мишина): должность «Кассир», подразделение «Бухгалтерия» (человек может быть и бухгалтером, и кассиром — две записи).
- **Сидорова** в регистр не вносить — исполнитель указан явно.
- Для каждого действия **в регистре адресации должны быть записи** по должности/подразделению, иначе задача не создастся.

## Проверка
- Старт без флажка «Оплата наличными»: задача «Заказ товара» → после выполнения «Оплата через банк» → «Оприходование товара» (Сидоров) → завершение.
- С флажком: «Заказ товара» → «Оплата из кассы» → оприходование.
- Остальные билеты строятся так же.
